# Surface brief — 共享测试台账

- 目标路径：`panel/`
- 模式：Operate（用户在执行一项任务：完成一次本地测试）
- 受众与任务：第一次使用也想直接完成测试的测试/开发用户；在窄幅编辑器面板里选项目、确认目标、选范围、生成计划、确认后运行、读懂结论与未覆盖、处理失败。
- 约束：Vue 3 + Vite + TS；只依赖 `window.aitestHost`；纯本地资源；400–900px 可用；文案全中文且不出现内部标识。
- 成功：用户能说清这次任务是什么、计划覆盖哪几项、本次跑了哪几项、哪些没跑、为什么没通过，以及下一步做什么。

## Direction contract

THESIS: 一张工程师的测试台账，不是工作台、仪表盘或聊天。任务、计划、运行、证据按同一条验收项脊线排列；计划/报告/问题详情是二级文档页。

OWN-WORLD: 浅色冷灰 `#f4f5f3` 或与编辑器一致的近黑 `#0f1211`；1px 分隔线；单一 petrol 强调色（浅色 `#0f6b5f` / 深色 `#5fd3c0`）；正文 11–13px、任务标题 18px；等宽只给数字、路径、证据与命令。无卡片、渐变、发光、胶囊；菜单浮层允许轻阴影，文档页全屏。

STORY: 顶栏只有项目按钮、测试/问题/历史、设置；项目按钮打开自绘菜单，不用原生下拉框；任务“切换目标”和报告版本也用自绘菜单。测试页按“选目标 → 选范围 → 生成计划 → 确认后运行 → 读结果”推进，每个状态只给一个主操作。范围编辑出现在无计划、计划过期或主动“调整范围”（含结果页）。固定头显示任务、计划/时间/用例数与状态；覆盖条给通过/失败/阻塞/等待中/未纳入计数。台账只列本次纳入的验收项，未纳入项收在底部摘要。失败用例在行内展开证据、问题、解释。结果页可查看计划、调整范围、报告、重跑未通过项/再次运行。历史是项目级列表，点开只读快照；问题是项目级台账。

FIRST VIEWPORT: 42px 顶栏；任务标题与“切换目标”；一行计划/时间/状态；覆盖条与计数；项目级检查；本次纳入的验收项台账；底部一个主操作。没有步骤向导、没有卡片外壳、没有聊天框、没有巨型结论、没有第二套工具栏。

FORM: 单列台账，最大 900px；验收项是章节，用例是条目，证据是内联文件名按钮；计划/报告/问题详情全屏文档页；证据文件用系统程序打开，没有缩略图或内嵌大图。

FINISH: 设计定稿以 `DESIGN.md` 与实现后的 640/420 深色截图为准；浅色截图待补。未在真实 Trae 重跑的验收项不得写成通过。
