# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vue 3 + Vite + TypeScript。纯本地资源构建：无 CDN、无在线字体、无外部图标库。

## Users

Windows 11 上的测试与开发人员，在 Trae 编辑器里对一个本地项目做上线前自测。熟悉代码与命令行，但不希望在侧栏里读内部状态码或手工拼命令。使用场景是白天办公桌前、编辑器深色主题下、面板宽度 400–900px。

## Product Purpose

把“选项目 → 确认验证目标 → 选范围 → 生成计划 → 确认后运行 → 看结论与证据”收进一个窄面板。任务是稳定对象，计划是任务的合同，运行是合同的一次尝试；面板只展示 CLI 返回的事实，不计算判定。

## Positioning

与通用测试面板的差别在“分母可见”：本次范围、适用项、未覆盖、未核实始终与结论同屏；AI 只解释事实，不改变结论。面板是跨编辑器共享的同一份前端，Trae 只是第一个宿主。

## Operating Context

- 宿主注入 `window.aitestHost`（call/getState/setState/getContext/openPath），面板只通过它取数与触发动作。
- 业务能力来自一期 CLI：项目、任务、计划、运行、证据、问题、报告、环境自检。
- 运行在后台 worker 中进行；关闭面板不中断运行，重开后在测试或历史里找回。
- 数据保存在用户数据工作空间，不写进被测源码。

## Capabilities and Constraints

- 顶层只有测试 / 问题 / 历史，设置收在右上角；项目切换在顶栏。
- 测试工作区只有一张验收项台账：计划、运行、结果共用；状态变化只改头部、行状态和底部操作。主台账只列本次纳入的验收项，未纳入项收在底部折叠区。
- 范围先选，按范围生成计划；范围变化生成新计划；计划内改用例生成新版本；任务验收项/验证方式变化使旧计划过期。范围编辑出现在无计划、计划过期或主动“调整范围”（含结果页）时。
- 执行前确认绑定计划版本、范围、环境、凭据来源、副作用和依赖；必须由人勾选确认。
- 计划、报告、问题详情用二级全屏文档页；台账内只给证据文件名按钮，证据查看器是全屏列表，点击用系统程序打开，没有缩略图或内嵌大图。
- 顶栏项目、任务“切换目标”和报告版本都是自绘菜单，不用原生下拉框。
- 问题按失败签名归并；状态待确认→处理中→待复测→已关闭；关闭必须绑定新运行的实际通过证据。
- 报告默认读最近一份；重新生成是显式动作；旧报告保留；验收意见可沿用。
- 已实现：项目规则列出/查看/绑定、GitHub 变更只读、补充证据、导入调用链日志、结果页调整范围。
- 未实现：规则编辑（`rules.save/import/export` 无 UI）、`link.assert` 无 UI、浅色截图、`Ctrl+Enter`/`Esc` 快捷键与焦点恢复。
- 接线缺口：计划文档调用的 `plan.update` 与 `delivery.show` 尚未加入扩展白名单，真实 Trae 中保存计划/读取交付会被拒绝；补齐前不宣称这两项可用。
- 界面不出现冒烟、L1/L2/L3、S/M、Mock、plan_id/run_id、失败签名、错误码；专业词如副作用、凭据、验收项、用例、阻塞保留。
- 不引入外部字体、图标库或网络请求；不实现判定、覆盖计算与 Mock 真实性推断。

## Brand Commitments

- 全中文，面向测试与开发用户；文案说“哪里错了 + 下一步怎么做”。
- 状态用“运行中 / 已完成 / 已取消 / 已中断 / 执行出错”；结论用“通过 / 没通过 / 没测完 / 这次不用测”。
- 不知道就写“未知 / 未提供 / 未验证 / 无法判断”，不用绿色掩盖。
- 视觉：深色中性台账 + petrol 强调色；无卡片、渐变、玻璃、发光、超大结论、聊天框。
- 表格与台账用 1px 分隔线；状态用文字 + 小记号，不靠颜色单独表达。

## Product Principles

1. 事实优先：结论、覆盖、用例结果只来自后端字段。
2. 分母可见：没有分母的数字不展示；未覆盖、未核实要说出来。
3. 一个主对象：任务；计划是合同，运行是尝试。
4. 不假装：缺能力、缺证据、未验证都明确写出来。
5. 一个面板：所有宿主共用同一份前端与同一套桥接契约。
6. 说人话：内部行话不进界面，专业词保留但不用口语替代。

## Operating Flow

- 打开面板：有项目则恢复上次任务/计划/运行；没有项目先登记。
- 无任务：AI 读项目给出目标候选，默认选第一条；人点“开始验证这个目标”才建任务。
- 有任务无计划：选本次范围，按范围生成计划。
- 有计划：台账显示计划用例；执行前确认后开始。
- 运行中：同一台账更新；可停止；关闭面板不中断。
- 结果：结论、本次范围/适用项、未覆盖、失败/未完成、证据、问题、解释、报告；可查看计划、调整范围或重跑未通过项/再次运行。
- 历史：项目级运行列表；点开只读运行快照。
- 问题：项目级台账；关闭绑定新运行证据。
- 设置：环境自检、项目规则（只列出/查看/绑定）、GitHub 变更（只读）、折叠的项目配置、外观、备份。
