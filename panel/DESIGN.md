# Design — AITEST 控制台

> 记录已建成的视觉系统，供后续增补页面时保持一致。产品事实见 `PRODUCT.md`，方向合同见 `SURFACE.md`。
>
> 2026-11-17 第二版：从“单卡片测试单”改为全宽控制台（AITEST CONSOLE）：无卡片、锐角、铜色信号、11px 单色标签、底部状态线。

## 1. 世界与基调

一台本地测试控制台：石墨黑地面、1px 规则线、锐角，铜色只用于编号、选中与光标。结论色低饱和，绝不靠颜色掩盖不确定。深色是使用场景决定的（编辑器内、白天办公环境、宿主本身为深色），不是品类默认。

## 2. 颜色

| 角色 | 值 | 用法 |
| --- | --- | --- |
| 地面 | `#08090a` | 页面背景、顶栏、状态线 |
| 表面 | `#0f1111` | 下沉区、弹层 |
| 抬升 | `#171a1a` | 次级按钮、选中段、hover |
| 下沉 | `#050606` | 输入框、输出块、进度槽 |
| 发丝线 | `#252a2a` | 分区、列表分隔 |
| 强线 | `#3a4141` | 控件边框、重点分隔 |
| 主文本 | `#f0f1f1` | 标题与正文 |
| 次文本 | `#a8aeae` | 说明 |
| 弱文本 | `#7e8686` | 辅助信息（≥4.5:1） |
| 强调 | `#e0a56b` / 线 `#b57a45` | 焦点、选中、编号、光标 |
| 通过 | `#8fbf9c` | 结论与用例状态 |
| 失败 | `#e08d82` | 结论、错误、危险 |
| 未完成 | `#d2b074` | 阻塞、待人工、风险 |
| 中性 | `#98a1a8` | 未运行、已取消、不适用 |

主按钮用近白底深字（`#f0f1f1` / `#090a0a`），在深色界面里形成唯一最高权重动作；危险动作只用描边与文字色，不用整块红底。

## 3. 字体与数字

- UI：`Segoe UI Variable Text` → `Segoe UI` → 系统中文无衬线；不加载在线字体。
- 等宽：`Cascadia Mono` → `Consolas`，只用于路径、证据引用、执行输出。
- 13px 正文、12px 辅助、10–11px 单色微标签、20px 页面标题、44px 结论词；固定 rem/px 阶梯，不随视口缩放。
- 所有计数使用 `font-variant-numeric: tabular-nums`；覆盖永远写成 `X / Y`。

## 4. 形状与层级

- 控制台没有卡片：内容直接铺在石墨地面上，只用 1px 规则线与留白分节。
- 圆角归零：控件 2px、徽标 0；不使用胶囊按钮。
- 层级只靠 1px 边框与表面色差表达，不加投影；唯一阴影保留给弹出层与抽屉。
- 焦点环 2px `#e5b98a`，偏移 2px；文本选区与滚动条从同一套颜色取。
- 不用彩色左边框做装饰；仅当前用例允许 2px 铜色定位线。不做毛玻璃、渐变文字、圆角卡片。

## 5. 组件词汇

| 组件 | 规则 |
| --- | --- |
| 品牌条 | 40px：`AITEST` 单色字标 + 闪动铜色光标 + `PROJECT` 选择器；右侧 `● READY` 与设置 |
| 状态线 | 24px 固定底栏：`LOCAL / NO NETWORK`、轮询状态或 `CTRL+ENTER RUN`；不承载业务动作 |
| 按钮 | primary（近白）/ secondary（透明+描边）/ ghost（文字）/ danger（红描边）；高度 30/26；锐角 2px |
| 范围条 | `RANGE` 单色标签 + `X/Y` + 逐条 10px 铜色刻度；验收项行用方形勾选与 `01..` 编号 |
| 状态标记 | 5px 色点 + 10px 单色文字，无底色无描边；颜色只辅助，文字承担语义 |
| 状态点 | 6px 圆点 + 中性标签；`running` 时呼吸 |
| 字段 | 12px 标签 + 控件 + 说明/错误；错误替换说明，不叠加 |
| 卡片 | 表面 + 发丝线；分区标题右侧可带 12px 注释 |
| 空态 | 图标块 + 一句标题 + 一段解释 + 一个动作 |
| 结论记分牌 | 左侧运行状态、结论词、一句解释与确认回执；右侧 `S/M`、按验收项着色的刻度、用例通过/失败/未完成/待人工计数；未纳入项与 AI 假设分行列出，不合并成一个“未验证” |
| 覆盖刻度 | 12px 刻度块；≤12 条逐条着色，超过 12 条退化为按状态分段的横条；分母为 0 时项目检查模式写“项目检查 X/Y 通过” |
| 失败用例 | 44px 折叠行（序号/标题/失败徽标/箭头）；首条默认展开；展开后显示验收标准、预期、层级与方式、输出、证据；行尾只保留“只重跑这条” |
| 分段进度 | 运行中每个用例一段 8px 色块（通过/失败/未完成/未执行），当前段呼吸；不使用百分比暗示总体完成度 |
| 人工记录 | `manual_pending` 行内“记录结果”→“通过/失败/阻塞+备注”→保存后重读运行；人工事实不伪装成 AI 判定 |
| 测试单 | 单张卡片：顶部“测试单 / 项目名 / 项目详情 / 历史”，其下目标标题与一句依据；建议、运行、结果三个相位在卡片内切换，不跳页 |
| 目标菜单 | 从“换一个目标”弹出的固定定位层，右对齐；列出候选与“自己写一句”，当前项标“当前”，Esc 关闭 |
| 历史时间线 | 右侧 `INSPECTOR` 抽屉内纵向线 + 节点；当前运行用铜色填充，点击在当前视图回放 |
| 证据缩略卡 | 文件名 + 类型（截图/数据/记录）+ 大小；缺失标“缺失”，点击交给宿主打开 |
| 抽屉 | 右侧 440px 模态层；历史、调整、项目详情与证据都在这里；Esc 关闭，焦点留在层内 |
| 勾选 | 14px 方形框，选中铜色底 + 深色勾；每行前有 `01…` 单色序号，只用于“纳入 / 不纳入” |
| 摘要 chips | 12px 键 + 同色描边值；没有内容写“未记录”，不省略分组 |
| 分段标签 | 用于高级配置，一次只渲染一个分组；修改未保存时标赭黄点 |

## 6. 布局

- 顶栏 40px，粘性；左侧 `AITEST` 字标，项目选择器最宽 300px，右侧 `READY` 与设置。
- 内容最大宽度 820px 居中，但页面本身全宽无卡片；页面内边距 24px，≤520px 时 16/12px。
- 底部 24px 固定状态线；页面预留 24px 内边距，避免最后一行被遮住。
- 主视图是一张测试单卡片，不再有独立项目页、运行页或结果页；抽屉 440px，≤520px 占满宽度。
- 正常路径不常驻文本框：写目标在“换一个目标”弹出层里按需展开，验收项与交付字段在调整抽屉里编辑，JSON 进高级配置。
- 结果页先给结论记分牌，再给编号分区（01 失败、02 阻塞、03 AI 解读、04 遗留问题、05 证据与报告、06 验收意见、07 全部用例）；链路、模板处置、全部用例、交付字段默认折叠；摘要永远能指回可展开的原文。
- 结果页“再测一次/新目标”放在记分牌之后，滚动时吸顶；失败与阻塞行用 44px 折叠行，通过/未执行不占据失败区。
- 列表行 10–16px 内边距；分组之间 16px；标题上方留白大于下方。
- 开始测试与运行操作放在测试单底部；抽屉底部固定保存/取消，主按钮始终可达。

## 7. 状态与文案

- 测试单相位：建议 / 运行 / 结果；设置是同一面板的另一屏，可从顶栏环境点进入并返回。
- 结论：通过 / 失败 / 未完成 / 不适用；运行：未开始 / 运行中 / 已完成 / 已中断 / 已取消 / 执行异常。
- 错误块固定三段：哪里错了、后端消息（若有）、下一步怎么办；不显示错误码。
- 空态教下一步，不写“暂无数据”。
- AI 分析不合格时整块隐藏正文，只说明原因。
- 运行取消发生在用例边界时，记分牌写明“已完成用例仍参与结论”，不把取消当成免责。
- 未提供的字段写“未提供 / 未记录”，不估算。

## 8. 动效

- 120–240ms，仅用于状态变化：相位内容 3px 位移淡入、进度条宽度、状态点呼吸、加载骨架扫光、抽屉滑入与目标菜单下落。
- 无页面级入场编排；`prefers-reduced-motion` 下全部关闭。

## 9. 宿主约束

- 构建产物由 Trae 注入的 CSP 加载：脚本需 nonce，样式允许 `'unsafe-inline'`（Vue 动态样式），图片仅本地与 data URI。
- 面板不访问网络、不写文件；所有数据来自 `window.aitestHost.call`。

## 10. 皮肤

- `data-skin="console"`：默认石墨黑 + 铜色（上面的 token）。
- `data-skin="paper"`：暖纸底 + 墨色文字 + 锈色信号；语义状态色相应加深，保持对比度。
- 皮肤只覆盖 token，不改变布局、组件结构、文案或任何业务事实；切换入口在顶栏主题按钮与设置 `[05] 外观`。
- 偏好写入 `localStorage["aitest.skin"]`，刷新/重开面板后保持；宿主禁用存储时只影响本次会话。
