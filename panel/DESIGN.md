# Design — 共享测试面板

> 记录已建成的视觉系统，供后续增补页面时保持一致。产品事实见 `PRODUCT.md`，方向合同见 `SURFACE.md`。

## 1. 世界与基调

一台测试计量仪：石墨黑工作台、冷灰层、1px 发丝线，钢蓝只用于选择与焦点。结论色低饱和，绝不靠颜色掩盖不确定。深色是使用场景决定的（编辑器内、白天办公环境、宿主本身为深色），不是品类默认。

## 2. 颜色

| 角色 | 值 | 用法 |
| --- | --- | --- |
| 地面 | `#0e1012` | 页面背景、吸底操作条 |
| 表面 | `#15181b` | 卡片 |
| 抬升 | `#1a1e22` | 次级按钮、选中段、hover |
| 下沉 | `#0b0d0f` | 输入框、输出块、进度槽 |
| 发丝线 | `#262b30` | 分区、列表分隔 |
| 强线 | `#363d44` | 控件边框 |
| 主文本 | `#e7eaec` | 标题与正文 |
| 次文本 | `#a3acb4` | 说明 |
| 弱文本 | `#7d868e` | 辅助信息（≥4.5:1） |
| 强调 | `#a8c8e0` / 线 `#4a7d9e` | 焦点、选中、链接 |
| 通过 | `#86b394` | 结论与用例状态 |
| 失败 | `#d68d84` | 结论、错误、危险 |
| 未完成 | `#c9a86f` | 阻塞、待人工、风险 |
| 中性 | `#9aa3ab` | 未运行、已取消、不适用 |

主按钮用近白底深字（`#e9edf0` / `#101316`），在深色界面里形成唯一最高权重动作；危险动作只用描边与文字色，不用整块红底。

## 3. 字体与数字

- UI：`Segoe UI Variable Text` → `Segoe UI` → 系统中文无衬线；不加载在线字体。
- 等宽：`Cascadia Mono` → `Consolas`，只用于路径、证据引用、执行输出。
- 13px 正文、12px 辅助、14px 分区标题、20px 页面标题、26px 结论词；固定 rem/px 阶梯，不随视口缩放。
- 所有计数使用 `font-variant-numeric: tabular-nums`；覆盖永远写成 `X / Y`。

## 4. 形状与层级

- 卡片圆角 12px，控件 8px，徽标 6px；不使用胶囊按钮（模块筛选除外）。
- 层级只靠 1px 边框与表面色差表达，不加投影；唯一阴影保留给弹出层。
- 焦点环 2px `#9fc4dd`，偏移 2px；文本选区与滚动条从同一套颜色取。
- 不做彩色左边框、毛玻璃、渐变文字、超大圆角。

## 5. 组件词汇

| 组件 | 规则 |
| --- | --- |
| 按钮 | primary（近白）/ secondary（描边）/ ghost（文字）/ danger（红描边）；高度 32/28；加载时显示行内小环并禁用 |
| 徽标 | 四种结论色 + 中性 + 进行中；小号、带 1px 同色描边 |
| 状态点 | 6px 圆点 + 中性标签；`running` 时呼吸 |
| 字段 | 12px 标签 + 控件 + 说明/错误；错误替换说明，不叠加 |
| 卡片 | 表面 + 发丝线；分区标题右侧可带 12px 注释 |
| 空态 | 图标块 + 一句标题 + 一段解释 + 一个动作 |
| 覆盖表 | `X / Y` + 4px 轨道 + 未覆盖说明；分母为 0 时写“没有适用项” |
| 结论块 | 状态徽标行、结论词、一句解释、覆盖表；结论色只染词与顶部极淡渐层 |
| 步进轨 | ≥720px 为左侧粘性刻度轨；更窄为顶部横向刻度，已完成显示勾 |

## 6. 布局

- 顶栏 48px，粘性；项目选择器最宽 320px，环境点与设置靠右。
- 内容最大宽度 760px 居中；页面内边距 24px，≤520px 时 16/12px。
- 向导 ≥720px 为 168px 轨 + 内容两列；更窄单列。
- 列表行 10–16px 内边距；分组之间 16px；标题上方留白大于下方。
- 步骤 3、4 的操作条吸底，主按钮始终可达。

## 7. 状态与文案

- 结论：通过 / 失败 / 未完成 / 不适用；运行：未开始 / 运行中 / 已完成 / 已中断 / 已取消 / 执行异常。
- 错误块固定三段：哪里错了、后端消息（若有）、下一步怎么办；不显示错误码。
- 空态教下一步，不写“暂无数据”。
- AI 分析不合格时整块隐藏正文，只说明原因。
- 未提供的字段写“未提供 / 未记录”，不估算。

## 8. 动效

- 120–240ms，仅用于状态变化：步骤进入 3px 位移淡入、进度条宽度、状态点呼吸、加载骨架扫光。
- 无页面级入场编排；`prefers-reduced-motion` 下全部关闭。

## 9. 宿主约束

- 构建产物由 Trae 注入的 CSP 加载：脚本需 nonce，样式允许 `'unsafe-inline'`（Vue 动态样式），图片仅本地与 data URI。
- 面板不访问网络、不写文件；所有数据来自 `window.aitestHost.call`。
