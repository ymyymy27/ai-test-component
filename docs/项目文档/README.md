# 项目文档

本目录是**产品合同层**：按期次分（一期、二期、三期），每个期次内部按文档类型分六类。字段、状态、时序与验收预期以这里为准；状态和问题以[项目现状](../现状.md)为准，跨包接口以[接口对接](../接口对接/README.md)为准。

## 1 期次与文档

| 期次 | 状态 | 目录 |
| --- | --- | --- |
| 一期 | 当前交付范围；轻量插件 18 FR / 26 AC | [一期](一期/README.md) |
| 二期 | 规划稿；6 FR / 9 AC，全 `untested` | [二期](二期/README.md) |
| 三期 | 规划稿；平台合同未定；2 FR / 8 AC，全 `untested` | [三期](三期/README.md) |

## 2 文档类型

每期使用相同的分类；二期、三期没有 `06-发布运维`，因为尚未实现。

| 类别 | 一期内容 | 回答什么 |
| --- | --- | --- |
| `01-项目` | 项目简报、技术评估、交付计划、遗留问题与风险 | 为什么做、范围、成本、交付与风险 |
| `02-需求` | 业务方案、需求规格、功能清单 | 角色与流程、FR/AC、判定与统计唯一口径 |
| `03-设计` | 产品方案与界面设计 | 页面、动作、文案与交互状态 |
| `04-架构` | 架构总览 + 7 个分册 + 开发规则 | 分层、字段、接口、存储、宿主、事务与安全 |
| `05-测试验收` | 测试计划、验收台账 | 怎么验、每条 AC 的证据与状态 |
| `06-发布运维` | 发布方案、恢复预案、安装操作、运维手册、效果检测 | 怎么发、怎么回、怎么用、怎么排障 |

## 5 维护约定

- 新增或修改合同，先改对应期次的 `02-需求` 或 `04-架构`，再同步 `03-设计`、`05-测试验收` 与 [验收台账](一期/05-测试验收/02-验收台账.md)。
- FR/AC 编号基线：一期 17/35、二期 6/9、三期 2/8，合计 25/52。改编号必须显式更新映射与 `status.json`。
- 文档分类与编号可以调整，调整后同步三期 `README.md`、[文档总览](../README.md)与相关链接。
