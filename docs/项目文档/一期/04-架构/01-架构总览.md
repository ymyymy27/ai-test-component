# 架构总览（一期）

> 状态：2026-11-16 设计基线（D4）。契约见[CLI 与数据契约](../03-设计/03-CLI与数据契约.md)；执行见[执行与证据](03-执行与证据.md)；存储见[存储与备份](04-存储与备份.md)。

## 1 形态

```text
Trae 扩展（UI / 命令）
   │  JSON over stdio
   ▼
Python CLI（按命令调用，进程结束即退出）
   ├─ core        领域规则与状态
   ├─ storage     文件读写、锁、备份
   ├─ runners     外部命令/HTTP/Playwright
   └─ adapters    模型、GitHub、链路
        │
        ▼
用户级工作空间（JSON / Markdown / 证据 / zip）
```

没有常驻核心、命名管道、数据库、索引、事件日志。

## 2 依赖方向

```text
扩展 → cli → core / storage / runners / adapters
core / storage / runners / adapters → models / errors / security
```

- `core` 不读文件、不调网络，规则可单测；
- `storage` 只做文件与目录，不做业务；
- 适配器互不依赖；
- 反向引用需在提交说明写原因。

## 3 进程模型

| 进程 | 生命周期 | 职责 |
| --- | --- | --- |
| 扩展 | 随 Trae | 界面、命令、参数收集、轮询、确认 |
| CLI | 单次命令 | 校验、读写、调用 core、输出 JSON |
| worker | 单次运行 | 执行用例、写运行目录、刷新心跳 |

- `run.start` 启动 worker 后立即返回；
- worker 不是守护进程，运行结束即退出；
- 同一项目同时只允许一个运行；
- 进程间只通过文件通信。

## 4 模块划分

| 模块 | 职责 |
| --- | --- |
| `cli.py` | 命令分发、信封、错误映射 |
| `worker.py` | 运行循环、取消、心跳、证据落盘 |
| `models.py` | 数据模型、枚举、字段校验 |
| `errors.py` | 错误码与异常 |
| `config.py` | 用户配置、密钥解析 |
| `security.py` | 脱敏、路径校验、危险命令扫描 |
| `storage/` | 工作空间、原子写、锁、证据、备份 |
| `core/` | 项目、任务、规则、计划、执行、证据、问题、报告 |
| `runners/` | 命令/pytest、HTTP、JUnit 解析、断言；Playwright 由命令执行器运行；人工记录归 `core/manual.py` |
| `adapters/` | 模型、GitHub、链路 |

## 5 一次运行的调用链

```text
扩展 → cli run.start
  → 读 plan/task/project/config
  → core 校验范围、确认记录
  → storage 创建 runs/<id>/、写 run.json
  → 启动 worker，返回 run_id
worker
  → 按计划取用例
  → runners 执行（必要时启动服务、生成脚本）
  → 证据写 runs/<id>/evidence/，结果写 run.json
  → 结束时派生结论与计数，先写 `completed`
  → 退出后异步生成 Mock 判定与 AI 分析并补写
扩展轮询 run.status → 展示结果
```

## 6 关键设计选择

| 选择 | 原因 |
| --- | --- |
| CLI 单次调用 | 无常驻进程，安装/升级简单 |
| 每次运行一个 worker | 长任务不占 CLI，关编辑器不中断 |
| 文件存储 | 数据量小，用户可直接查看与备份 |
| 无数据库/索引 | 避免系统级复杂度；需要时先分页/缓存 |
| AI 产出带依据 | 分析可追溯，判不出就写未知 |
| 结论由 core 派生 | 单一判定口径，面板与适配器不重算 |
| 扩展不直接写文件 | 所有写入走 CLI，锁与原子写集中 |

## 7 失败边界

| 失败 | 行为 |
| --- | --- |
| 模型不可用 | AI 步骤标未生成；测试、证据、报告继续 |
| GitHub 不可用 | 关联标缺口；不影响本地测试 |
| 链路缺配置 | 标缺口；不阻塞用例 |
| 服务启动失败 | 依赖 `service` 的用例 `blocked` |
| worker 被杀 | 心跳超时 + PID 不在 → `interrupted` |
| 磁盘不足 | 停止写入并报错 |
| 旧数据格式 | 拒绝并提示转换或重建 |

## 9 非目标

- 多入口并发写业务文件；
- 跨机器同步与多人协作；
- 平台上传、共享审核；
- 任意框架零配置适配；
- 全仓语义分析。
