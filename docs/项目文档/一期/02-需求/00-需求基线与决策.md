# 需求基线与决策（一期）

> 状态：2026-11-16 轻量插件重构基线。上位执行计划见[轻量 Trae 插件修改计划](../../../修改日志/ymy/2026-11-16-轻量Trae插件重构计划.md)；本文只记录基线声明、关键决策与旧编号映射。

## 1 基线声明

- 一期按“Trae 扩展 + 本地 Python CLI + 文件工作空间”实现，不做系统级平台；
- 需求以[需求规格](02-需求规格.md)的 18 项 FR 与 26 条 AC 为准；
- 行为、状态与判定以[功能清单](03-功能清单.md)为准；
- 旧 21 FR / 26 AC 与本文件下方的映射仅作历史追溯，不再作为实现依据；
- 模型 API 必需；GitHub 与链路是一期必需的薄适配器；
- 一期不登录、不上传、不做共享审核。

## 2 关键决策

| 主题 | 决策 |
| --- | --- |
| 宿主 | Trae；其他编辑器后置 |
| 运行形态 | 扩展调用 CLI；没有常驻核心 |
| 长任务 | 每次运行一个 detached worker；取消用标志文件 |
| 范围 | 按验收项选择；全部适用 / 自选（模块筛选，可选层级） |
| 计划 | AI 生成后自动发布为初版；改动生成新修订 |
| 执行确认 | 执行前确认一次；范围/环境/凭据变化需重新确认 |
| 重跑 | 按验收项新建运行，旧运行保留 |
| L3 | 前端 UI 与接口/命令；AI 生成可重放脚本；不可自动化转人工 |
| Mock | AI 按需读业务代码判定，附依据；不可手改 |
| 问题 | AI 自动生成，按失败签名去重；五态 |
| 报告 | core 生成独立结论；AI 摘要只写事实 |
| 验收意见 | 自由文本，无审批流 |
| 存储 | 用户级工作空间；JSON/Markdown/证据；原子写；zip 备份 |
| 密钥 | 环境变量优先，其次用户级配置；工作空间不存 |
| GitHub | `gh` CLI 登录态，只读 |
| 链路 | 日志文件 + 只读查询命令 |
| 证据 | 永久保留；单文件 20MB 截断；媒体软上限 |
| 变更回归 | 一期只提示；影响分析后置二期 |
