# 需求规格（一期）

> 适用期次：一期；主责：产品目标、范围、21 项 FR 与验收场景；状态：需求重写版，未重新验收。
> 上位决策见[需求基线与决策](00-需求基线与决策.md)；业务语义见[业务方案](01-业务方案.md)；行为与判定口径见[功能清单](03-功能清单.md)。

## 1 产品目标

在 Windows 11 x64 的 Trae 中提供本地 AI 辅助测试插件：用户能够理解项目上下文、组织任务/验收项、生成计划/用例、执行 L1/L2/L3、关联 GitHub 变更与链路证据、形成问题清单、跟踪回归并导出报告。所有记录保存在本机文件工作空间。

目标：

1. 验收项、用例、执行、证据、问题、回归可相互追溯。
2. 源码可运行、模块功能、用户业务流程分别表达。
3. 实际执行结果与开发说明、Mock 声明、AI 候选分析分开。
4. 模型不可用时仍能保留证据、人工处理与导出。
5. 一期不依赖账号、上传或共享审核。

## 2 范围与边界

### 2.1 支持环境

| 项 | 范围 |
| --- | --- |
| 宿主 | Windows 11 x64 上的 Trae 稳定版 |
| Python | 3.11 及以上；当前验证 3.11/3.13，3.14 未验证 |
| 数据 | 本机文件工作空间；单写核心；不监听网络端口 |
| 模型 | DeepSeek 兼容的 HTTP 模型 API，可选 |
| GitHub | 只读关联一个私有仓库；手动刷新；不接 Webhook |
| 链路 | HTTP 执行器自动记录请求 + 人工页面请求编号；不装浏览器扩展 |

### 2.2 一期不做

- 统一账号、结果上传、共享查询、跨账号审核、结果接收端；
- 计划许可账本、逐动作授权记录、证据等级 A—D；
- 7 步格式迁移/回滚/注册表；
- 自动点击捕获、浏览器回放、跨服务/函数级追踪；
- 其他编辑器与操作系统组合；
- 生产部署、合并冲突处理、无人审核自动修复。

### 2.3 明确保留

- 模板体系作为规则库预设检查清单；
- 功能/验收项覆盖与 L1/L2/L3 分层统计；
- 永久保留、备份与恢复；
- 一次范围确认 + 动作日志。

## 3 功能需求

### FR01 项目与模块上下文

- **输入**：本地目录、项目目标、模块职责、依赖、接口说明、实现状态、负责人。
- **规则**：支持 git 与 plain 目录；同步盘/网络盘拒绝；AI 推断关系标为推断并需人工确认；目录或形态变化新建绑定修订。
- **输出**：项目编号、模块清单、绑定修订、依赖图、上下文缺口。
- **异常**：路径无效、目录不可写、仓库信息不可得时阻塞并说明。

### FR02 任务与验收项

- **输入**：任务目标、范围、输入输出、前置条件、验收项、执行/验收人。
- **规则**：验收项独立编号，必须可观察；可关联多个用例与证据；需求变化保留版本并提示用例待更新；AI 可提建议但不能改要求。
- **输出**：任务修订、验收项清单、验收项到用例/证据的引用。
- **异常**：验收标准不完整时显示待补充，不推进为可验收。

### FR03 标准交付说明

- **输入**：原始任务、完成/未完成内容、变更模块、接口变化、运行方式、测试数据、依赖、Mock、已知问题、自测证据。
- **规则**：统一模板；AI 可起草，用户确认后提交；开发自述完成与测试验证完成分列；缺必填或无可识别版本时提示补齐。
- **输出**：交付说明修订、Mock 清单、源码版本关联。

### FR04 GitHub 变更与检查

- **输入**：仓库、分支、提交、PR、已有检查、合并状态、部署版本。
- **规则**：只读；手动刷新；固定被测提交；环境部署版本不一致时提示；无法取得部署版本标未确认；检查通过不改变业务结论。
- **输出**：变更关联、检查结果引用、版本对应关系。
- **异常**：GitHub 不可用时显示未确认或缺口，不用缓存冒充最新。

### FR05 测试规范与规则库

- **输入**：人读测试步骤、AI 检查规则、证据要求、输出格式、模板预设。
- **规则**：规则分类、版本、项目绑定、Markdown 导入导出；新测试用新版本，历史保留；模板是提醒清单，不是第二套发布门禁。
- **输出**：规则版本、模板应用结果、项目当前规则引用。
- **异常**：导入内容不自动成为已授权执行规则。

### FR06 测试计划与用例

- **输入**：任务、交付说明、项目上下文、规则、模板预设、验收项。
- **规则**：AI 建议范围与用例，用户编辑后发布；用例含验收项、层级、前置条件、输入、步骤、预期、验证方式、Mock 许可、重要性；无预期或前置条件不得发布。
- **输出**：计划修订、用例修订、范围、档位与驱动。
- **异常**：AI 不可用时允许人工编写或导入。

### FR07 引导式测试工作台

- **输入**：已发布计划、环境、规则、测试数据。
- **规则**：按阶段/步骤展示目的、规则、输入、动作、结果、证据与下一步；支持暂停、取消、重试、补证、退回；缺环境/凭据/依赖/数据时阻塞；未执行不得汇总为通过。
- **输出**：运行、步骤、尝试、证据、控制状态。
- **异常**：取消未确认停止按执行异常记录；未知副作用不自动重放。

### FR08 L1 源码可运行性

- **输入**：源码快照、入口、环境、检查范围。
- **规则**：语法检查、适用构建/编译、模块加载或最小启动；不适用项记录原因；区分源码错误、依赖缺失、环境不可达、工具失败与通过。
- **输出**：L1 结果、原始输出、错误位置、退出状态、证据。
- **异常**：L1 失败/阻塞时依赖它的用例阻塞，独立用例继续。

### FR09 L2 函数与模块

- **输入**：既有测试命令或约定入口、输入、断言、环境。
- **规则**：记录命令/入口、输入、断言、实际输出、退出状态、日志、Mock 范围；局部 Mock 通过只覆盖声明范围。
- **输出**：L2 模块结果、证据、Mock 真实性。
- **异常**：缺环境/依赖/数据时阻塞，不伪造通过。

### FR10 L2 接口与集成

- **输入**：接口、环境、凭据引用、请求数据、响应断言、独立存储核验方式。
- **规则**：按业务顺序串联请求，上一步输出作为下一步输入；核对状态、字段、业务规则、模块交互与数据库结果；响应成功不等于业务正确。
- **输出**：请求/响应、业务断言、数据核验、证据。
- **异常**：缺数据库核验能力时显示未完成。

### FR11 Mock 与真实性

- **输入**：开发声明、配置检查、代码候选检查、运行证据。
- **规则**：真实性状态为真实/Mock/混合/未知；绑定版本与环境；静态检查只产生疑点；声明外 Mock 或关键真实性未知不得给真实链路通过。
- **输出**：真实性清单、缺口、影响范围。

### FR12 L3 用户场景

- **输入**：用户角色、业务目标、操作步骤、测试数据、预期结果。
- **规则**：覆盖按钮、分页、跳转、表单、滚动、适用鼠标操作、异常提示与数据展示；同一业务对象贯穿全流程并核对最终持久化；无前端时用接口/命令/智能体完成适用 L3。
- **输出**：L3 步骤、截图/请求关联、业务对象编号、最终结果、未覆盖项。
- **异常**：任一步失败、跳过必需步骤或关键依赖未知，不得判整个流程通过。

### FR13 AI 分析与人工复核

- **输入**：失败事实、原始证据、上下文。
- **规则**：固定结构：观察到的事实、引用证据、可能原因、尚未验证内容、建议下一步；区分已观测失败、候选原因、待验证假设；用户采纳/修改/驳回并留痕；AI 不可用时人工处理继续。
- **输出**：AI 分析修订、复核记录。

### FR14 缺陷与回归

- **输入**：失败步骤、证据、影响范围。
- **规则**：生成草稿，用户确认后提交；分级 P0—P3；可关联修复版本与回归；开发修复说明不能替代复测；关闭需新执行证据；未关闭 P0/P1 阻止验收通过。
- **输出**：问题记录、处置、修复版本、回归结果、关闭依据。

### FR15 链路采集

- **输入**：一次页面操作记录或接口执行记录、请求标识、后端日志、模块调用、数据库结果。
- **规则**：按执行顺序展示节点名称、状态、耗时、脱敏输入输出、证据来源、真实性；未采集/无法匹配显示缺口，不补造；缺少关联标识提示无法可靠关联。
- **输出**：链路节点、证据引用、缺口清单。

### FR16 链路断言与故障定位

- **输入**：链路节点、关键节点业务断言。
- **规则**：断言请求是否到达服务、返回字段、记录是否写入并可查询；展示首个观测异常节点、上游输入与下游影响；首个异常不一定是根因，定位需说明依据与未知范围；可跳转日志、代码位置或缺陷。
- **输出**：节点断言、定位结论、候选原因、未知范围。

### FR17 报告与验收

- **输入**：范围、源码/环境/GitHub 版本、规则、L1/L2/L3 结果、Mock、问题、未验证项、证据索引。
- **规则**：报告修订冻结输入；测试完成与验收通过分列；缺证据时 AI 只能生成说明或草稿；导出 Markdown；凭据不进导出。
- **输出**：报告修订、导出、验收意见。

### FR18 变更提示与回归建议

- **输入**：任务/源码/接口/依赖变化、GitHub 变更、模块依赖。
- **规则**：按已登记模块依赖提示受影响用例；人工可增加或排除并保留理由；AI 建议只作辅助。
- **输出**：待回归清单、理由、关联用例。

### FR19 Trae 编辑器接入

- **输入**：Trae 扩展、面板、核心连接。
- **规则**：安装、启用、停用、升级、卸载；面板与工具同源；多目录明确当前项目；关闭编辑器不等于取消执行；停用/卸载展示活动运行与未提交材料；重开查询原运行。
- **输出**：项目绑定、运行视图、导出。
- **异常**：宿主版本不兼容、核心缺失、连接失败给出具体原因。

### FR20 环境适配与连接恢复

- **输入**：Windows 11 x64、Trae、Python 3.11+、模型 API、GitHub、被测环境。
- **规则**：分别展示编辑器到核心、模型、GitHub、被测环境的连接状态；自检区分 DNS、网络、TLS、配置、能力缺失；断连保留最后确认状态；重连先查询原运行/提交；有副作用且结果未知不自动重放。
- **输出**：连接状态、自检结果、恢复记录、缺口。
- **异常**：不通过关闭证书校验绕过错误。

### FR21 本地存储、备份与恢复

- **输入**：工作空间、业务记录、证据、报告、问题。
- **规则**：文件工作空间；单写锁；业务记录/证据/报告/问题永久保存；不做自动清理/删除入口；备份形成可校验快照；恢复核对记录、引用与附件；只支持当前格式，旧格式拒绝并提示导出/重建。
- **输出**：记录、备份清单、恢复结果、缺口。
- **异常**：空间不足停止接纳新增字节，不驱逐历史。

## 4 验收场景

以下为一期验收场景。每条都需要实际输入、步骤、版本、原始证据与预期对比；定义接口或截图不能代替实际执行。旧 35 条 AC 不再作为唯一基线。

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| AC01 | 建立含两个依赖模块的项目，关联任务、交付与源码 | 同一项目编号在各入口一致；摘要变更不覆盖原交付 |
| AC02 | 一条验收项追溯到交付版本、用例、执行结果与验收意见 | 未关联证据的验收项显示待验证 |
| AC03 | 提交缺少运行说明和版本的交付 | 提示必填，不推进为可验收 |
| AC04 | GitHub 检查通过但业务断言失败 | 保留业务失败，两类检查分列 |
| AC05 | 同一用例按两个规则版本执行 | 可分别查看规则内容；未执行不得记为通过 |
| AC06 | 生成含正常/边界/异常用例的计划 | 人工确认前为草稿；缺预期/前置条件不得发布 |
| AC07 | 从失败步骤重试并补充证据 | 旧尝试保留，新尝试成为当前，不伪造通过 |
| AC08 | 注入语法错误、入口加载失败、缺依赖 | L1 分别给出源码失败/环境阻塞；依赖用例阻塞 |
| AC09 | 模块测试使用声明 Mock 并通过 | 显示“通过，使用 Mock”，不计真实集成通过 |
| AC10 | 接口返回成功但数据库无记录 | 业务断言失败，报告不显示真实业务通过 |
| AC11 | 关键函数使用未声明模拟实现 | 提示疑点或风险；无法核验显示未知 |
| AC12 | 工单创建→分页查询→详情→改状态→重新进入 | 同一工单贯穿 L3，最终持久化独立核对；缺步骤不得通过 |
| AC13 | 缺少后端日志时 AI 给出具体根因 | 作为待验证假设；人工可驳回并留痕 |
| AC14 | 缺陷修复后复测仍失败 | 保留修复版本与复测记录，问题回到处理中 |
| AC15 | 一次请求有请求标识和后端日志 | 能关联日志、模块调用与数据库结果；缺口明确 |
| AC16 | 缺少关联标识或节点未采集 | 提示无法可靠关联，不拼接为同一调用 |
| AC17 | 人为制造后端校验失败 | 展示首个异常节点、上下游与证据，不把首错当根因 |
| AC18 | 报告同时有通过、失败、阻塞、未执行 | 计数准确，未执行不计通过，导出可定位记录 |
| AC19 | 修改被多个用例依赖的模块 | 提示待回归；人工增删并保留理由 |
| AC20 | 在支持的 Trae 环境安装、绑定、执行、导出 | 工具与面板结果一致；停用/升级/重开不丢可靠记录 |
| AC21 | 不兼容宿主版本、Python 运行时缺失、能力缺失 | 分别报告缺项，不宣称可用 |
| AC22 | 执行中断网或关闭重开 Trae | 保留最后确认状态，重连查询原运行；不盲目重放 |
| AC23 | 取消后执行器未确认停止 | 不伪造已取消；按执行异常/阻塞记录并保留原因 |
| AC24 | 备份后恢复工作空间 | 记录、引用、附件可核对；缺口如实显示 |
| AC25 | 业务记录、证据、报告、问题长期保存 | 无自动清理或删除入口，占用可查 |
| AC26 | Python 3.11 与 3.13 环境运行核心与面板 | 支持范围内行为一致；3.14 未验证需明示 |

## 5 未覆盖与后置

- 统一账号、上传、共享查询与跨账号审核：后置，不在一期 AC。
- 计划许可账本、逐动作授权、证据等级：不实现。
- 自动点击捕获、浏览器回放、跨服务/函数级追踪：二期。
- 其他编辑器与操作系统组合：二期。
- 生产部署、合并冲突、无人审核自动修复：不做。
- 真实平台对拍、真实外部业务系统：未验证，不登记通过。
