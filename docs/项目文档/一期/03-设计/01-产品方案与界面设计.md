# 产品方案与界面设计（一期）

> 状态：2026-11-16 设计基线（D3）。契约见[CLI 与数据契约](03-CLI与数据契约.md)；需求见[需求规格](../02-需求/02-需求规格.md)。

## 1 设计原则

1. **正常路径少点击**：选目录 → 选目标 → 确认执行 → 看报告，四步内完成。
2. **AI 先给结果，人再改**：不让人从空白表单开始。
3. **事实与判断分开展示**：结论、覆盖、Mock、AI 分析各有位置，不混成一句话。
4. **不知道就写不知道**：缺证据、未执行、判不出，都用明确文案，不用绿色掩盖。
5. **面板只读 CLI**：不重算结论、不直接写业务文件。

## 2 信息架构

Trae 侧边栏一个入口，面板内分五个区：

```text
测试面板
├─ 项目       当前项目、模块、目标、历史运行
├─ 本次测试   目标 → 范围 → 计划 → 确认 → 运行
├─ 结果       结论、覆盖、用例、证据、AI 分析
├─ 问题       列表、详情、处置、回归
└─ 设置       环境自检、模型、GitHub、服务与链路配置
```

首次使用只有“项目”和“设置”；建项目后出现“本次测试”。

## 3 关键流程

### 3.1 首次使用

```text
[选择项目目录]
   → 检测环境（Python / 模型 / gh）
       ├─ 缺低风险项：自动修复并显示结果
       └─ 缺高风险项：显示命令，等人处理
   → 生成项目档案（模块、关系、运行命令）
   → 给出 3—5 条目标候选
       ├─ 选一条 → 进入范围
       ├─ 改一句 → 进入范围
       └─ 自己输入 → 进入范围
```

### 3.2 一次测试

```text
目标
 → 范围（全部适用 / 自选；先模块，可选层级；显示 S/M）
 → 计划预览（用例数、层级分布、每项的预期）
 → 执行前确认（环境、凭据、副作用、将安装依赖、预计耗时）
 → 运行中（用例进度、当前步骤、证据滚动）
 → 结果（结论 + 覆盖 + 失败 + 分析）
 → 报告（导出 / 填验收意见）
```

### 3.3 失败后

```text
结果页
 ├─ 失败用例 → 证据（脚本、输出、截图、请求）
 ├─ AI 分析（四段；不合格不显示）
 ├─ 问题（自动生成，按签名去重）
 └─ 重跑（按验收项新建运行）
```

### 3.4 中断与恢复

```text
重开面板
 → 读取 run.json
   ├─ running：显示进度与心跳时间
   ├─ interrupted：显示“执行中断”，保留已完成用例
   ├─ cancelled：显示取消时间与未完成范围
   └─ completed：进入结果页
```

## 4 页面清单

| 页面 | 目的 | 主要动作 | 空态 / 失败态 |
| --- | --- | --- | --- |
| 项目 | 选目录、看项目档案 | 新建、切换、更新模块 | 无项目：引导选目录 |
| 目标 | 选或输入本次目标 | 选候选、改一句、自定义 | AI 不可用：直接输入 |
| 范围 | 选验收项 | 预设、模块/层级筛选、勾选 | 无适用项：提示补验收项 |
| 计划 | 看用例与预期 | 编辑、重新生成、发布 | 生成失败：手写或导入 |
| 确认 | 执行前最后检查 | 确认、取消 | 缺确认：按钮不可用并说明 |
| 运行中 | 看进度与控制 | 取消、查看证据 | 心跳丢失：标中断 |
| 结果 | 看结论与覆盖 | 查看用例、导出、填意见 | 无证据：标缺口 |
| 问题 | 处理问题 | 确认、处置、重跑、关闭 | 无问题：显示“本次无失败” |
| 设置 | 环境与配置 | 自检、修复、配置 | 缺项：分项列出 |

## 5 状态与反馈

| 状态 | 展示 |
| --- | --- |
| AI 生成中 | 骨架屏 + “AI 正在生成”，可取消 |
| AI 不可用 | 黄色提示 + “改用手动”，不阻塞后续 |
| 运行中 | 进度条 + 当前用例 + 心跳时间 |
| 中断 | 红色标记 + “执行中断，已完成部分保留” |
| 已取消 | 灰标 + 取消时间 + 未完成范围 |
| 证据截断 | 文件名旁标“已截断” |
| Mock 未知 | 真实性列显示“未知”，悬浮显示原因 |
| 模型分析不合格 | 显示“分析不合格”，不展示半截内容 |

## 6 文案规则

- 不用“完成”描述未验证的事；用“已执行”“已生成”“待验证”；
- 数字必须带分母：`6/8 验收项`，不写“大部分通过”；
- 失败与阻塞分开写；
- 缺少能力时写“未配置/未安装/未验证”，不写“暂不支持”了事；
- 结论词只出现在“结论”区，AI 摘要里不出现。

## 7 交互细节

- 范围选择记住上次的模块筛选，不记住勾选；
- 计划预览默认展开失败风险高的层级（L2 接口、L3）；
- 确认页把“将安装依赖”和“明显副作用”放在最上面；
- 运行中取消需二次确认，说明“已完成的用例会保留”；
- 报告导出前提示是否包含证据；
- 所有长操作显示可取消，取消后说明停在哪一步。

## 8 面板与 CLI 边界

- 面板通过 CLI 取数与触发动作，不直接读写工作空间文件；
- 面板展示的结论、覆盖、Mock 状态均来自 CLI 输出；
- 面板不实现判定、计数、真实性与范围计算；
- 轮询运行状态：运行中 2 秒、空闲 10 秒。
