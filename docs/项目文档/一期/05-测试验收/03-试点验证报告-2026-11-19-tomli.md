## 5 是否可正式投入使用

**当前结论：可以进入受限试点，不建议直接全量正式启用。**

已经具备：

- 本地优先、可追溯的运行/证据/报告链路；
- 明确的四值结论和 `S/M` 范围口径，未完成不冒充通过；
- 真实模型、真实项目、真实脚本执行的成功路径；
- 失败可重跑，报告可导出。

正式启用前仍缺：

1. **更多项目类型**：至少再覆盖 2—3 个不同布局（根包、多包、Node/前端）和不同测试框架，确认不是 tomli 特例。
2. **失败与恢复路径**：依赖缺失、脚本超时、worker 中断、运行中取消、模型不可用、GitHub 不可用。
3. **真实 GitHub / 备份恢复 / 链路断言 / 交付读取**：目前未纳入本次试点。
4. **安全与凭据**：模型 key 只在本机用户配置；需要确认企业环境的密钥托管、轮换、审计与日志脱敏。
5. **规模与并发**：单项目、单任务、单 worker；未验证多项目并发、长运行和磁盘增长。
6. **回归基线**：把 `src/` 布局修复纳入发布版本，并用 CI 固化；当前修复已通过单测，但需要进入下一次全量构建/安装验证。

建议准入标准：完成上述 1—4 的多项目试点并留存证据；对 5 做一次受控压测；对 6 完成带修复版本的 VSIX 重装和全量回归后，再给出“可正式投入使用”的结论。
