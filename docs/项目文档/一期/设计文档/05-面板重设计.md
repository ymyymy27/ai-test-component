# 一期设计05：面板重设计（编辑器原生）

版本：0.1；日期：2026-11-09  
状态：**已实现视觉与信息架构；功能仍复用同一核心合同**。本文件记录面板作为编辑器插件的界面重设计，不替代需求、功能、架构与原有设计分册。

## 1. 定位

面板不是网站，也不是营销页。它运行在 Trae/VS Code 的侧栏或编辑器标签页里，用户正在写代码、看 diff、跑测试。

设计目标：

- **像编辑器的一部分**：紧凑、扁平、信息密度高，遵循宿主主题 token；
- **先给下一步**：打开就知道现在能做什么；
- **不抢代码的注意力**：没有大 hero、没有渐变营销卡片、没有大幅留白；
- **一屏能扫完**：项目、状态、下一步、待处理、计划、报告按顺序纵向排列；
- **侧栏优先**：320px 宽仍可用；编辑器标签页只做更宽的同一视图。

## 2. 信息架构

顶层只保留六个入口：

| 入口 | 职责 |
| --- | --- |
| 首页 | 当前测试状态、下一步、待处理、计划与最近报告 |
| 工作台 | 步骤、当前尝试、授权、执行、核验、证据 |
| 计划 | 计划修订、范围、用例与覆盖 |
| 报告 | 报告、覆盖收据、问题与导出 |
| 设置 | 模型配置档、材料范围、项目连接 |
| 诊断 | 核心能力、只读查询、事件流、原始回执 |

侧栏用横向标签条；编辑器标签页用左侧窄导航栏。导航不承载业务状态，状态仍在页面内容里。

## 3. 页面结构

### 3.1 顶栏

- 一行项目选择器：状态点 + 项目名；
- 右侧只保留“新建测试”“更多”；
- 第二行是连接/模型状态，低对比度；
- 项目详情展开后显示项目编号、新建测试和连接管理。

### 3.2 首页

纵向区块，用分隔线而不是卡片：

1. 当前测试：标题、档位/驱动、控制状态、业务结论、下一步；
2. 下一步：唯一主按钮 + 次级入口；
3. 待你处理：待人工、待核验、阻塞、依据过期；
4. 执行工作台：有运行视图时才显示；
5. 测试计划：打开计划与用例；
6. 最近报告：读取最近报告 / 完整报告列表；
7. 状态栏：核心连接与等待状态。

### 3.3 向导

- 四步紧凑 stepper：选择项目、模型 API、测试环境、核对计划；
- 表单最大宽度收窄，标签在上、输入在下；
- 技术字段折叠，不默认展示；
- 主按钮在右下，取消/返回在左。

### 3.4 详情页

- 左上“返回本次测试”；
- 标题 + 可选上下文行；
- 内容按 `工作台部分` 分隔，不套大卡片；
- 证据正文使用等宽/可选中块，限制高度；
- 表格只在宽度足够时显示，窄侧栏用文字行。

## 4. 视觉规则

- 只使用宿主 CSS 变量：`--vscode-*`；
- 圆角 4–8px，扁平边框；不使用阴影卡片；
- 主色只用于主按钮、当前标签、链接和焦点；
- 状态色只表达运行/暂停/失败/未完成；
- 字号 10–16px；正文 12px，标题 14–16px；
- 不使用外部字体、图片、图标库；
- 不使用大 hero、渐变营销背景、居中大留白；
- 支持 `prefers-reduced-motion`。

## 5. 实现

- 旧面板源文件整体删除，新面板从 `src/index.ts` 与 `src/styles.ts` 重写；
- 新面板只依赖宿主协议：`dispatch`、`writeDispatch`、`controlledDispatch`、`wizard*`；
- 页面：首页、运行、计划、报告、设置、诊断；
- 向导：选择项目 → 模型 → 审查 → 一次发布 → 准备/登记；
- 运行页：读取运行、步骤选择、开始/暂停/继续/取消、准备执行、授权、执行、核验；
- 设置页：模型配置档读取/切换/保存、密钥引用；
- 旧面板的批量授权、证据正文、问题详情、工作流 JSON 表单没有搬入新面板；核心能力仍可通过 CLI/MCP 使用。

## 6. 验证

- 新面板 3 项 Playwright 冒烟通过；
- `tsc --noEmit` 通过；
- 320px 侧栏与 1100px 编辑器标签页截图核对；
- 未修改核心协议、动作白名单或业务判定。

## 7. 边界

- 本次是视觉与信息架构重设计，不是功能重写；
- 真实 Trae/Tk 宿主内的最终字体、缩放和主题差异仍需真实环境复核；
- 面板不重算判定、覆盖、证据等级或授权状态。
