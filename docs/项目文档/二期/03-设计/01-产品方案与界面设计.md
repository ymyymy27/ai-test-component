# 产品方案与界面设计（二期）

> 适用期次：二期；主责：二期新增页面与动作的呈现；状态：规划稿，页面行为不构成验收结论
>
> 本册只写增量。基础面板、首次向导、计划与工作台、三段信息区的布局与文案由[一期界面设计](../../一期/03-设计/01-产品方案与界面设计.md)维护；判定与统计只读一期 DTO，界面不另算。

## 1 增量原则

- 一期三段（运行前／运行时／运行后）**结构不变**；二期在同一面板内增加“历史记录”入口、配置页的环境自检可视化和运行后视图的图联动。
- 信息区只读，动作放在独立操作区；操作区通过核心用例发起检查、导出与跳转，不直接写业务文件。
- 新增页面的成功标准是“让已有事实可读”，不是增加指标：不出现排行榜、通过率看板、历史删除入口。
- 宿主能力缺失时给替代入口（路径文字、命令或 CLI、手动配置），不以空白页或静默失败代替说明。

## 2 历史记录页

回答一个问题：**这个代码版本之前验到什么程度。** 按代码版本分组，不按运行编号排列。

### 2.1 分组与行

- 分组键是完整源码身份：Git 提交 + 未提交差异 + 排除规则，或 plain 文件清单摘要；不出现仓库/提交空字段来假装分组。
- 组头显示范围、环境、规则/验收/模板与判定策略条件；同一提交的不同 diff、范围或环境不得合并成一个绿灯。
- 行只显示：记录时间、档位与驱动、业务结论、证据等级或“未打分”、必测完成数与跳过数。
- 同一运行的多份报告修订默认显示最新并可展开历史；点击行载入该次运行的运行后视图（只读），明确标“历史视图”。
- 当前完整验证尚未完成或已取消时，组头显示“重新验证/未完成”，上一次结果仅作历史参考。

### 2.2 筛选与分页

- 筛选区提供源码分组、范围、环境、档位、业务结果；条件变化取得新游标，翻页保持同一提交快照。
- 先读源码组摘要，展开时再读组内运行与报告修订；不一次性加载全部附件。
- 有筛选时明确标“筛选结果分页”，不冒充完整源码组。

### 2.3 线框与空态

```text
历史记录 / 工单系统
筛选区：源码分组 | 范围 | 环境 | 档位 | 业务结果
-----------------------------------------------------
源码 abc1234 + diff8f3c…（或 plain:清单9f21…）
  范围：状态修改 / 环境E2 / 规则R3 / 模板T2
  当前完整验证：未完成（本轮取消）；旧通过仅作历史
  记录时间   完整验证/计划驱动   未完成/C   完成11/12 跳过0
  记录时间   快速检查/计划驱动   所选通过/未打分
  同一运行：报告修订4（共3个修订，可展开）
操作区：[查看所选运行] [查看报告] [返回当前检查]
```

- 无历史时显示“尚无已保存运行”及原因；索引缺失或损坏显示“历史索引需恢复”并给出入口，不展示空历史冒充无记录。
- 历史选择属于界面上下文，不写回当前结论记录；返回当前检查时重新读核心的最新状态。

## 3 设置·环境自检

配置页在既有设置项旁增加环境自检展示，动作“重新检查环境”调用核心既有维护用例；页面不自行探测、不改配置、不绕过存储不可写守卫。

| 分组 | 显示 | 下一步 |
| --- | --- | --- |
| 依赖环境事实 | 当前方式、对应环境修订、是否解析成功 | 查看或配置环境；未使用 venv 不等于失败 |
| 运行时与依赖 | 解释器版本、依赖可用性、具体缺项 | 定位配置或依赖说明 |
| 被测目标与数据 | 可达性、部署身份、数据准备/复位及未核实项 | 处理关联目标，不把探测成功当业务通过 |
| 模型连接 | 启用/未配置/可用/失败及原因 | 测试连接或关闭 AI，人工流程继续 |

- 宿主能力另列：面板、MCP 登记、文件跳转、目录权限与工作区信任，不混入环境四项。
- 显示已检查、失败与未知项；未检查项不显示通过。模型不可用只影响依赖模型的 AI 动作。
- 数据目录不可写时明确哪些动作不可用，并把“查询已有产物”与“创建新导出”分开说明。

## 4 运行后·图与定位联动

### 4.1 图区域

```text
运行后 / 范围：工单状态修改 / 本轮未完成
操作区：[生成/查看图] [查看所选缺口] [导出图]
-----------------------------------------------------
依赖图 / 链路图    来源运行与图修订
画布：已采集业务节点、真实边、缺口标记
详情：节点ID、来源修订、断言/真实性、证据与已知位置
操作区：[打开证据] [打开执行快照] [校验并打开当前文件]
布局编辑：[保存布局与注释] [取消编辑]
```

- 缩放、搜索、聚焦只操作视图；画布同时提供节点列表作为键盘入口，缺口不能只靠鼠标悬浮读取。
- 点击缺口优先定位同源链路节点；没有对应节点时打开证据详情并保留缺口标记，不捏造节点。
- 单模块无依赖边时只隐藏“不适用”的依赖图，实际链路仍可查看。
- 保存布局前由核心校验事实节点、边与缺口；拒绝篡改时保留用户未保存布局并说明原因。

### 4.2 定位动作

- 默认动作是“打开执行快照”；“校验并打开当前文件”是显式动作，不在打开页面时自动发生。
- 元数据相同显示“当前内容尚未核实”，不给已确认图标；哈希不一致时提示重新固定源码或查看旧快照，绝不直接跳到变化后的行。
- 当前文档有未保存修改时显示“当前文档未保存，无法确认与快照一致”，提供只读快照入口和“保存后重新校验”，插件不自动保存。
- 六态文案与判定由[定位架构分册第 1 节](../04-架构/03-源码定位与行内标注.md#1-用例与六态)维护，界面不自行推断未知状态。
- 行内标注展示本行问题、Mock 声明与证据缺口；只读展示，不修改代码、不触发新工具。

## 5 空态、迟到响应与验收映射

| 情形 | 界面行为 | 对应验收 |
| --- | --- | --- |
| 无历史/记录缺失 | 空态说明原因，不填空行、不显示推测值 | P2-AC07 |
| 索引损坏 | 显示“历史索引需恢复”，保留已保存材料；不前端全盘扫描 | P2-AC07 |
| 无图或缺节点 | 保留统计与缺口入口，缺口回到证据详情 | P2-AC08 |
| 自检某组未知 | 只把该项标未知，不抹掉已确认结果，不显示通过 | P2-AC08 |
| 目录切换后迟到响应 | 只更新原项目缓存并标“非当前视图”，不进入当前页 | P2-AC03/09 |
| 宿主缺能力 | 给路径/CLI/手动配置等替代入口，并说明缺项 | P2-AC06 |

历史返回保留筛选与展开项；查看旧运行不覆盖当前活动运行；图与定位结果按项目、绑定与快照修订核对后才会显示。
