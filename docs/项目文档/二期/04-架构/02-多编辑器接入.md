# 多编辑器接入

> 适用期次：二期 P2-FR01；主责：入口适配、面板宿主、多入口单写；状态：规划稿，未实现、未验收
>
> 本册负责“同一套能力在更多编辑器里可用”。新增编辑器复用核心、DTO 与判定，不建立第二套记录格式；Trae 为一期基线，宿主协议与保活合同见[一期 Trae 接入](../../../归档/系统级文档-2026-11-16/06-Trae接入.md)。

## 1 接入检查清单

每个宿主必须完成下表各项；成功和降级都保留真实输入、输出与版本证据。

| 责任 | 宿主须完成 | 共享内容 |
| --- | --- | --- |
| 命令映射 | 安装、菜单与快捷入口映射到明确动作与参数 | `contracts` 动作语义与错误码 |
| 项目上下文 | 打开、切换、多根目录事件映射 `project_id` 与 `binding_revision` | 核心项目记录；不能按目录名自建业务键 |
| 面板宿主 | 加载同一 Web Component、CSP、Schema 与净化渲染 | `resources/panel/` 唯一源码 |
| 工具配置 | 按宿主方式登记 stdio MCP 或指导手动配置 | 固定 relay、绑定在参数中、无密钥 |
| 定位装饰 | 消费 `LocationDTO` 与标注内容 | `application/locations` 输出 |
| 能力上报 | 上报实例、版本、能力项与调用失败事实 | 核心校验后保存能力状态（见[能力降级与诊断](05-能力降级与诊断.md)） |
| 生命周期 | 断开订阅、清理自登记、升级时协商版本、卸载保留数据 | 单核心与一期保活/退出合同 |

- 各 `integrations/<editor>/` 目录互不 import，也不借用对方构建产物；共同类型进入 `contracts`。
- 新增定位、图与能力上报动作通过能力声明开放；未知动作明确拒绝，不猜测参数。
- 临时 CLI 替代不能证明该宿主面板已支持；接入验收逐项记录通过、失败、不适用及原因。

## 2 接口层不变、入口可变

| 项 | 是否随编辑器变化 | 说明 |
| --- | --- | --- |
| 应用 DTO 与动作名 | 既有语义不变，允许兼容新增 | 面板、CLI、MCP 与各编辑器共用同一批动作 |
| 判定、统计、结论上限 | 否 | 由一期领域层唯一计算 |
| 记录格式与编号 | 既有记录不变；新增投影与能力状态记录 | 见[架构总览第 4 节](01-架构总览.md#4-新增记录与字段兼容) |
| 命令注册、事件 API、Webview 宿主 API | 是 | 由入口适配处理 |
| 面板宿主容器 | 是 | Web Component 不变，宿主适配不同 |

```text
interfaces/local/            # 沿用一期；按能力协商增加动作路由
  api.py · pipe.py · editor_host.py
integrations/<editor>/       # 每个新编辑器一个目录，互不引用
  src/                       # 命令注册、目录事件、面板宿主、工具登记
resources/panel/             # 唯一一份面板源码，被所有编辑器复用
```

- `LocationDTO` 与图 DTO 只经 `contracts` 暴露；入口不解析记录文件，也不读取存储裸路径。

## 3 多入口时序与单写

- 第二入口先做实例握手，再核对自己的项目与绑定修订；相同持久业务意图只得到原运行结果。
- 能接入现有核心就接入；实例不一致或无法接入时返回 `WORKSPACE_IN_USE`，不启动第二个写入者。
- 第二个、第三个入口共用同一 OS 锁持有者；版本不兼容不得以“兼容旧核心”为名另起写入者。
- 所有入口复用一期入口的受控用户确认来源与挑战核对；MCP 或 agent 请求不能映射为用户点击，同一 OS 用户身份不能替代人工确认。
- 面板、CLI 与各编辑器不得各自启动单写循环或重试循环；重试资格与间隔由 `connectivity` 统一提供。

## 4 目录切换、迟到响应与生命周期

- 切换目录时先关闭旧订阅再取新快照；原项目的活动运行继续并保留导航，不能把两套记录拼进同一视图。
- 项目或绑定切换后，原请求的迟到响应只更新原目录缓存并标“非当前视图”，不进入新项目页面。
- 可读源码与可写数据空间分别核对；源码只读但数据目录可写时，仍可固定到可写工作目录执行与物化，不修改源仓库。
- 数据目录不可写时禁止新运行与新导出登记，已有记录仍可查询；导出仅在无需登记新产物的只读获取路径可用。
- 工作区信任不足时，不自动执行项目命令、不自动加载项目 MCP 配置，并说明宿主的信任设置步骤。
- 停用或卸载前保存检查点与未保存材料；直接卸载不依赖停用回调，业务记录与证据保留。

## 5 验收映射

| 验证主题 | 关键检查 | 场景 |
| --- | --- | --- |
| 记录一致性 | 同一操作在新编辑器与 Trae 产出相同 DTO 与相同判定结论 | P2-AC01 |
| 目录与绑定 | 多目录切换不串项目；绑定修订一致 | P2-AC09 |
| 单写 | 第二、第三入口不产生第二写入者，全部接入同一核心或被拒绝 | P2-AC09 |
| 缺能力降级 | 宿主缺面板、跳转或工具登记时给替代入口 | P2-AC06 |

新增编辑器的实测结果写入兼容清单（见[操作系统与运行时兼容](06-操作系统与运行时兼容.md)）；未实测组合不得声明通过。
