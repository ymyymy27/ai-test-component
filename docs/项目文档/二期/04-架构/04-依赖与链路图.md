# 依赖与链路图

> 适用期次：二期 P2-FR04；主责：图来源与身份、定义与修订、渲染导出、事实守卫；状态：规划稿，未实现、未验收
>
> 本册负责把已提交记录渲染成可交互图件。图是**记录的投影**：不新增未采集的节点，不改变测试事实，不参与判定。定位与跳转见[源码定位与行内标注](03-源码定位与行内标注.md)，存储与提交见[一期存储与恢复](../../一期/04-架构/05-存储与恢复.md)。

## 1 图来源与身份

| 图 | 数据来源 | 节点与边 | 本期归属 |
| --- | --- | --- | --- |
| 依赖图 | 项目的模块与依赖边 | 节点＝`module_id`；边＝使用者 → 提供者 | P2-FR04，必须实现 |
| 链路图 | `TraceNode` 与证据引用 | 节点＝实际 `(run_id, attempt_id, trace_node_id)`；边＝实际采集的父子或请求关联 | P2-FR04，必须实现 |
| 问题关联图 | 问题与回归关联 | 节点＝问题与执行；边＝复现与回归关系 | 后续探索，不作为本期必交 |

- 源码路径与符号只是导航附加属性，不是调用节点身份；不同实际调用不因函数同名合并。
- 缺少采集的位置以**已知业务范围的缺口项**挂出，点击回到证据详情，不创建虚构调用节点。
- 单模块项目没有依赖边时，依赖图返回“不适用”并说明原因，不生成空图、不报错；实际业务链路仍按证据显示。

## 2 定义、修订与报告引用

| 记录 | 核心内容 |
| --- | --- |
| `DiagramDefinition` | 图编号、类型、精确来源集合 `[{record_type, record_id, content_revision}]`、投影策略版本、投影时间、事实节点/边/缺口集合 |
| `DiagramRevision` | 定义修订引用、坐标、折叠、独立注释、生成来源、`schema_version`、导出引用 |

- 两类记录是**投影记录**，按不可变修订经 `WorkspaceUnitOfWork` 提交，编号与修订空间独立于领域记录；**不参与判定、不计入统计分母**。
- 报告对图的引用写在附件索引中（`diagram_definition_rev` + `diagram_revision`），不进报告必需字段；缺失时报告照常可读，只标“图件引用缺失”。
- 图修订只改变布局、折叠与注释；新布局不自动升级报告，已有报告继续引用其冻结的图修订。
- 用户明确选择新图纳入报告时，按一期报告规则生成新内容修订；旧报告仍指原图，原始记录与判定不变。

## 3 编辑与事实守卫

- 人工编辑仅允许布局、折叠与独立注释；保存前逐 ID 核对事实节点、事实边、状态与缺口集合，**删除或同数量替换均拒绝**，不能只检查缺口数量。
- 不能新增未采集节点或调用关系；人工补充事实须先采集证据或执行生成新来源，再重新投影。
- 来源记录变化使旧图整体过期，旧修订仍可查看并标“基于旧来源”；重新生成时仅对仍存在的业务 ID 沿用可匹配布局，不偷偷用推断补齐旧图。
- 标签与注释按文本净化，不执行脚本；导出即使折叠也保留完整缺口清单。

## 4 渲染与导出

- 面板消费图 DTO，不用 iframe 加载完整 HTML；独立 HTML 只加载内嵌或包内资源，不访问外部 CDN、不含凭据。
- 支持缩放、搜索、聚焦与按需展开；节点跳证据或经定位用例跳源码；画布同时提供节点列表作为键盘入口。
- 图视图 DTO 与导出 HTML 来自**同一修订**，字段与缺口一致；导出遵循统一脱敏规则。
- 图渲染失败只影响图件，不隐藏统计、业务结论与缺口入口；原始记录仍可独立查看。

## 5 数据流与保存顺序

| 阶段 | 输入 | 输出与校验 |
| --- | --- | --- |
| 定义投影 | 项目、图类型、来源记录类型/ID/精确修订集合 | Definition 含策略版本与事实节点/边/缺口；来源不齐明确缺口 |
| 初始布局 | 已冻结 Definition | 新 Revision 保存坐标、折叠/注释、生成来源与 `schema_version` |
| 人工调整 | 定义或旧修订、`expected_revision`、允许的布局字段 | 守卫逐项校验事实与缺口集合，拒绝增删改事实 |
| 渲染/导出 | 精确 Revision、统一投影策略 | DTO 与 HTML 同源，产物按摘要存对象，记录经工作单元发布 |
| 报告引用 | 用户显式选择定义修订与图修订 | 生成新报告内容修订，旧报告不动 |

只在请求图时投影，不为每次运行提前生成全部图；已发布的定义与修订永久保留，缺记录时提示缺口，不用推断重建。

## 6 验收映射

| 验证主题 | 关键检查 | 场景 |
| --- | --- | --- |
| 可交互 | 图件可打开、缩放、搜索、聚焦 | P2-AC04 |
| 可跳转 | 节点跳转到对应证据或问题 | P2-AC04 |
| 缺口如实 | 未采集节点保留缺口标记，不用推断补全 | P2-AC04 |
| 修订不改事实 | 布局调整生成新图修订，原始记录与判定不变 | P2-AC05 |
| 落盘与归属 | 经工作单元提交、编号独立、不参与判定与分母；报告精确引用图修订 | P2-AC05 |
| 拒绝篡改 | 缺少原定义缺口标记或删除事实边/节点的修订被拒绝并说明原因 | P2-AC05 |
| 导出安全 | 导出不含密钥，DTO 与 HTML 一致 | P2-AC05 |
| 单模块项目 | 依赖图显示不适用，不生成空图、不报错 | 一期单模块规则 |

验收注入覆盖重复函数调用、无源码的人工节点、删除事实边与缺口、重新布局、来源变更与导出一致性。
