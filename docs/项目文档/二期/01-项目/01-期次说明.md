# 期次说明（二期）

> 适用期次：二期（P2-FR01—P2-FR06 / P2-AC01—P2-AC09）
> 主责：范围、状态、与一期的关系、边界
> 状态：规划稿——P2-AC01—09 全部登记为 `untested`，本文件不表示任一能力可用或已完成真实环境验收

## 1 二期要解决的问题

一期把本地测试闭环限定在 Windows 11 x64、Python 3.11+ 与 Trae。二期在**同一核心**之上扩展使用面：

- 同一套能力在至少一个非 Trae 编辑器和至少一个新桌面系统（macOS 或 Linux）上可用，记录与判定口径不变。
- 从证据、问题和链路节点回到源码位置，并在编辑器内只读标注。
- 把已提交记录的依赖与实际调用链路投影为可交互图件，节点可跳回证据。
- 宿主能力缺失时明确报缺项并提供替代入口，不静默失败。
- 在一期三段信息面板之上增加历史记录页、环境自检可视化与图联动。

| 主题 | 二期处理 |

| 入口、面板宿主、渲染 | 二期新增适配与投影，不引入第二套业务规则 |

## 5 明确不做

- 不做账号、登录、结果上传、回执、共享查询与跨账号审核（属三期或平台项目）。
- 不做自动操作录制与回放、任意语言自动插桩、跨语言静态影响分析。
- 不让任何编辑器插件实现第二套业务规则、记录格式或重试逻辑。
- 不重新定义三段信息面板；不在信息区放动作，不新增判定规则。
- 不交付独立分层结果图；问题关联图属后续探索，不作为本期必交。
- 不扩大被测技术栈的自动执行承诺；技术栈自动执行扩展另行立项。
