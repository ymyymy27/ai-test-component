# 二期设计：历史、自检与图联动

版本：3.3  
更新日期：2026年9月23日  
文档类型：工程设计文档

在[一期界面](../../一期/设计文档/01-面板与工作台.md)上增加历史页、设置自检展示、图联动和源码标注；不改原计划/执行/结果确认语义。

## 1 历史页

按完整源码身份分组：Git提交＋未提交diff＋排除规则，plain文件清单摘要。组内显示范围、环境、规则/验收/模板及判定策略条件，不能把同提交的不同结果合并为一个绿灯。行包含记录时间、档位/驱动、业务结论、证据等级或未打分、完成/适用和跳过数；报告多修订默认最新并可展开历史，无删除入口。

点击载入只读旧运行，明确“历史视图”；当前新full尚未完成/取消显示重新验证或未完成，上一次结果仅历史参考。报告和图引用保持精确修订。

## 2 设置自检

展示依赖环境方式、运行时/依赖、被测目标及数据条件、模型连接，动作“重新检查环境”。宿主面板/MCP/跳转能力另列，不混在环境四项。模型坏只降AI；数据目录不可写禁止运行；目标不可达阻塞关联步骤。依赖环境方式单列；未用虚拟环境不自动降级，具体污染/版本问题按证据规则处理；quick/按需未打分。

## 3 图与定位

运行后增加依赖/链路图区域，支持缩放/搜索/聚焦；缺口点击优先同源节点，无节点跳证据详情并保留缺口。单模块依赖无边显示不适用，业务链路不因此隐藏。图编辑仅布局/折叠/注释，保存不能删事实或缺口。

定位默认“打开执行快照”；“校验并打开当前文件”为显式动作。元数据相同显示尚未核实当前内容，不给已确认图标；哈希不一致提示重新固定或查看旧快照，绝不直接跳变化后的行。大量标注按可视范围和目标文件批量处理，不全仓扫描。

图布局新修订不自动刷新报告；“用此图生成报告新修订”是独立动作，明确不改变测试事实。图导出与面板同源，无平台网络依赖。

## 4 空态与验收

无历史说明无已保存运行；缺图不影响统计/证据；缺宿主能力给路径/CLI等替代。新编辑器复用这些页面，不增加自己的判定。P2-AC03—08覆盖定位、图编辑、自检和历史；多入口目录隔离由P2-AC09验证。

## 5 导航与历史页线框

主导航在一期基础上增加“历史记录”，当前检查、工作台和报告入口沿用。历史选择不改变实际运行，也不改变当前结论。

```text
历史记录 / 工单系统
筛选区：源码分组、范围、环境、档位、业务结果
-----------------------------------------------------
源码 abc1234 + diff8f3c…
  范围：状态修改 / 环境E2 / 规则R3 / 模板T2
  当前完整验证：未完成（本轮取消），旧通过仅作历史
  记录时间   完整验证/计划驱动   未完成/C   完成11/12 跳过0
  记录时间   快速检查/计划驱动   所选通过/未打分
  同一运行：报告修订4（共3个修订，可展开）
源码 plain:文件清单9f21…
  按实际范围和环境展示，不出现仓库或提交空字段
操作区：[查看所选运行] [查看报告] [返回当前检查]
```

无历史显示“尚无已保存运行”；索引可恢复但记录缺失显示具体原因，不填空行假装存在。分页只加载摘要，展开精确修订才取详情。新full开始/取消不回退旧通过，同一提交不同diff或范围不得合并成单个绿灯。不提供排行榜、通过率看板或历史删除。

### 历史记录（二期）

回答一个问题：**这个版本之前验到什么程度。** 按代码版本分组，不按运行编号排。

**动作**：点击任一行切换到"当前检查"并载入该次运行的运行后视图（只读）；没有"删除历史"入口，历史由保留规则处理。

要点：

- **按版本分组**：用户脑子里的问题是"这个版本现在可信到什么程度"，不是"我第 3 次跑得怎么样"。
- 每行只显示：时间、档位与驱动、等级、必测与跳过数。
- **不做排行榜、不做通过率看板**——一旦变成指标就会有人刷指标，而不是补证据。
- 同一版本多次运行时，"最近一次"只用**完整验证**的结果作为该版本的当前结论；快速检查与按需自测列为补充。

## 6 环境自检字段与动作

| 分组 | 显示 | 下一步 |
| --- | --- | --- |
| 依赖环境事实 | 当前方式、对应环境修订、是否解析成功 | 查看/配置环境；不使用venv不等于失败 |
| 运行时与依赖 | 解释器版本、依赖可用、具体缺项 | 定位配置或依赖说明 |
| 被测目标与数据 | 可达性、部署身份、数据准备/复位及未核实项 | 处理关联目标，不把探测成功当业务通过 |
| 模型连接 | 启用/未配置/可用/失败及原因 | 测试连接或关闭AI，人工流程继续 |

操作区提供“重新检查环境”；显示已检查、失败及未知项。自检不自动改配置。宿主能力另列面板/MCP/跳转、权限和信任，避免混成环境四项。数据不可写时明确哪些动作不可用；查询已有产物与创建新导出分开。

## 7 图、缺口与源码详情

```text
运行后 / 范围：工单状态修改 / 本轮未完成
操作区：[生成/查看图] [查看所选缺口] [导出图]
-----------------------------------------------------
依赖图 / 链路图    来源运行与图修订
画布：已采集业务节点、真实边、缺口标记
详情：节点ID、来源修订、断言/真实性、证据和已知位置
操作区：[打开证据] [打开执行快照] [校验并打开当前文件]
布局编辑：[保存布局与注释] [取消编辑]
```

缩放、搜索、聚焦只操作视图；保存布局前核心校验节点、边及缺口，拒绝篡改时保留用户未保存布局并解释。缺trace节点的缺口直接到证据详情，不捏造节点。单模块无依赖边只隐藏不适用的依赖图，实际链路仍可看。

| 定位状态 | 文案与动作 |
| --- | --- |
| unknown | 无法确认位置，展示原因与证据入口 |
| metadata_match | 元数据一致，当前内容尚未核实；可开快照或显式校验 |
| current_verified | 当前干净文档所显示内容已核实与快照一致；绑定文档身份/版本后定位，后续编辑即失效 |
| snapshot_verified | 已核实历史快照；只读打开该冻结内容，不证明当前目录一致 |
| stale | 文件已变化；打开旧快照或重新固定，不按旧行号错跳 |
| missing | 快照或路径缺失；说明哪项缺失，保留原记录 |

图源过期显示“基于旧来源”，新布局仅提示有更新；用户明确用新图生成新报告修订。图件失败不隐藏业务结论/缺口。无宿主跳转能力提供相对路径文字，未确认位置不输出猜测行号。

## 8 刷新、返回与验收

当前文件已有未保存修改时显示“当前文档未保存，无法确认与快照一致”，提供只读快照入口及自行保存后重新校验；不自动保存用户代码。干净文档仍核对请求、宿主、URI、版本、dirty及显示摘要，变化或迟到响应不贴旧标注。完整规则与六态取自[定位合同](../架构文档/02-源码定位与行内标注.md#4-当前编辑器文档与校验请求)，界面不自行推断未知状态。

自检响应按配置修订核对，图/定位响应按项目、绑定与快照修订核对；用户切换后迟到结果不覆盖当前页。历史返回保留筛选/展开项，当前检查读取核心最新状态。图画布提供对应节点列表作为键盘入口，不能只有鼠标悬浮才能读缺口；窄面板详情可切换而非遮住主结论。P2-AC03—09覆盖以上分组、降级、定位、图及多入口行为。

历史行将“完成”明确标为“执行完成”，同时提供“所选有效验证V_S/S及完整必测有效验证V_M/M”和未验证数；全部执行但依据待确认时两数不同，沿一期统计示例。宿主更换不改变人工确认弹层和事件快照边界，图/历史无需第二套授权或统计。

## 统计与恢复沿用

高级历史及跨编辑器面板沿用一期S/M、E/R/V及当前Attempt优先规则；显示复用来源，不把复用显示成本轮执行。读取SnapshotEnvelope及配对游标，从边界之后续读；二期不另算结论或维护第二套复用状态。

## 9 历史查询与索引恢复

历史页先取源码组摘要，展开时再取组内运行与折叠修订，切换过滤条件取得新游标；同次翻页保持commit快照，刷新才读取新根。INDEX_REBUILD_REQUIRED显示“历史索引恢复中/需维护”及原因，不能展示空历史或由前端全盘查找。已保存业务材料与历史报告仍保留。实际查询键由[有限查询合同](../../一期/架构文档/04-存储与恢复.md#13-有限查询与索引键)维护。

## 历史筛选的查询合同

源码组浏览调用history.groups；按范围、环境、档位或业务结果筛选时调用history.runs，四项可组合，source_identity可选，project固定。精确字段为scope_revision、environment_revision、tier、business_outcome；显示名称和修订，不将execution_state当业务结果。有限16种筛选掩码及跨源码/限定源码入口由[存储QuerySpec目录](../../一期/架构文档/04-存储与恢复.md#页面控件与queryspec固定目录)统一承接，不在面板扫描全部记录。

筛选结果按运行分页并附源码组标题，明确标“筛选结果分页”，不冒充完整源码组；无筛选的组浏览按组分页。条件变化刷新游标，列表和字段来自同commit的统一判定摘要；展开旧报告保持其历史结果。P2-AC07验证每个控件和允许组合、跨组查询、状态变更、翻页及索引损坏。

### 动作可用性

降级按[动作依赖矩阵](../架构文档/04-能力降级与诊断.md#2-按动作依赖降级矩阵)统一呈现：可选模型不可用只影响依赖它的动作；被测凭据/运行时缺失阻塞关联执行；核心不可用不能插件查询或新导出，只能普通工具打开已有导出；记录可读不可写仅保留查询。按钮与错误理由使用核心结果，恢复不自动重放未知副作用。
