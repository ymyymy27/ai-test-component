# 接口目录全量整理与受控入口修复

日期 2026-10-15，起点 `fix@86cb554`。范围为全部接口目录文件、6 份现行合同与交付/评审/夹具，以及宿主受控提交路径。不是全项目全量通过，也没有把全部剩余业务缺口写成关闭。

## 修复与清理

1. 修复排队写请求在配置变化后误转发到另一工作空间的风险：面板回传宿主 contextId，宿主在派发前核对当前 scope；缺失或过期拒绝，即使 project_id 相同也不转发。BD-001 升 0.9，总台账升 2.89。旧面板应与 VSIX 同步升级，不能省略字段降级放行。
2. 公共 ExecutionFacts 增加遗漏的 business_failure 校验，并逐场景比较公开交付副本与消费方副本；生成夹具和 Schema 未手改。
3. 同步 6 份合同和 4 份交付说明的当前实现/剩余边界。纠正待裁定索引关于 DEC-010 破坏性改名、DEC-011 未接线、DEC-012 尚待使用的过时状态，保留原裁定记录。
4. 5 份历史评审移入归档，保留作者、日期、回复和意见，调整移动后的链接并统一行尾；路径见 [归档映射](archive-map.json)。有效合同、公共夹具及历史失败均保留，没有可直接删除且无需追溯的材料。目录现存 49 个文件的处理分类与 SHA-256 见 [逐项清单](interface-file-audit.json)。
