## 范围

按 10 张 `editor-test-panel-*.png` 参考图重建 1024×1110 的整窗交互草图，并同步实现真实编辑器侧栏和右侧详情标签页。

## 实现

- 侧栏宽度 300px，活动栏 39px，主背景 `#191b20`、侧栏 `#22252b`、工具区 `#272a31`、边框 `#2b2f37`、主蓝 `#3679d4`。
- 覆盖准备、运行中、暂停、结果、设置五种侧栏状态。
- 覆盖 AI 生成记录、驱动与运行修订、环境与来源、问题草稿、报告查询、变更与回归、报告修订、运行步骤八种详情。
- 复刻全局标题栏、活动栏、编辑器标签、源码区、底部工具区与状态栏，便于逐图对照。
- 详情通过 `openDetail` 消息在编辑器侧边标签页打开；`aitest.openReferencePreview` 直接打开整窗参考图预览。
- `aitest.demoMode` 控制详情标签页是否显示评审夹具，默认关闭。
