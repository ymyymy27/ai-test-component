# 验证档案（现行）

本目录用于新增验证批次。历史批次（40 个 `p1-*`，2026-10-01—2026-10-16）已移入[归档验证档案](../归档/validation/README.md)。

新批次使用 `p1-<主题>-<YYYYMMDD>/`，至少包含：

- `README.md`：版本/提交、输入、命令、预期/实际、证据文件、未验证原因；
- 可复核的结果文件：JUnit/XML、命令回执 JSON、facts/source-inventory 或制品核对结果。

批次之间不累加“通过项”为全量；中断、失败、跳过与未取到回执的结果保留原样。
