## 测试中发现并修复

1. **取消后的提示文案过期**：取消完成并进入结果页后，顶部仍显示“已请求取消，当前用例结束后停止”。现在按刷新后的运行状态显示“本次运行已取消，已完成用例与证据已保留”；仍在运行时才显示“当前用例结束后停止”（`panel/src/state/session.ts`，`session.spec.ts` 新增 1 项）。
2. **演示宿主取消后仍返回未完成**：取消的运行含 2 条失败用例，却返回 `outcome: incomplete`，页面出现“没有有效失败”与失败用例同屏的矛盾。演示宿主改为按实际失败返回 `failed`；真实后端判定逻辑未改。
3. **演示宿主缺少可测路径**：补充 `no-project` 场景、项目切换、`openPath`、取消状态与取消后重跑重置，使浏览器回归可覆盖完整前端路径。
4. **测试脚本发现选择器问题**：模板 `<option>` 不以 visible 状态出现，改为 attached 后选择；属于测试脚本问题，不是产品缺陷。
5. **调整抽屉仍是长表单**：交付、模板、模块三块改为默认折叠，标题右侧显示“未填写/未应用/未生成”或已应用数量，展开后才露出字段与 AI 动作；E2E 相应先展开再操作。
6. **结果页滚动后主操作离开视口**：结果页“再测一次/新目标”改为吸顶；长页面滚到底仍可一键再测。失败用例增加编号，证据卡增加打开箭头，减少“这能不能点”的犹豫。
7. **窄幅设置页命令断词**：`word-break: break-all` 把 `install` 拆成 `inst/all`，改为按词换行。
8. **通过运行仍显示“分析未生成”**：一次整理 `ResultPanel` 时漏掉传给 `AnalysisPanel` 的 `not-needed`，组件单测只能证明面板自身，真实 Trae 才暴露。已补传参并增加“全部通过”的结果页集成测试；`passed-result.png` 与 `real-trae-result.png` 为修复后证据。
9. **同一版本重装后 webview 仍加载旧资源**：扩展给面板资源 URL 加内容哈希查询串（`?v=<index.html sha1>`），重装后无需依赖浏览器缓存猜测；扩展测试断言 js/css 都带版本号。真实 Trae 完全重启后确认新文案与新抽屉生效。
