# 面板设计对照与本轮边界

日期：2026-10-16。依据：[编辑器内面板交互设计草案](../../项目文档/一期/设计文档/02-编辑器内面板交互设计草案.md)。用户要求先完善面板再恢复 Trae 实测，并允许在不降低原设计质量的前提下改进交互。

## 实施方向

采用编辑器原生尺度，继承宿主字体和颜色。独立浏览器检查使用侧栏背景 `#22262c`、输入背景 `#191d23`、正文 `#d5d9df`、说明 `#a6aebc`、边界 `#363b44`、焦点 `#3686d7` 作为后备值；宿主主题变量优先。内容左对齐，紧凑行、树与分隔线组织信息，避免把每个动作做成独立卡片。

```text
AI 测试                      设置 更多
项目入口
模型状态                         配置
──────────────────────────────────
当前测试：状态 / 下一步 / 一个主动作
待处理：需要处理的具体步骤
测试计划：用例与步骤树
测试记录：最近修订与报告入口
──────────────────────────────────
核心连接状态
```

长表单在同面板详情内打开，保留返回路径。向导按项目、模型 API、测试环境、计划核对分步展示；返回上一步保留已填内容。计划预期按检查项展开，避免首次进入同时面对四套表单。

## 已实现的界面调整

| 设计位置 | 本轮调整 |
| --- | --- |
| §3 常驻侧栏 | 顶部移除技术动作数量、连接按钮和横向导航堆叠；保留标题、项目入口、模型状态和四个分组；连接状态放底部 |
| §3.2 待处理 | 以当前步骤序号展示入口，不让用户辨认内部 UUID；证据缺口不再误当作步骤编号跳转 |
| §4 准备 | 无运行时只给开始测试的主入口，不显示不可用刷新和空来源边界 |
| §6 工作台 | 执行操作与结果核验分区；区分步骤状态、本次尝试、过期依据及独立核验；不自动授权或执行 |
| §7 报告 | 业务结论、覆盖统计、原因使用中文层级；内部字段与引用按需展开；导出仍绑定准确修订 |
| §8 设置 | 面板内填写供应方、地址、模型、超时并保存默认配置；密钥通过宿主安全输入与 Windows 凭据存储，正文不进入 Webview |

模型默认配置只用于后续新建测试，不静默修改已有运行。保存检查配置格式与凭据可用性，不冒充网络连接检查成功。首次实际出站仍走核心材料范围确认。

## 尚未达到文档完整实现的部分

本轮没有把界面整理写成产品全部完成：项目入口仍需补齐已保存项目列表与隐藏/恢复；模型连接检查尚无默认可用核心处理器；计划树仍缺业务目标名称及 L1/L2/L3 完整摘要；工作台还需完整证据正文阅读；自动生成可执行测试入口、任意业务环境准备、完整报告查询筛选与 AI 来源记录页仍需继续实施。当前向导只支持已准备的标准库 Python JSON 测试入口。

用户要求的质量基线仍是原设计，以上缺口不得通过删减设计要求或把按钮存在写成验收完成来消除。Trae 执行测试按本轮要求暂停，尚未重新安装此轮面板布局。
