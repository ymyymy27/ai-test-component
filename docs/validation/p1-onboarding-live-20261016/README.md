当前引导面向标准库 Python 本地测试入口；入口须已准备测试场景并输出约定 JSON 字段。输入条件字段是说明，不能宣称插件已经自动生成或执行任意业务测试代码。模型建议仍需用户核对；源码默认不出站。

## 已发现与修复的问题

1. Trae 实测中独立 venv 创建成功，但工作空间目录未创建，核心拒绝启动。补齐目录创建，原工作空间与报告保留。
2. 实测保存项目成功，下一步绑定被核心拒绝：向导漏带受控写参数中的准确项目/仓库修订。绑定、环境和发布同时补齐，核心守卫不放宽。
3. 真实核心组件回归发现源码根范围 `.` 在快照适配器中被拒绝；空范围又不满足 PreparedRun 的非空选择合同。现支持明确的根目录选择 `.`，仅在范围选择中允许，文件名/越界/链接检查保留；新增嵌套文件与新增文件变化检测回归。
4. 取消确认后锁定已排队表单，继续沿用原意图，避免界面输入变化却提交旧队列。
5. 核心确认窗口增加中文操作目的与准确输入摘要，保留完整安全投影及已保存依据。
