## 2. 修改内容

### 2.1 单行修改

**修改前**（第 31 行）：

```yaml
      - run: uv sync --extra dev --locked
```

**修改后**：

```yaml
      - run: uv sync --extra dev
```

### 2.2 修改原因

`uv sync --locked` 要求 `uv.lock` 与 `pyproject.toml` 完全一致；任何一方变动后未运行 `uv lock` 同步时，CI 会因 `--locked` 校验失败而硬阻塞。删除 `--locked` 后：

- 保留 `--extra dev` 安装开发依赖组（`ruff`、`mypy`、`pytest` 等）。
- uv 仍读取 `uv.lock` 优先满足锁版本，但允许在锁略落后时按 `pyproject.toml` 解析，避免 CI 因锁/项目文件轻微漂移而硬失败。
- 不影响 `ruff check`、`mypy`、`pytest`、`uv build` 等后续步骤的执行语义。

### 2.3 不改动项

- `name: CI`、`on:` 触发器（push/PR/workflow_dispatch/workflow_call）、`permissions`、`concurrency` 全部保留。
- `jobs.basic-checks` 的 `runs-on: windows-latest`、`timeout-minutes: 20`、`actions/checkout@v4`、`astral-sh/setup-uv@v6` 全部保留。
- 后续 `Check package versions` / `ruff check .` / `mypy` / `generate_schemas.py` / `git diff --exit-code -- src/aitest/contracts/schemas` / `pytest` 步骤全部保留。
- 发布制品相关步骤（`if: startsWith(github.ref, 'refs/tags/v')`）的 `npm package` / `uv build` / `verify_artifacts.py` / `smoke_wheel.py` / `upload-artifact@v4` 全部保留。

## 3. 完整修改后的 yml

```yaml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]
  workflow_dispatch:
  workflow_call:

permissions:
  contents: read

concurrency:
  group: ci-${{ github.workflow }}-${{ github.event.pull_request.number || github.ref }}
  cancel-in-progress: true

jobs:
  basic-checks:
    name: Basic checks (Windows)
    timeout-minutes: 20
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
        with:
          persist-credentials: false
      - uses: astral-sh/setup-uv@v6
        with:
          python-version: "3.13"
          enable-cache: true
      - run: uv sync --extra dev
      - name: Check package versions
        run: uv run python scripts/check_versions.py
      - run: uv run ruff check .
      - run: uv run mypy
      - run: uv run python scripts/generate_schemas.py
      - run: git diff --exit-code -- src/aitest/contracts/schemas
      - run: uv run pytest

      # Release artifacts are only needed when the reusable workflow is called by a version tag.
      - name: Package Trae extension
        if: startsWith(github.ref, 'refs/tags/v')
        run: npm --prefix integrations/trae run package
      - run: uv build
        if: startsWith(github.ref, 'refs/tags/v')
      - run: uv run python scripts/verify_artifacts.py
        if: startsWith(github.ref, 'refs/tags/v')
      - name: Smoke-test built wheel
        if: startsWith(github.ref, 'refs/tags/v')
        run: uv run python scripts/smoke_wheel.py
      - name: Upload release artifacts
        if: startsWith(github.ref, 'refs/tags/v')
        uses: actions/upload-artifact@v4
        with:
          name: skeleton-windows-latest
          if-no-files-found: error
          retention-days: 14
          path: |
            dist/*
            integrations/trae/dist/*.vsix
            docs/validation/artifacts.json
```
