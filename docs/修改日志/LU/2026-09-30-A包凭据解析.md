# 2026-09-30-A包凭据解析

## 1. 本次实现概述

补齐 `infrastructure/credentials.py` 占位模块与新增 `contracts/secrets.py`，实现按用途凭据解析与安全管理：仅允许显式登记的环境变量与 Windows 凭据管理器两类来源，无明文工作空间文件回退；凭据值只在受控内存中显式 reveal，默认表示不暴露。

## 2. 新增/修改文件清单

- `src/aitest/contracts/secrets.py`（新增）
  - `ResolvedSecret`：含 purpose/reference/source 元数据，`reveal()` 显式取值、`clear()` 清空，`str/repr` 永不输出值。
  - `SecretPurpose` 一期受控用途（model/http）与 `KNOWN_PURPOSES`。
- `src/aitest/infrastructure/credentials.py`
  - `EnvironmentSecretProvider`：按显式登记的 `(purpose, reference) -> 环境变量名` 解析，不遍历环境。
  - `WindowsCredentialProvider`：ctypes 定义 CREDENTIALW 结构，经 `CredReadW/CredFree` 读取 Generic 凭据（目标名 `aitest/<purpose>/<reference>`），非 Windows 不可用。
  - `SecretManager`（SecretPort 实现）：按用途校验、依次尝试可用来源，提供 `resolve` 与能力探测 `has_secret`；默认装配两类来源。
  - `SecretProvider` Protocol、`SecretUnavailable`。
- `src/aitest/application/ports.py`
  - `SecretPort` 从文档字符串正式化为 `resolve(reference, *, purpose)` 与 `has_secret` 方法签名，返回 `contracts.secrets.ResolvedSecret`。
- `tests/unit/test_a_credentials.py`
  - 新增 11 项单元测试：环境来源解析/拒绝未登记/缺失变量、管理器解析与来源、未知用途拒绝、全来源失败、has_secret、repr 不泄密、clear、默认装配补映射、Windows 提供方可用性与缺失报错。

## 3. 落地的约束清单

- 凭据用途限定为一期登记集合（model/http），未知用途直接拒绝。
- 环境变量必须先显式登记映射，不存在“从环境任意读取”。
- 无工作空间明文文件回退；不写日志/检查点/命令行。
- 默认字符串表示不含值；只能在受控进程内显式 reveal。
- Windows 凭据读取严格类型 Generic，读取后立即 CredFree。
- 端口返回合同 DTO，application 不依赖 infrastructure。
- 不改动 B/C/D 包任何代码。

## 4. 重要备注

- Windows 凭据管理器提供方未做写入/创建（只读）；生产凭据需用户自行登记到系统。
- 未实现内存锁定（页锁定/禁交换）能力；Python 层无法完全阻止解释器内存中的临时副本。
- 尚未接入 HTTP/模型出站的实际调用链（仅提供解析能力）。
