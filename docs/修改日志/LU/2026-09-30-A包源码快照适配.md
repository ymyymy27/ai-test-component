# 2026-09-30-A包源码快照适配

## 1. 本次实现概述

补齐 `infrastructure/adapters/source_snapshot.py` 占位模块，实现文件型 SourceSnapshotPort：真实字节流式 SHA256 固定快照、幂等 snapshot_id、按清单物化并再核对、变化检测；默认排除 .git，支持选定路径与排除规则，拒绝路径逃逸与非空目标覆盖。

## 2. 新增/修改文件清单

- `src/aitest/infrastructure/adapters/source_snapshot.py`
  - 新增 `FileSourceSnapshotStore`：
    - `pin(canonical_path, purpose, selected_paths, exclusion_rules)`：遍历目录，逐文件 64 KiB 流式 SHA256 + 大小，按规则过滤，快照清单原子落盘；身份来自路径+文件真实摘要，同内容同 id（幂等）。
    - `read_pinned(snapshot_id)`：按标识读元数据，不重新扫描。
    - `materialize(snapshot_id, destination)`：按清单复制（自动建父目录）到空目标，复制后逐项重算摘要核对。
    - `detect_changes(snapshot_id)`：重新扫描比对 added/removed/modified；源码目录消失报 unknown，绝不谎称未变。
  - 新增 `SnapshotError`。
- `src/aitest/application/ports.py`
  - `SourceSnapshotPort` 正式化为 pin/materialize/read_pinned/detect_changes 四个方法签名。
- `tests/unit/test_a_source_snapshot.py`
  - 新增 11 项单元测试：真实摘要、幂等、.git 排除、选定路径、读取、物化核对、非空拒绝、未变检测、修改检测、缺失路径、非法 id。

## 3. 落地的约束清单

- 内容身份只来自实际字节 SHA256；mtime 不作为身份证明。
- 快照目录标识校验防注入；路径全部 resolve 后使用。
- 物化只允许空目标；复制后必须字节级再核对。
- 无法证明未变时返回 unknown/changed，不做乐观报告。
- 排除规则按相对路径/目录前缀匹配，默认排除 .git。
- 不改动 B/C/D 包任何代码。

## 4. 重要备注

- 快照文件存于工作空间 `snapshots/`，属永久业务材料，不纳入临时回收。
- 当前固定的是工作目录副本；Git 形态的基准提交身份由 SourceControlPort 承接。
- 大仓库 pin 为一次性全量扫描，未做增量。
