# 2026-09-30-A包Git适配

## 1. 本次实现概述

补齐 `infrastructure/adapters/source_control.py` 占位模块，实现受控 git CLI 的本地 Git 事实（能力探测、仓库身份、工作区变更、本地 upstream 计数）与可选 GitHub HTTPS 只读客户端；plain 形态不注册不调用，Git 不可用不静默转 plain，远端失败只降级不阻塞本地。

## 2. 新增/修改文件清单

- `src/aitest/infrastructure/adapters/source_control.py`
  - `GitSourceControl`：
    - `is_available()`：`git --version` 能力探测并缓存；
    - `is_repository(path)`：rev-parse 判定；
    - `describe(path)`：toplevel/分支/HEAD/origin URL，并解析 GitHub owner/repo；
    - `changes(path)`：`status --porcelain -z` 解析 added/modified/deleted/untracked；
    - `upstream_counts(path)`：基于本地引用 `HEAD...@{u}` 的 ahead/behind，不做网络 fetch。
  - `GitHubRef`：HTTPS/SSH 远端 URL 解析。
  - `GitHubReadOnlyClient`：可选 HTTPS API 只读分支头，失败降级 unavailable。
  - 异常 `GitUnavailable`。
- `src/aitest/application/ports.py`
  - `SourceControlPort` 正式化为 is_available/is_repository/describe/changes/upstream_counts。
- `tests/unit/test_a_source_control.py`
  - 新增 9 项单元测试：可用性、可执行缺失、仓库判定（仓库外目录）、describe 事实、plain 拒绝、untracked/modified 检测、无 upstream、GitHubRef URL 解析。

## 3. 落地的约束清单

- 所有 git 调用为参数列表子进程，无 shell，带超时。
- git 不可用显式报错；调用方不得静默转 plain。
- 远端计数只依据本地已知引用，不隐式联网。
- GitHub API 为可选能力；失败只降级，不阻塞固定/准备/运行。
- 远端事实不产生任何 L1 或业务通过。
- 不改动 B/C/D 包任何代码。
