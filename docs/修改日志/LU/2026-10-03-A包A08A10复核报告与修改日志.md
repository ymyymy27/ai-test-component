### 2.3 复核发现并已修复的缺口

1. **范围事实前缀误报**（python_checks.py 探针脚本）：旧实现 `realpath(path).rstrip(os.sep).startswith(root)` 做字符串前缀比较，兄弟目录（如 `materialized-evil`）会被误报为项目范围内路径，`project_scope_entries` 事实失真。已改为整段归属比较（`real == root or real.startswith(root + os.sep)`）。verdict 判定本身未受影响（此前用 `is_relative_to`），但该事实会进诊断与报告，必须准确。
2. **Windows 大小写假阻塞**（evaluate_source_binding）：Windows 文件系统大小写不敏感，`Path.is_relative_to` 是大小写敏感比较；project_root 与子进程报告路径仅大小写不同（盘符/短名/大小写变体）时，真实在范围内的文件被误判 mismatch+blocked（假阻塞）。已改为 `os.path.normcase` 归一后整段比较。
3. **空期望冒充 verified**（evaluate_source_binding）：`expected_modules={}` 时旧实现返回 `verified`——没有任何核对发生却给出通过结论，违反"未验证不冒充通过"。已改为 `unverified` + 明确原因（blocked=False，与导入失败路径一致，阻塞策略由调用方决定）。

新增测试 3 项：`test_scope_entries_exclude_prefix_sibling_directory`、`test_empty_expected_bindings_never_verify`、`test_windows_case_insensitive_scope_match`（win32 专属）。

### 2.4 有意保留的边界（非缺口）

- 探针能力未在 `application/ports.py` 新增端口：接口台账 CORE-001/AB-001 仍 reviewing/partial，检查文档 3.2 明确"不得擅改接口冻结状态"；A 侧经 `CoreAssembly.source_probe` 暴露，跨包对拍后回写端口合同。

### 3.3 复核发现并已修复的缺口

1. **凭据故障被误落人工降级（实现缺陷）**：bootstrap 模型装配分支中，凭据解析失败先 `report`（自动 degraded/auth，可恢复），随后 else 分支又 `degrade("缺少模型凭据", classification="auth")`（manual=True）覆盖同一条件。后果：凭据临时故障（Windows 凭据管理器瞬时不可用等）被钉死为人工降级，后续成功事实无法恢复，违反"人工降级与自动事实分开记录，恢复必须由一次新的成功事实或显式 restore 清除"。已移除 else 分支的 degrade：解析失败保持自动 degraded（可恢复）；未提供凭据引用保持 not_configured（缺配置，非故障）。
2. **缺凭据引用的语义缺口**：传 `model_endpoint` 但未传 `model_secret_reference` 时旧实现落 DEGRADED+manual；按三态语义"not_configured：默认装配未获得该能力的显式配置（缺端点/缺凭据）"，缺凭据引用是缺配置不是故障，应为 NOT_CONFIGURED。已随缺口 1 一并修正并补测试。

新增测试 2 项：`test_model_credential_failure_is_recoverable_automatic_degradation`（断言 manual is False 且成功事实可自动恢复）、`test_model_endpoint_without_secret_reference_stays_not_configured`。

### 3.4 有意保留的边界（非缺口，如实记录）

- `BUseCaseDependencies` 仅含 unit_of_work/reader/clock：B 用例消费 model/secret 端口属 B 域依赖注入签名，台账未冻结前 A 不得擅改；装配产物（`model_provider`/`secret_manager`/`snapshot_store`/`source_probe`）已在 `CoreAssembly` 暴露待注入。
- 默认 B 动作未硬编码模型依赖映射：哪些动作依赖 MODEL 属动作语义（B 主责），经 `extra_action_dependencies` 在装配点登记（测试覆盖 C 动作拦截路径）。
- 门禁 fail-open（`_gate_denial` 门故障返回 None）：门自身故障不得让全部业务动作停摆；门实现错误由装配测试兜底，doctor 同步暴露条件。接口层以字符串 `"connection"` 引用能力键（interfaces 禁止 import infrastructure），合同测试断言状态流转兜底。
