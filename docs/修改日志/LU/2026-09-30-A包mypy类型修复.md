## 1. 修改范围

只修改两个内部基础设施占位模块 `pipe.py` 与 `editor_host.py`，为其补充**类型占位定义**与 `__all__` 导出。**不改动**：

- `core_worker.py`、`bootstrap.py`（导入语句正确，无需改动）
- `application/ports.py`（A 包对外端口，未触碰）
- 任何 A-C 接口契约文档
- 业务逻辑、接口签名（仅补占位定义，方法体统一 `raise NotImplementedError`，保持"一期预留，尚未实现"状态）
- 测试文件 `tests/`
- `pyproject.toml`、`uv.lock`

## 2. 问题根因

`pipe.py`、`editor_host.py` 原文仅 3-4 行文档字符串：

```text
一期职责预留，尚未实现，不注册为可用能力。
```

未定义任何类/函数/类型别名，也无 `__all__`。`core_worker.py` 与 `bootstrap.py` 的 `from ... import ...` 语句在运行期会 `ImportError`，在 mypy 静态检查期报 `attr-defined`。

## 3. 修改内容

### 3.1 `pipe.py` 补充定义

| 名称 | 类型 | 签名 | 说明 |
| --- | --- | --- | --- |
| `PipeUnavailable` | `Exception` 子类 | — | 管道不可用异常 |
| `PeerRejected` | `Exception` 子类 | — | 对端身份校验失败异常 |
| `NamedPipeServer` | class | `__init__(workspace_id, *, instance_id)`；方法 `start/wait_for_client/validate_peer/read_message/close` | 签名严格匹配 `core_worker.py` 调用 |
| `NamedPipeClient` | class | `__init__(workspace_id, *, instance_id)`；方法 `connect(*, timeout_ms)` | 签名严格匹配 `bootstrap.py` 调用 |
| `validate_workspace_id` | function | `validate_workspace_id(workspace_id: str) -> None` | 不合法时抛 `PipeUnavailable` |

所有方法体统一 `raise NotImplementedError`，保持"尚未实现"语义。补充 `__all__` 导出上述 5 个名称。

### 3.2 `editor_host.py` 补充定义

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `Connector` | `Callable[[str], tuple[object, str] \| None]` | 连接器类型别名，匹配 `make_pipe_connector` 返回的 `connect` 函数签名 |
| `CoreLauncher` | `Protocol`，含 `start(workspace_id: str) -> str` | 核心启动器协议，`SystemProcessLauncher` 满足该协议 |
| `CoreEndpoint` | class（占位） | 已核对身份的核心连接端点 |
| `EditorHost` | class | `__init__(*, connector, launcher, wait_timeout_seconds, poll_interval_seconds)`；方法 `acquire(workspace_id) -> CoreEndpoint` |
| `WorkspaceInUse` | 从 `aitest.application.errors` 重导出 | 与 `bootstrap.py` 文档字符串引用路径一致 |

`EditorHost.__init__` 与 `acquire` 方法体 `raise NotImplementedError`。补充 `__all__` 导出上述 5 个名称。
