## 2. 代码改动

### ① 新增：凭据窄适配器（候选甲）

`src/aitest/infrastructure/credential_resolver.py`（全文 63 行）：

```python
class PurposeBoundCredentialResolver:
    """按用途绑定凭据引用的窄解析器；实现 B 的 ``CredentialResolver`` 协议形状。"""

    def __init__(self, secret_port: SecretPort, references: Mapping[str, str]) -> None: ...

    def resolve(self, *, purpose: str) -> CredentialResolution:
        reference = self._references.get(purpose)
        if reference is None:
            return CredentialResolution(status=CredentialStatus.PURPOSE_MISMATCH, ...)
        try:
            self._secret_port.resolve(reference, purpose=purpose)  # 即取即弃
        except Exception as error:
            return CredentialResolution(status=CredentialStatus.MISSING, ...)
        return CredentialResolution(status=CredentialStatus.AVAILABLE, purpose=purpose)
```

`CredentialResolution`/`CredentialStatus` 经 `application/ports.py` 转口导入（遵守架构边界：infrastructure 只允许导入 `application.ports`/`application.errors`；本轮在 ports.py 补了两个 `as` 转口）。

### ② usecase_registry.py：依赖结构 + 三动作 handler

- `BUseCaseDependencies` 增加三个可选字段（默认 None）：`projector: MaterialProjector | None`、`caller: ModelCaller | None`、`credentials: CredentialResolver | None`。
- 新增参数适配辅助函数（键名与领域对象逐字一致、缺字段即 `B_INVALID_PARAMETER`、不填默认值）：
  `_list_of`、`_outbound_confirmation_of`、`_case_revision_refs_of`、`_rule_revision_refs_of`、`_template_version_refs_of`、`_plan_from_payload`、`_cases_from_payload`、`_confirmations_from_payload`、`_runtime_revision_request_from_payload`、`_outbound_outcome_result`、`_runtime_revision_result`。
- `handle_request_model_draft`：三端口缺一即 `B_DEPENDENCY_NOT_CONFIGURED`；`ModelOutboundPolicy`（含 `confirmation`）构造失败、`MaterialKind`/`ModelTaskType` 非法枚举一律翻译为 `B_INVALID_PARAMETER`；调用编排 `request_model_draft()` 后只搬运 `OutboundOutcome`（状态/阻塞原因/草稿元数据），不含凭据。
- `handle_revise_pending_steps`：`Plan`/`Case`/`ConfirmationRecord`/`RuntimeRevisionRequest`/`ExecutionFacts` 五对象从命令载荷重建（`ExecutionFacts` 走 `_model_of` 翻译 pydantic 校验错误），交 `request_runtime_revision()` 纯规则评估，返回交接清单（accepted/refusals/affected/preserved/invalidated_basis/rejudge/confirmation_required/pause/new_run）。
- `handle_narrow_driver`：`RunDriver` 枚举解析与 `narrow_driver()` 的 `ValueError`（扩大授权）统一翻译为 `B_INVALID_PARAMETER`。
- `_guard` 新增 `ModelGenerationConflictError` → `B_GENERATION_CONFLICT` 翻译（B-10 同键异输入）。

### ③ bootstrap.py：默认装配 + 能力声明

- 装配点构造 `PurposeBoundCredentialResolver(secret_manager, {purpose: reference})`（引用来自既有 `model_secret_reference` 参数）、`SafeMaterialProjector()`、既有 `HttpModelProvider`，注入 `BUseCaseDependencies`。
- `gate.require("request_model_draft", MODEL, SECRET)`：模型未配置/凭据故障时只降级该动作，其余动作与 doctor 不受影响。
- 依赖构造位置上移到连接水合之后、handler 注册之前，行为不变。
