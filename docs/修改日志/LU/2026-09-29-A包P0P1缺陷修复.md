## 2. 新增/修改文件清单（src代码 + docs文档）

- `src/aitest/infrastructure/file_store/unit_of_work.py`：事务开始获取单写锁，提交/回滚释放锁，校验 workspace_id，使用批量原子发布。
- `src/aitest/infrastructure/file_store/records.py`：增加批量记录提交；intent 映射和业务记录同一原子替换；查询强制依赖索引，禁止全表扫描。
- `src/aitest/contracts/errors.py`：统一扩展人工确认、维护状态和无效游标错误码。
- `src/aitest/contracts/views.py`：复用统一 `ErrorDTO`。
- `src/aitest/interfaces/local/api.py`：handler 输出统一经过 `credential_projector` 或脱敏投影。
- `src/aitest/infrastructure/file_store/backup.py`：备份扩展到当前提交根、事务、事件和清单目录。
- `src/aitest/bootstrap.py`：首个工作空间实例创建后关闭用例注册窗口。
- `docs/文档-LU/A包对外接口与装配约定.md`：同步错误模型、锁生命周期和注册时机。
- `docs/修改日志/LU/2026-09-29-A包P0P1缺陷修复.md`：新增本次固定模板日志。

## 3. 落地的约束清单

- 同一工作空间活动事务持有真实 OS 单写锁。
- 事务提交和意图结果使用原子文件发布边界。
- `FileRecordRepository.query()` 不再直接遍历 records 文件。
- 索引缺失时不降级全表扫描。
- 错误响应统一使用同一 `ErrorDTO` 结构。
- handler 输出不能绕过凭据脱敏投影器。
- 备份覆盖当前提交根、事务、事件、清单、对象和 spool 闭包。
- B/C/D 用例动作禁止重复注册、覆盖和删除。
- 首个工作空间实例创建后关闭注册窗口，已创建 API 不接受后续注册。
- 永久业务数据仍只追加，无删除接口。
