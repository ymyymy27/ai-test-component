# 修改日志：A 包 pytest 测试导入修复

| 项 | 内容 |
| --- | --- |
| 日期 | 2026-09-30 |
| 修改文件 | `src/aitest/interfaces/local/pipe.py` |
| 关键词 | A包pytest测试导入修复 |
| 触发原因 | `tests/unit/test_a_pipe_peer_rejection.py` 收集报错 `ImportError: cannot import name 'check_peer_identity' from 'aitest.interfaces.local.pipe'`。根因是上一轮 mypy 修复（commit 178201f）将 `pipe.py` 完整实现误替换为全 `raise NotImplementedError` 占位桩，丢失了 `check_peer_identity`、`validate_workspace_id` 真实校验、非 Windows 拒绝等既有逻辑 |
| 分支基线 | `develop` |
| 遵循规范 | 根目录 `AGENTS.md`、`docs/A-LU` |

## 1. 问题根因

`pipe.py` 在 commit `276b56c`（A 包底座补齐）中已有完整实现，包含：

- `check_peer_identity` 纯函数（跨会话/跨用户拒绝）
- `validate_workspace_id` 真实字符校验
- `NamedPipeServer` / `NamedPipeClient` 非 Windows 平台拒绝 + Windows kernel32 实现
- `__all__` 导出上述名称

上一轮 mypy `attr-defined` 修复时，为消除导入错误，将 `pipe.py` 重写为仅有占位类（方法体全 `raise NotImplementedError`）的桩版本，**覆盖了既有完整实现**，导致 `check_peer_identity` 丢失、测试导入失败。

## 2. 修改内容

**方案选择**：采用方案 A 的变体——`check_peer_identity` 并非"存在但未导出"，而是被误删。从 git 历史（commit `276b56c`）恢复 `pipe.py` 的完整既有实现，使 `__all__` 重新包含 `check_peer_identity`。

**未改动**：
- 测试文件 `tests/unit/test_a_pipe_peer_rejection.py`（导入语句本身正确，无需修正）
- `editor_host.py`（仍为 mypy 修复时添加的占位桩，本次不涉及）
- `bootstrap.py`、`core_worker.py`
- `application/ports.py`（A 包对外端口）
- A-C 接口契约文档

## 3. 恢复的 pipe.py 关键内容

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `PipeUnavailable` | `RuntimeError` 子类 | 管道不可用异常 |
