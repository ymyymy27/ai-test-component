# 2026-09-30-A包命名管道

## 1. 本次实现概述

补齐 `interfaces/local/pipe.py` 占位模块，实现 Windows 当前用户/会话命名管道：ctypes 直调 kernel32 创建单实例阻塞字节管道（不监听 TCP、无第三方依赖），4 字节大端长度前缀消息帧，连接后按对端 PID/会话/令牌 SID 校验同会话同用户，拒绝跨会话跨用户。

## 2. 新增/修改文件清单

- `src/aitest/interfaces/local/pipe.py`
  - `NamedPipeServer`：`start`（nMaxInstances=1 强制唯一；同名并发创建失败）、`wait_for_client`（容忍 ERROR_PIPE_CONNECTED）、`validate_peer`（GetNamedPipeClientProcessId/SessionId + 进程令牌 SID 比对）、`read_message/write_message/close`。
  - `NamedPipeClient`：`CreateFileW` 连接，忙时 `WaitNamedPipeW` 有限等待，同帧协议读写。
  - `_Kernel`：统一登记 kernel32/advapi32 函数签名；`_TokenUser` 结构。
  - `validate_workspace_id` 白名单字符校验；异常 `PipeUnavailable`、`PeerRejected`；8 MiB 消息上限。
- `tests/unit/test_a_pipe_host.py`
  - 新增 9 项测试（含真实本地管道）：往返、第二实例拒绝、20 KB 大消息帧、不存在管道、非法 id 及 editor_host 四项。

## 3. 落地的约束清单

- 只使用命名管道，不开放任何 TCP 监听。
- 管道 nMaxInstances=1，保证一个工作空间同时只有一个核心实例。
- 对端必须同会话同用户；SID 经独立进程令牌取得，不信任自报身份。
- 消息长度受限且帧协议确定，防止越界读取。
- 非 Windows 平台显式报错。
- 不改动 B/C/D 包任何代码。

## 4. 重要备注

- 默认安全属性（NULL SA）依赖进程令牌的系统缺省管道 ACL；未自定义 SDDL。
- 管道仅承载控制消息；未实现 overlapped I/O 与多客户端并发（顺序 accept）。
- 尚未做真实跨会话/跨用户的物理拒绝测试（逻辑校验路径已测试）。
