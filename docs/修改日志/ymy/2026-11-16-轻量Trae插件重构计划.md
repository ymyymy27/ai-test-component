# 轻量 Trae 测试插件修改计划

日期：2026-11-16
范围：一期插件 MVP；不含产品设计稿与界面细化。
状态：执行计划；完成情况以提交、测试与真实 Trae 验收为准。

## 1 目标

把当前“系统级本地测试平台”收敛为**可缩成小组件的 Trae 插件**：

```text
Trae 扩展（薄 UI）
  → 本地 Python CLI（按命令调用，无常驻核心）
    → 少量核心模块
      project / plan / run / evidence / issue / report
    → 简单文件：JSON / Markdown / 证据文件 / zip 备份
```

硬约束：

- 不引入常驻核心、命名管道、单写引擎；
- 不使用数据库；
- 不实现提交根、manifest、分片、索引、事件日志、迁移框架；
- 不做计划许可账本、逐动作授权、A—D 证据等级、功能×维度覆盖契约；
- 不把账号、上传、共享审核写进插件内核；
- 默认单用户、单 Trae 窗口、串行执行。

目标规模：

| 项 | 目标 |
| --- | ---: |
| Python 核心 | 6,000—10,000 行 |
| Trae 扩展/面板 | 3,000—5,000 行 |
| 测试 | 8,000—12,000 行 |
| 模块 | 20—35 个 |
| 全量测试 | ≤2 分钟 |
| 默认快测 | ≤20 秒 |

## 2 产品决策

| 主题 | 决策 |
| --- | --- |
| 宿主 | 一期 Trae；其他编辑器后置 |
| 模型 API | **必需**（AI 主导测试）；DeepSeek 兼容 HTTP API；不可用时 AI 步骤失败/阻塞，本地证据与导出继续 |
| 运行形态 | 扩展调用 Python CLI；无常驻核心 |
| 存储 | 项目目录 JSON/Markdown/证据文件 + 原子写 + zip 备份 |
| 数据升级 | 只支持当前格式；备份后转换或拒绝/重建 |
| 账号/上传/共享审核 | 不做，后续外部集成 |
| GitHub | 可选薄适配器，默认不进入核心 |
| 链路 | 可选薄适配器；消费外部日志/DB 证据，不做自动追踪 |
| 计划确认 | 一次范围确认 + 简单动作日志 |
| 覆盖与等级 | 显示状态与计数；不做 A—D 等级 |
| 模板 | 保留为规则预设清单 |
| 保留期 | 文件永久保留；用户自行清理，插件不做自动清理 |
| Python | 3.11+；验证 3.11/3.13，3.14 未验证 |
| 纯本地边界 | 模型 API 是必需外部依赖，因此不是严格“纯本地”；默认不依赖自建服务/数据库，GitHub/链路仍为可选适配器 |

## 3 MVP 范围

### 3.1 功能

| 编号 | 功能 | 最小内容 |
| --- | --- | --- |
| FR01 | 项目与模块 | 目录、目标、模块、依赖、负责人、实现状态 |
| FR02 | 任务与验收项 | 目标、范围、验收条件、执行/验收人 |
| FR03 | 交付说明 | 完成/未完成、变更、运行方式、Mock、自测证据 |
| FR04 | 规则与模板预设 | 规则版本、预设清单、Markdown 导入导出 |
| FR05 | 计划与用例 | 分层用例、验收项关联、预期、Mock 许可 |
| FR06 | L1 源码可运行性 | 语法、入口加载/最小启动 |
| FR07 | L2 函数与模块 | pytest/命令、断言、输出、日志、Mock |
| FR08 | L2 接口与集成 | HTTP 串联、业务断言、存储核验 |
| FR09 | L3 用户场景 | 人工步骤、截图/请求关联、最终持久化 |
| FR10 | Mock 与证据 | 真实/Mock/混合/未知；证据文件引用 |
| FR11 | 问题与回归 | 草稿、分级、修复版本、复测 |
| FR12 | 报告与导出 | Markdown、状态计数、证据索引 |
| FR13 | Trae 接入 | 面板/命令、项目绑定、运行状态、导出 |

### 3.2 可选适配器

| 编号 | 能力 | 限制 |
| --- | --- | --- |
| O1 | GitHub 只读 | 提交/PR/检查引用；失败不影响本地测试 |
| O2 | 链路证据 | 导入请求标识、日志、DB 查询结果；不做自动追踪 |

可选适配器默认关闭；不进入核心数据模型，不阻塞 MVP。

### 3.3 不做

- 账号、登录、项目成员、上传、共享审核、接收端；
- 常驻核心、命名管道、MCP 多协议；
- 自定义提交/索引/事件/迁移；
- 计划许可账本、逐动作授权、证据等级、覆盖契约；
- 自动浏览器捕获、回放、跨服务/函数级追踪；
- 多编辑器、多操作系统；
- 生产部署、合并冲突处理、无人审核自动修复。

## 4 目标代码结构

```text
src/aitest/
  cli.py                 # 唯一入口：JSON 命令、JSON 输出
  core/
    projects.py          # 项目/模块/绑定
    tasks.py             # 任务/验收项/交付
    rules.py             # 规则/模板预设
    plans.py             # 计划/用例
    execution.py         # L1/L2/L3 结果与状态
    evidence.py          # 证据引用与真实性
    issues.py            # 问题/回归
    reports.py           # 报告/导出
  storage/
    workspace.py         # 目录、原子写、备份
    files.py             # JSON/Markdown 读写
  runners/
    python_runner.py     # pytest/命令
    http_runner.py       # HTTP 串联
    manual.py            # 人工步骤
  adapters/
    github.py            # 可选
    link_evidence.py     # 可选
  models.py              # 共享数据模型
```

Trae 扩展：

```text
integrations/trae/
  src/extension.ts       # 命令与面板入口
  src/bridge.ts          # 调用 Python CLI
  src/panel/             # 或复用现有共享面板
```

存储布局：

```text
workspace/
  projects/<project_id>/
    project.json
    tasks/<task_id>.json
    plans/<plan_id>.json
    runs/<run_id>/run.json
    runs/<run_id>/evidence/<files>
    issues/<issue_id>.json
    reports/<report_id>.json
  backups/<timestamp>.zip
```

规则：

- 单文件原子写：临时文件 + rename；
- 可选简单 `.lock` 防止同一项目并发写；
- 查询靠目录扫描；
- 证据只存文件引用与摘要，不嵌入正文；
- 报告/导出从文件读取，不维护全局索引。

## 6 现有代码取舍

### 保留/移植

- 领域规则：L1/L2/L3、Mock、证据、问题、报告；
- 面板中可复用的视图与交互；
- 扩展命令与项目绑定流程；
- Python 测试/命令/HTTP 执行器的核心逻辑；
- 模板内容作为规则预设。

### 删除/归档

- `infrastructure/file_store` 的提交/索引/事件/迁移/恢复引擎；
- `application` 中为系统协议服务的编排、DTO、ports/adapters；
- 计划许可、逐动作授权、证据等级、覆盖契约；
- 常驻核心、命名管道、MCP、原生确认历史；
- 系统级架构/需求/验收文档。

### 重写

- CLI、简单存储、运行状态、面板桥接；
- 项目/任务/计划/运行/证据/问题/报告的最小模型；
- 新验收场景与测试。

## 7 验证与门禁

每个工作包：

1. `ruff`、`mypy`；
2. 受影响行为测试；
3. 真实文件/备份测试按限额；
4. 默认快测 ≤20 秒；全量 ≤2 分钟；
5. 文档链接与状态一致。

验收：

- 真实 Trae 安装/绑定/执行/导出；
- 试点业务 L1/L2/L3 闭环；
- 备份恢复；
- 可选 GitHub/链路不可用时明确降级。

不以全量测试通过、文档一致或模拟器通过代替真实 Trae 验收。

## 8 风险

| 风险 | 控制 |
| --- | --- |
| 删除系统级代码影响旧数据 | 只支持当前格式；备份后重建；旧格式拒绝 |
| 轻量存储查询变慢 | 数据量小；超阈值再评估可选 SQLite 索引 |
| 面板功能缩水 | 保留核心页面；非核心后置 |
| 可选 GitHub/链路重新变重 | 默认关闭，薄适配器，不进入核心 |
| 测试删得过多 | 质量门禁：变异/覆盖/审计回归；关键路径不可删 |
| 需求再次膨胀 | MVP 13 FR 冻结；新增功能走适配器，不改核心 |

## 9 完成定义

1. 插件只依赖 Trae 扩展 + Python CLI + 文件工作空间；
2. 无常驻核心、数据库、提交引擎、迁移框架、许可账本、证据等级；
3. MVP 13 FR 可用，核心闭环在真实 Trae 中跑通；
4. 默认快测 ≤20 秒，全量 ≤2 分钟，质量门禁通过；
5. 旧系统级文档与代码归档，不再出现在现行路径；
6. 未完成/未验证项明确标注，不写成通过。
