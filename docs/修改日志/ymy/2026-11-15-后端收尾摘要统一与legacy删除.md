## 已实现

- **拆分**：`application/project/understanding.py` 拆为 `understanding/` 包；`application/execution/commit.py` 收敛为门面，按记录、开始认领、快照暂存、检查点发布、运行修订、初始登记拆模块。

- **事务**：删除 `open()` 回落；`claim_start` / `commit_checkpoint` / `publish_and_stage` 统一 `begin(request_id, project_id)`；`publish_and_stage` 单次回滚。
- **面板确认 v2**：`panel-confirmation/2`；扩展 `core-bridge.ts` 直连核心命名管道发送 prepare/confirm；`core_worker.py` 要求同连接、同入口 `HUMAN_UI`；删除 `dispatch-panel` CLI、`panel-confirmation/1`、批量确认 API 与旧扩展路径。
- **legacy 栈**：legacy 文件（`records.json`/`commit.json`/`events.json`/`transactions.json`）且无 `current.json` 时拒绝装配与写入；裸目录首次写入先建立工作空间身份，再走 0003—0007 发布共享提交根。
- **摘要统一**：新增 `domain/canonical.py`（`canonical_json_bytes/text`、`canonical_digest`、`canonical_hexdigest`），全部 JSON 内容摘要改调它；删除 `ensure_ascii=True`、`default=str`、缺 `allow_nan` 的分散实现。内容字节摘要、流式哈希与存储分片键仍各自实现。
