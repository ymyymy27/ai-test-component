# 2026-11-09 面板回迁与后端适配

## 决策

同日早先的“从零重写最小面板”丢失了证据正文、问题详情、补证、批量授权和工作流 JSON。现改为以 develop 的完整面板为准，回迁源码与测试，再适配当前后端。

## 回迁

- 从 `develop` 恢复 `src/aitest/resources/panel/src/`：
  - `index.ts`、`shell.ts`、`onboarding.ts`、`guided.ts`、`model-settings.ts`、`evidence.ts`、`workflow.ts`。
- 恢复对应 13 个 Playwright 测试文件；删除重写版的 `styles.ts` 与 `new-panel.spec.ts`。
- 保留当前扩展侧的修复：密钥引用写回会话、宿主错误回显、Python 3.11+ 门禁。

## 适配

- 面板向导的环境说明与依赖声明改为 `Python 3.11+`。
- 测试宿主在回执前等待真实请求出现，并闭合运行视图后的自动面板/报告读取。
- `execute_step` 回执不再自动刷新，保留“核实执行状态”人工步骤。
- `create_report` 回执不再自动重读，保存后可继续保存新修订。
- 面板测试中“主操作”改为按名称断言，保留主按钮与编辑器打开两个入口。
- **AI 计划**：模型阶段生成 `PlanProposal`；复核页调用 `wizardReview` 显示覆盖，允许编辑提案 JSON、重新校验、确认业务功能目录；发布阶段以一次 `publish_plan`（`plan_grant`/覆盖契约/understanding 引用）提交 `full` 计划，再准备与登记。四项检查保留为人工回退。
- **普通写通道**：`save_context`、`save_environment`、`analyze_project`、`generate_draft`、`save_case`、`save_acceptance`、`prepare_run`、`register_run` 走 `writeDispatch`；`save_binding`、`save_model_outbound_policy`、`publish_plan` 保持原生确认。扩展的 `PLAIN_WRITE_ACTIONS` 增加 `save_environment`，并新增边界测试。
- **向导收敛**：项目目标与数据隔离合并在第一页，模型配置第二页；手工四项检查收进“高级”入口。
- **复核可读**：列表展示用例与覆盖摘要，完整提案 JSON 收进“高级：编辑提案 JSON”；修改后必须重新校验。
