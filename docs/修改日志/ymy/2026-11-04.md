# 2026-11-04

## 完成

### 报告/问题记录冻结配对证据修订

- `ReportSnapshot` / `ReportDraft` 增加 `evidence_revisions`（evidence_id → 正整数修订）；报告创建时从 `ExecutionFacts.EvidenceFact.evidence_revision` 冻结，随报告修订不可变。
- 报告 payload 读写增加 `evidence_revisions`；旧报告无该键时按空映射读取，不追溯补写。
- `IssueRecord` 增加 `evidence_revisions`；问题保存时对**本次新增**的证据引用读取已保存 `evidence_ref` 记录的当前修订并冻结，已有引用保留原修订。
- 问题 payload 读写增加 `evidence_revisions`；旧问题无该键时按空映射读取。
- `record_view` 的 `report` / `issue` 记录白名单返回 `evidence_revisions`，面板按配对修订打开证据正文；旧记录缺修订号的引用仍显示缺口提示。
- 面板 `evidenceRefLinks` 支持 `evidence_refs` + `evidence_revisions` 配对，报告、记录、问题详情和工作台失败证据共用。
