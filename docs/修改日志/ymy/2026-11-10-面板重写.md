# 面板按产品流程重写（2026-11-10）

## 1 范围

按用户要求，在删除旧面板后按产品使用流程重写共享面板。目标是让“下一步该做什么”始终可见，同时保持核心事实、授权和判定边界不变：

- 本次测试概览：运行前/运行时/运行后三阶段、主动作、范围统计、缺口、待人工事项；
- 首次向导：选择项目 → 目标/环境/模型 → 分析源码 → 生成计划 → 复核发布 → 准备并登记运行；
- 工作台：步骤列表、准备操作 → 原生授权 → 执行 → 独立核验、证据正文、手工补证；
- 报告/问题：报告修订列表与详情、导出、问题详情与复测简报；
- 设置：模型配置与安全凭据引用、核心连接、空间诊断；
- 诊断：真实能力列表、依赖状态、受影响动作、事件续读、高级动作 JSON 入口。

未改变：核心、CLI/MCP、后端 `read_view`/`query`/DTO、Trae 扩展桥、领域判定、FR/AC 与验收登记。

## 2 代码结构

```text
src/aitest/resources/panel/src/
├── index.ts        # 自定义元素、宿主连接、路由、数据加载、焦点/滚动保持
├── host.ts         # 有界宿主传输：requestId 关联、超时、迟到回执提示
├── wizard.ts       # 首次向导状态机与受控命令队列
├── types.ts        # 协议/视图/本地状态类型
├── context.ts      # 视图使用的窄接口
├── ui.ts           # DOM/组件原语（按钮、卡片、状态、步骤条、字段）
├── styles.ts       # Trae/VS Code token 设计系统与响应式布局
├── labels.ts       # 核心词汇中文映射、缺口说明、格式化
├── icons.ts        # 内联 SVG 图标
└── views/          # home / wizard / plan / workbench / reports / settings / diagnostics
```

要点：

- **主导航 3 个入口**：本次测试（概览/步骤/计划）、问题与报告、设置；计划与工作台是“本次测试”的子视图，诊断保留在页头。概览的主动作直接切到“步骤”，不增加操作步数。
- **单一宿主桥**：`HostClient` 只用 `clientRequestId` 关联回执；超时返回 `ENTRY_TIMEOUT`，迟到回执提示“先核对原操作”，不自动重试。
- **写通道分离**：普通写入走 `writeDispatch`，`HUMAN_ACTIONS` 走 `controlledDispatch`；`wizard.ts` 的两张白名单由 `tests/unit/test_action_allowlists.py` 与核心合同对账。
- **幂等意图**：应用按 action/target/expected_revision/parameters 复用稳定意图；向导直接使用服务端生成的 `intent_id`。
- **事实只读**：页面只展示 `read_view`/`query` 回执；没有回执时显示空状态或原因，不补造成功。
- **重渲染不打断输入**：`render()` 重建 shadow DOM 前后恢复焦点、选区与滚动位置。

## 3 产品流程映射

| 产品步骤 | 面板位置 | 关键边界 |
| --- | --- | --- |
| 连接核心 | 顶栏/每页页脚 | `ensureCore` 后只以 doctor 回执声明能力 |
| 选择项目与环境 | 首次向导第 1–2 步 | 目录、入口、数据复位说明；模型凭据只存引用 |
| 应用配置 | 首次向导“重启核心” | 先请求优雅停机；活动执行未排空时拒绝；新实例 READY 才继续 |
| 分析源码 | 首次向导“保存项目并分析源码” | 4 个受控命令顺序执行；失败停在本阶段可重试 |
| 生成计划 | 首次向导“生成 AI 计划”或手工四项检查 | 模型只返回提案，不执行程序 |
| 复核发布 | 首次向导“核对计划” | 覆盖、unknown、能力缺口同屏；一次确认冻结计划/覆盖/许可 |
| 准备与登记 | 首次向导“准备并登记运行” | 登记不等于执行 |
| 执行 | 本次测试（概览/步骤） | 解析、授权、执行、核验分别记录；原生窗口确认 |
| 证据与核验 | 工作台 | 证据按 `evidence_id + revision` 读取；执行返回不等于通过 |
| 报告与问题 | 问题与报告 | 报告快照、导出、复测简报；问题确认/开始/修复/回归/关闭/处置表单，关闭仍由核心守卫判定 |
| 恢复 | 顶栏连接 / 工作台刷新 | 退出重开后按原运行继续；未知结果不重放 |
