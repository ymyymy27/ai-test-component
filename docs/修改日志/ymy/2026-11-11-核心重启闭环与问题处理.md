# 核心重启闭环、问题处理与全量回归（2026-11-11）

## 1 范围

补齐面板重写后遗留的跨组件问题，并完成当前版本全量回归：

- 环境/模型配置变更后，核心能够受控重启并加载新配置；
- 问题页提供确认、开始、修复、回归、关闭与处置的一等表单；
- 手工四项检查路径补齐端到端测试；
- 运行真实 Trae 面板启动冒烟；
- 跑完整 Python 回归并核对产物。

未改变领域判定、FR/AC 编号或验收登记；从既有计划直接准备运行仍未开放（缺少原始准备回执字段）。

## 2 变更

### 2.1 核心受控重启

- `src/aitest/bootstrap.py`
  - 新增 `CoreRestartBlocked` 与 `restart_endpoint()`：先探测活动核心；有核心时请求优雅停机，活动执行未排空则明确拒绝；停机确认后按同一启动入口启动并核对新实例。
- `src/aitest/interfaces/tools/cli.py`
  - 新增 `restart-core --workspace`：成功输出 READY/workspace_id/instance_id；停机拒绝时输出结构化 `CORE_RESTART_BLOCKED`，不强制杀进程。
- `integrations/trae/src/core-bridge.ts`
  - 抽出 `coreEntry`，新增 `restartCore`；保留 ensure-core 的 60s 预算，restart 允许 120s；解析入口的结构化拒绝，不复制原始 stderr。
- `integrations/trae/src/extension.ts`
  - 新增 `restartCore` 消息分支，回执保留 code/message 与客户端关联。
- 面板
  - `HostClient.restartCore()`、`AppContext.restartCore()`、设置页“重启核心”按钮；
  - 向导在 `wizardSetup` 成功后进入“重启核心”步骤，只有新实例 READY 才继续保存项目/分析源码；活动执行未排空时停在重启步骤可重试。

### 2.2 问题处理表单

- `src/aitest/resources/panel/src/views/reports.ts`
  - 新增“处理问题”表单：确认问题（严重度/责任人）、开始处理、记录修复、请求回归、关闭问题（原用例/回归运行/新尝试/断言引用）、处置（非缺陷/重复/推迟）。
  - 关闭与更新走 `controlledDispatch`，修复与回归走 `writeDispatch`；操作后重新读取问题修订。
- `tests/unit/test_action_allowlists.py`
  - 面板写白名单同时与扩展、核心合同对账。

### 2.3 工作台恢复入口

- `src/aitest/resources/panel/src/views/workbench.ts`
  - 新增“执行不顺利？”卡片：重试这一步、退回上游、补录证据。
  - 重试/退回先展示“创建新尝试、旧尝试与证据保留、下游影响以核心回执为准”，确认后自动完成 `prepare_execution` → `retry_step`/`return_stage`；结果回执中的下游需重跑清单直接显示。
  - 补录证据绑定当前已完成的尝试，预填 run/step/attempt，只填写操作类型、操作目标、实际结果和业务对象；空附件不伪造完整证据。
  - 三个入口都回到原步骤并刷新；原始回执不占主屏。

### 2.4 高级动作目录

- 诊断页高级动作不再只列动作名：每个动作显示中文标题、何时使用、注意事项；常用动作可从当前页预填 `run_id` / `step_id` / `attempt_id` / `execution_action_id` / `issue_id` / `report_id` / `plan_id` 等标识。
- 低频维护动作仍只在高级入口，不新增一级导航；原始 JSON 仍可编辑，写动作仍按核心合同选择普通写入或原生确认。

### 2.5 本地复核

- 报告详情新增“本地复核”：复核结论与说明绑定准确报告修订，`record_local_review` 走核心原生确认；复核编号在本次会话内按报告保存，导出时自动带入 `review_ids`。
- 边界：后端没有 `local_review` 的 query/read view，面板重启后无法从报告视图重新列出既有复核；导出仍以保存回执为准。

### 2.6 测试与文档

- 新增 CLI `restart-core` 测试：缺路径不创建目录；真实两次重启实例 ID 更换、工作空间不变。
- 面板新增：设置页重启核心链路、问题确认走受控通道、手工四项检查、工作台重试/退回/补证端到端。
- 设计与现状页同步 3 个一级入口、受控重启和问题处理边界。
- 新增本日志；面板重写日志与删除日志保留原事实并标注后续。
