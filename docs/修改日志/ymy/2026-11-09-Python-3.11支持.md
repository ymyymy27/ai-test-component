# 2026-11-09 Python 3.11+ 支持

## 决策

一期被测环境从“仅 Python 3.13”调整为 **Python 3.11 及以上**。`pyproject.toml` 的可安装范围保持 `>=3.11,<3.14`，本次不改锁文件。

## 代码

- `src/aitest/interfaces/tools/onboarding.py`
  - 新增 `_supported_python()`：`(3, 11)` 及以上通过，3.10 及以下拒绝。
  - `setup` 的最低版本门禁由“必须 3.13”改为“3.11+”。
  - 独立环境的依赖目录按实际解释器版本生成；返回的 `dependencies` 使用实际 `Python X.Y`。
  - 通用错误提示改为“Python 3.11+”。
- `src/aitest/application/project/onboarding.py`
  - 自动生成的 `EnvironmentRef` 标签由 `Python 3.13` 改为 `Python 3.11+`。

## 文档

- `AGENTS.md`、`docs/项目文档/总体架构.md`、一期需求/功能/架构总览、Trae 接入、面板交互设计草案、AI 主导设计草案中的版本口径同步为 3.11+。
- `docs/现状.md` 增加本次变更记录。
