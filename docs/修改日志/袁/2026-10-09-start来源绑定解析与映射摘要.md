# C 侧 start 来源绑定解析：物化映射到 source_binding_digest

基线 `46fd8c0`，`fix`。把 A 侧已实现的物化映射接到 C 侧 start，按合同生成并**独立核对** `source_binding_digest`；不启动执行、不写业务记录、不声称来源通过。

## 1. 合同依据

- [AB-001 1.34](../../接口对接/进行中/AB-001-端口与保存/contract.md)：`materialize` 成功返回 `paths`（期望来源路径→workdir 实际路径，含 `sha256`/`size`）与 `content_digest`；
- [BC-001 第 6 节](../../接口对接/进行中/BC-001-PreparedRun/contract.md)：`source_binding_digest` 由 **C 在 start** 计算，是固定 workdir 的"期望→实际路径映射"摘要，**不可**与 B 在 prepare 冻结的 `resolved_input_digest` 合并或互替。

## 2. 源码

新增 [application/execution/start_source_binding.py](../../../src/aitest/application/execution/start_source_binding.py)：

- `StartSourceBindingResolver.resolve(snapshot_id=..., destination=...)`：
  1. 调 `SourceSnapshotPort.materialize`；`state != "materialized"` 或 `verified is not True`（含拒绝集合）即 `SourceBindingUnverified`；
  2. 返回的 `snapshot_id` 必须等于请求的快照，`destination` 必须存在；
  3. `paths` 逐项严格校验：期望相对路径非空、非绝对、不含 `..`、**逐项唯一**；实际路径非空；摘要必须是 `sha256:`+64 位小写；`size` 必须是**精确整数**且非负；
  4. **独立重算**映射摘要（对 `paths` 规范 JSON 字节）并要求等于 `content_digest`，不信任传入声明；
  5. 每个实际路径必须在固定 workdir 内、是常规文件（非链接），并**有界**核对字节：最多读取 `size + 1` 字节，长度与摘要都必须精确相符；
  6. 返回 `snapshot_id`/`workdir`/`paths`/`source_binding_digest`。
- 配套：修 [source_snapshot.py](../../../src/aitest/infrastructure/adapters/source_snapshot.py) 的 `paths[].sha256` 统一为 `sha256:`+64 形式（清单内原为裸十六进制，新增 `_as_digest` 归一），对外摘要口径与全仓一致。

## 5. 补记：start 准入闭环与与 `source_checks` 的分工

按[裁定四项](../../一期工程整改/02-整改计划/裁定-2026-10-09-start准入四项.md)（AB-001 1.35）完成后，本模块提供一次调用即完成的 **`admit_start`**，顺序为：

1. 物化映射六处核对（冻结期望**精确覆盖**、物化**自述 workdir** 必须等于请求目录、非符号/**硬链接**、实际路径**唯一**、**有界字节**、**跨入口摘要**一致）；
2. 裁定 **1A**：`workdir:<安全相对路径>`，拒绝绝对/盘符/`..`/越界/**逐段链接**/非目录；
3. 裁定 **2A**：执行参数与冻结已登记入口参数**逐字**一致，提供代入即拒绝；
4. 裁定 **3A**：适配器由 `adapter_versions` **唯一键**决定；
5. 可选：**已登记入口**一致、**解释器**一致、**来源核验必须 `verified`**；
6. 任一步失败即按裁定 **4A** 阻塞（`SourceBindingUnverified`；四类原因回执 `retryable=False`、缺口取领域既有 `EvidenceGapKind.SOURCE_UNVERIFIED`）。

证据：[test_start_source_binding.py](../../../tests/unit/test_start_source_binding.py) **31 passed / 1 skipped**（skip 为宿主不支持目录符号链接，如实不计通过），含真实物化端到端与真实物化失败反例；Ruff 无发现、Mypy 225 文件通过。

**与 `source_checks` 的分工（避免重复判定）**：本模块只做**输入侧**核对与准入（冻结值 vs 观察值/物化事实，全部为纯函数、不写记录、不启动进程）；[source_checks.py](../../../src/aitest/application/execution/source_checks.py) 继续负责**探针观察**到核验事实的派生（`state`/`failure_class`/`gap_ids`）与持久化。两者通过 `require_verified_source(verification)` 衔接：本模块只消费其结论，不重算缺口。

**仍未接入默认装配**：真正的 start 需要可信动作解析器把冻结绑定变成 `Attempt`/`ExecutionRequest`（A-02/C-02/C-12 未闭合），故本轮不注入、也不改写"缺解析器 ⇒ 执行诚实地不可用"的默认期望。A-08/C-12 整项不闭合；ABC 仍 21 整项，真实 AC 仍 0 verified。

## 6. 边界（截至本批更新）

- 本组件**不**决定"实际入口/解释器/加载来源是否与冻结绑定相符"的**缺口派生**（仍由 `source_checks.py` 承担），也**不**写 `RunFact.source_binding_digest`、不接管进程、不落业务记录；
- `cwd_mapping` 语法、参数代入、适配器选择、失败回执分类**已裁定并实现**（裁定四项，AB-001 1.35，单方裁定待双方确认），不再是待裁定项；
- 本组件**未接入默认装配**：可信动作解析器（把冻结绑定变成 `Attempt`/`ExecutionRequest`）尚未实现，属 A-02/C-02/C-12 的未闭合项，故不改写"缺解析器 ⇒ 执行诚实地不可用"的默认期望；
- A-08/C-12 整项不闭合；ABC 仍 21 整项，真实 AC 仍 0 verified。
