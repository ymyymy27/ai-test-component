### 6.1 结清一个未解释疑点：mypy 报的文件数

会话中 `mypy` 的成功行一开始报 228 个源文件，后段变成 227，而 `src/` 下始终恰好 **213** 个 `.py`（全部位于 `src/aitest`）。为了确认不是**源文件被静默跳过**，做了受控实验：

1. 在 `src/aitest/` 下临时新增一个带真实类型错误的文件（返回 `str` 而声明 `-> int`，**不加** `type: ignore`）→ mypy 报 `error: Incompatible return value type ... [return-value]`，计数变为 228；
2. 删除该文件 → 计数回到 227，无错误。

结论：**`src/aitest` 的每一个文件都在 mypy 覆盖内**（计数随新增文件同步，且真实错误被报出）。228 与 227 的差异来自 mypy 通过导入关系额外跟进的文件数，不是静态门禁的覆盖缺口。第一次实验我误在错误行上写了 `# type: ignore[return-value]`，把错误压掉、得到"通过"的假象——已重做并记录。
