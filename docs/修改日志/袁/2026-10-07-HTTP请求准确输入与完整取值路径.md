# HTTP请求准确输入与完整取值路径

涉及C-03/12、A-10；ABC整项仍21，真实一期AC仍0/35。

根因：请求配置只检查非空/timeout>0，NaN/Infinity/bool、非HTTP地址、内嵌凭据、非法端口/方法/头及重复提取/断言身份可直接进入transport；超大整数还可能抛转换异常。取值路径用partition/删尾括号，value[0、value[0]]]、value..child被解释成另一个合法路径，能得到断言通过。现在请求在构造时严格验证完整文本、HTTP/HTTPS目标、字节正文、有限正数且不超过本地TIMEOUT_MAX的时长及唯一身份。路径移到纯领域read_json_path，完整语法才读取；非法/未支持路径保持unknown，超长数组编号先按长度拒绝，不直接转换整数。JSON根/显式null和合法点分路径不变。

源码：[HttpRequestSpec与HTTP取值边界](../../../src/aitest/infrastructure/adapters/execution/http.py)、[唯一纯领域路径](../../../src/aitest/domain/execution/assertions.py)；[反例与正例](../../../tests/unit/test_http_request_boundary.py)覆盖输入拒绝、原来3种错误通过、已有正确拒绝、合法根/IPv6/正文、未支持及超长索引。HTTP/HTTPS限制是项目执行边界，urllib自身还支持其他协议，见[Python入口说明](https://docs.python.org/3.13/library/urllib.request.html#urllib.request.urlopen)。
