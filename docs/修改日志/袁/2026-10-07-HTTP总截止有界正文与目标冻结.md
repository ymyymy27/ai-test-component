# HTTP总截止、有界正文与目标冻结

涉及C-03/12、A-10；ABC整项仍21，真实一期AC仍0/35。

根因：原socket timeout不是整请求截止，正常响应和HTTPError均无界read；自动跳转可改目标/方法，截断响应还抛出未归一化异常。现同请求以单调时钟约束DNS、连接、TLS、发送、响应头及正文，本次持有socket到期中止；最多4个未完DNS线程只解析，迟到不得连接/请求。冻结目标直连，不取隐式代理、不跟随跳转；TLS保留信任链/主机名校验。请求定界须与准确字节一致，非法编码/Transfer-Encoding在IO前拒绝。

响应默认4MiB、最高64MiB，正常/错误共用有限read1采集，准确区分边界EOF、声明长度/完整chunked、超限和截断；不完整时保留实际前缀/已知状态，body_complete=false，提取/断言一律unknown，即使前缀是可匹配JSON。异常细节不回显原文。源码：[适配与完整性消费](../../../src/aitest/infrastructure/adapters/execution/http.py)、[总截止/准确socket/有界transport](../../../src/aitest/infrastructure/adapters/execution/http_transport.py)；[实际出站回归](../../../tests/unit/test_http_transport_limits.py)。read1/关闭及TLS机制参考[Python HTTP](https://docs.python.org/3.13/library/http.client.html#http.client.HTTPResponse.read1)、[socket shutdown](https://docs.python.org/3.13/library/socket.html#socket.socket.shutdown)、[SSL验证](https://docs.python.org/3.13/library/ssl.html#ssl.SSLContext.wrap_socket)。
