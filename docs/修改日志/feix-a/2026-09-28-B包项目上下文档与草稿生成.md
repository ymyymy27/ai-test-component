### 1.3 关键约束的落点

- **上下文缺失列缺口并阻塞，不编造依赖与结论**（P1-AC17）：`detect_context_gaps()` 返回缺口，
  `prepare_run` 据此返回 `status=blocked`；`apply_template()` 缺口非空时**不生成草稿**。
- **"映射缺失不能解释为没有影响"**（P1-FR03）：有模块但无任何依赖边 → **阻塞**缺口，
  而不是"无依赖、可继续"。
- **非 Git 目录不构成拒绝理由**（P1-AC25）：`plain` 是**一等绑定**。
- **同步盘/网络盘拒绝建立并说明原因**：返回 `WorkspaceLocationRejection`，不是布尔。
- **`DriveKind.UNKNOWN` 不由领域层擅自拒绝**：只产生**非阻塞**提示，由调用方决定。
- **模板只生成草稿**：`GeneratedContent.status` 构造期拒绝非 `draft` 取值，本模块无发布路径。
- **人工修订不被重新生成覆盖**：再次生成得到**新草稿修订**，旧对象原样保留。
- **定向失效**：`draft_expiry()` 只报告真正变化的来源；`None` 表示不适用，不参与比较。
