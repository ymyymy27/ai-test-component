# Issue #125：面板证据正文只读视图（2026-11-01）

## 1. 问题

`read_view` 仅支持 `run / panel / delivery / plan / report / case / issue`，没有 `evidence` 视图。
证据记录（`aggregate_kind=evidence_ref`）只保存元数据（`evidence_id`、`object_digest`、
`redaction_state` 等），正文按 `object_digest` 存放在对象仓。面板和报告只能拿到
`evidence_ref` 的 id，无法读取正文内容。

## 3. 方案设计

### 3.1 视图形状

与 `plan / report / case / issue` 一致：

```text
{
  project_id, record_id(=evidence_id), record_revision(=evidence_revision),
  record_kind="evidence", historical_snapshot=True,
  record: { ... 白名单元数据 ... },
  body?: "<脱敏后的 UTF-8 文本>",           // 仅安全态返回
  body_omitted_reason?: "redaction_unsafe" | "object_unavailable"
                       | "body_too_large" | "object_unreadable"
                       | "object_corrupted" | "binary_content"
}
```

### 3.2 强制脱敏门控（逐层短路）

1. **`redaction_state` 门控**：只允许 `redacted` / `not_required`；`blocked` / `unknown` / 非法值
   → 只返元数据，`body_omitted_reason=redaction_unsafe`，**不返回正文**。
2. **对象仓可用性**：`objects` 未注入、`object_digest` 非 `sha256:` 前缀、`object_size` 非法
   → `object_unavailable`。
3. **大小预算**：`object_size > 4MB`（`_MAX_EVIDENCE_BODY_BYTES`）→ `body_too_large`，不读正文。
4. **摘要校验**：`EvidenceObjectStore.read_bytes` 内部校验 SHA-256；抛 `ValueError`/`OSError`
   → `object_unreadable`，**不泄露原始异常**。返回字节长度与 `object_size` 不符 →
   `object_corrupted`。
5. **文本限制**：UTF-8 解码失败（二进制材料）→ `binary_content`，不返 `body`。

正文来自对象仓，对象字节在落盘前已由 `guard_bytes` 不可关闭过滤；视图层不做二次推断或加工。

### 3.3 元数据白名单

显式剔除 `code_identity`（含 `workspace_ref` 绝对路径）。保留字段：

```text
evidence_id, evidence_revision, project_id, run_id, step_id, attempt_id,
source_instance_id, evidence_kind, capture_source, object_digest, object_size,
integrity, redaction_state, projection_state, redaction_summary_ref,
evidence_level, gap_ids, media_type, created_at
```

### 3.4 跨项目与身份校验

- 记录 `project_id` / `evidence_id` 与请求参数不符 → 抛 `ValueError`（不返回空视图冒充没有记录）。
- `require_record_identity` 校验 `aggregate_kind=evidence_ref`、`record_id`、`revision`。
- dispatch 前后两次取快照边界，不一致抛 `SNAPSHOT_REQUIRED`。
