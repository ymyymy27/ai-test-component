## 文档维护规则

- 每新增阶段文档，应在本README中加入分类、链接和一句话简介。
- 文档名称较长时，可在索引中使用简化标题，但链接必须指向实际文件。
- 跨包字段变化必须先更新公共接口文档，再同步C包实施文档和修改日志。
- 已解决问题从《待解决问题清单》改为完成或移入新的阶段性说明，不覆盖历史记录。
