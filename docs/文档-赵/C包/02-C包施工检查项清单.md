# C包施工检查项清单

版本：0.1  
日期：2026-09-24  
用途：后续每次修改C包时逐项勾选，不允许只看代码是否可导入

## 1. 开发前

- [ ] 已拉取develop最新代码并从develop切出或更新功能分支。
- [ ] 未直接修改main或develop。
- [ ] 已检查git status，不覆盖他人未提交改动。
- [ ] 已确认本次只修改C包及其合同、测试或文档。
- [ ] 若涉及跨包字段，已建立待确认项，不私自改B或D内部模型。
- [ ] 已明确本次FR/AC、输入、输出、异常和恢复分支。

## 2. 领域模型

- [ ] domain层只使用标准库，不导入Pydantic。
- [ ] Run、Step、Attempt身份稳定且可追溯。
- [ ] Attempt.attempt_index从1开始，retry_count为index减1。
- [ ] pending_verification、blocked、execution_error和cancelled不混用。
- [ ] 超时只记录等待事实，不宣称停止、回滚或业务失败。
- [ ] 新Attempt不退回旧通过，旧事实不被覆盖。

## 3. 执行与恢复

- [ ] 启动前已保存意图、输入摘要、幂等信息和副作用类别。
- [ ] 句柄未保存时不会直接推断未执行。
- [ ] 有副作用且结果未知时进入pending_verification。
- [ ] 暂停只在步骤边界生效。
- [ ] 取消先登记意图，再请求停止；未确认不写成cancelled。
- [ ] 恢复同一句柄不创建新业务执行。
- [ ] 重试创建新Attempt并成为当前Attempt。
- [ ] 未知副作用不自动重放。
- [ ] workdir在停止和必要证据保存前不清理。

## 4. 采集与证据

- [ ] output block包含流名、序号、offset、length、digest、完整标志和采集来源。
- [ ] 游标推进前已保存过滤后的实际内容。
- [ ] ExitFact包含真实退出码、启动身份、流字节数和终止原因。
- [ ] 进程退出、编辑器关闭、网络断开不作为停止证明。
- [ ] 凭据在落盘前过滤。
- [ ] RedactionSummary不含凭据值或可逆信息。
- [ ] EvidenceRef绑定项目、Run/Step/Attempt、采集来源和代码身份。
- [ ] TraceNode使用实际节点ID和父节点关系。
- [ ] 不能仅凭相近时间或AI推断建立调用关系。
- [ ] Mock声明、静态候选和实际核实结论分开。
- [ ] 核验失败和材料不足分开表达。

## 5. 依赖与合同

- [ ] Attempt固定step_revision、resolved_input_digest和source_binding_digest。
- [ ] consumed_outputs和consumed_conditions使用精确上游引用。
- [ ] 上游新Attempt使相关下游和传递依赖失效。
- [ ] 不使用“最新一个成功Attempt”拼接依赖。
- [ ] ExecutionFacts只包含单个Run的一致快照。
- [ ] ExecutionFacts不包含最终E/R/V/P/F/U/H。
- [ ] ExecutionFacts不含凭据、未过滤内容或完整大对象。
- [ ] 合同变更更新Schema、夹具、确认表和修改日志。
- [ ] 跨包字段只能由合同所有者修改并做兼容检查。

## 6. 测试与交付

- [ ] 领域单元测试覆盖合法和非法状态。
- [ ] 合同测试覆盖成功、失败、未知三类夹具。
- [ ] 架构测试通过domain依赖方向检查。
- [ ] Schema由脚本生成，未手工编辑。
- [ ] 运行失败、未验证项和未覆盖环境写入交付说明。
- [ ] 修改日志已更新。
