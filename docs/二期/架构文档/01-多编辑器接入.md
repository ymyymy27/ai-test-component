# 二期架构01：多编辑器接入

版本：2.5  
更新日期：2026年9月21日  
状态：修订基线，待实现与实测；文档不代表产品已通过验收。

integrations/<editor>分别承载命令、目录、宿主面板和工具配置，不互相import；公共视图和DTO共用。Trae为一期基线，新编辑器不复制调度、重试、判定或存储。

启动向核心report_capabilities，来源携editor_instance_id、版本、能力与实际失败信息；应用用例校验后持久化，扩展不写records。目录切换核对绑定修订，迟到响应保留原缓存。第二入口发现同核心并核验实例后连接；无法连接报WORKSPACE_IN_USE，不绕锁。

接入必须覆盖安装、绑定、计划/执行/查询/导出、面板、工具入口、文件跳转、目录切换、停用升级卸载和能力替代；接口允许向后兼容新增动作，通过能力声明识别，未知动作明确拒绝而非猜测。

源码只读但本地工作空间可写可运行；数据目录不可写只能查询已保存结果，导出仅在无需登记新产物的只读获取路径可用，创建新导出记录须恢复写入。工作区信任不足不自动启用项目命令或MCP。

验证P2-AC01/06/09，真实版本写入兼容清单，不能以其他编辑器通过替代本编辑器结果。

## 1 接入检查清单

| 责任 | 每个宿主须完成 | 共享内容 |
| --- | --- | --- |
| 命令映射 | 安装/菜单/快捷入口映射明确动作与参数 | contracts动作语义及错误 |
| 项目上下文 | 打开/切换/多根目录事件映射project与binding_revision | 核心项目记录，不能自己按目录名建业务键 |
| 面板宿主 | 加载同一Web Component、CSP、Schema和净化渲染 | resources/panel唯一源码 |
| 工具配置 | 按实际宿主方式登记或指导手动stdio配置 | 固定relay、参数中的绑定、无密钥 |
| 定位装饰 | 消费LocationDTO/标注，不自行推断内容一致 | application/locations输出 |
| 生命周期 | 断开订阅、清自己登记、升级版本协商、卸载保留数据 | 单核心与维护合同 |

各integrations目录互不import或借用对方构建产物；共同类型进入contracts。新增图/定位动作通过能力协商开放，不要求一期接口实现已有未知动作。接入验收逐项记录通过/失败/不适用及原因，临时CLI替代不能证明该宿主面板已支持。

## 2 多入口时序

第二入口先验证实例握手，再查询自己的project/绑定；相同intent只得到原运行。切换目录时关闭旧订阅后取新快照；原项目活动运行继续并保留导航。第三入口与前两个共用同一OS锁持有者；版本不兼容不得启动独立写入者“兼容”旧核心。可读源码与可写数据空间分别核对，信任不足单独拒绝执行。

新宿主须实现一期入口第9节的受控用户确认来源和挑战核对，不能把MCP请求映射为用户点击。所有入口复用该权限检查，不以同一OS用户身份替代人工确认。
