# 二期架构05：操作系统与运行时兼容

版本：2.4  
更新日期：2026年9月21日  
状态：修订基线，待实现与实测；文档不代表产品已通过验收。

新增平台仍一个核心/一个用户工作空间/一个写入者，不引入常驻服务或第二套业务。先试点编辑器，再新增系统组合；不扩大技术栈自动执行承诺。

| 差异 | 适配方式与验证 |
| --- | --- |
| IPC | Windows受限命名管道；Linux/Unix本地socket，适配器get_peer_identity按平台实现，Linux可SO_PEERCRED，Apple采用支持的getpeereid等方式，不能统一写死一个API |
| socket权限 | 私有目录与socket权限、对端用户、实例握手分别验证；仅本机路径 |
| 文件系统 | 锁释放、同卷原子替换、文件/目录刷新与断电恢复逐系统实测，不支持则拒绝活动存储 |
| 路径 | 大小写/Unicode/符号链接按实际文件系统处理；项目ID稳定，路径不是业务主键 |
| 凭据 | Windows凭据管理、macOS Keychain或Linux Secret Service等受控后端；不可用明确提示，禁止明文回退 |
| 运行时与打包 | Python、编辑器发行版、制品和依赖锁文件纳入兼容清单，未测不声明支持 |

参考：[Linux unix(7)](https://man7.org/linux/man-pages/man7/unix.7.html)、[Apple getpeereid官方归档](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/getpeereid.3.html)。资料描述接口，不替代目标版本实测。

升级重新验证受影响组合；迁移遵守一期备份/维护模式。兼容数据记录os/os_version/runtime/editor及发行版/version/core/adapter/artifact_digest/evidence_path/verified_at/result。验收P2-AC02，至少一新增系统真实闭环，失败或未测如实记录。

## 1 组合验收与升级清单

| 类别 | 实测输入与失败注入 | 交付证据 |
| --- | --- | --- |
| 路径 | 空格/中文/大小写差异、符号链接、目录移动 | 正确绑定与边界拒绝，不按显示名串项目 |
| IPC/锁 | 第二入口、旧发现、进程退出、对端身份不符 | 单写成立，旧身份不能接管，权限拒绝明确 |
| 文件提交 | 各发布中断点、空间不足、损坏指针/对象、恢复再中断 | 仅原提交或完整新提交可见，证据缺口如实 |
| 凭据 | 后端缺失、引用失效、跨机恢复 | 需要凭据的能力不可用，其他本地能力继续，无明文回退 |
| 运行时/制品 | 缺解释器、版本不兼容、扩展/核心主版本冲突 | 安装/动作拒绝原因、版本和制品摘要 |
| 升级 | 宿主版本变更、需要实际格式迁移 | 重新探测，受影响组合重新实测；不继承旧pass |

核心支持区间在实际pyproject与锁文件确定后记录，不用文档推测任意组合兼容。新增系统不强制同时支持所有编辑器；每个组合独立列result/evidence_path。平台差异由基础设施和入口实现，上层只依赖统一端口。
