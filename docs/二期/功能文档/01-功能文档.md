## 1 兼容规则

允许新增动作/字段，不改变已发布字段语义。定位状态新增unknown/metadata_match/current_verified/stale/missing，旧记录缺字段按unknown，旧客户端忽略未知字段。新动作通过能力协商，不要求一期已存在所有图动作。

CapabilityState按editor_instance/版本独立修订，入口提供探测事实但核心唯一持久化。环境ConnectionState另存，不能相互覆盖。DiagramDefinition/Revision是投影记录，不参加判定和分母，仍经同一工作单元不可变提交。

## 2 图与定位边界

依赖节点用module_id，调用节点用run/attempt/trace_node_id；源码位置仅导航，不用路径/函数名合并重复调用。单模块无边显示依赖图不适用，链路仍可按实际证据显示。缺节点用已知范围缺口标记，不能补造调用节点。

人工只调整布局、折叠、注释；必须保留事实节点、边和缺口集合，不准通过隐藏关键缺口改变导出内容。源码定位来自证据，不因人工布局产生代码位置。图视图DTO和导出HTML来自同一修订。

## 3 历史和诊断

历史按源码身份分组，含diff/排除规则；组内再按一期结论键显示不同范围、环境、规则/验收/模板及判定策略。行显示记录时间、档位/驱动、业务结论、证据等级或未打分、必测完成/跳过。新full取消/未知不能回退旧绿灯。一个运行多报告修订折叠，点击只读，不改变当前选择算法。

环境自检展示依赖环境、运行时/依赖、被测目标与数据条件、模型连接；模型失效只降AI，但被测目标不可用阻塞关联测试。宿主缺跳转给路径文字、缺面板给命令/CLI、缺MCP给手动配置。存储不可写仍禁止写动作，不能以“降级不阻塞”绕过保存要求。

建设顺序：先历史/定位/图的本地增量，再按实际试点扩展编辑器、操作系统；不加入未立项的自动批采集、报告AI草稿或步骤预填。完整AC映射附后。

## 4 逐功能操作合同

### 4.1 P2-FR01 多编辑器接入

| 项目 | 说明 |
| --- | --- |
| 输入 | 实测宿主/版本、当前目录、绑定修订、同一核心与协议能力清单 |
| 操作 | 安装适配扩展，核实能力，绑定目录，加载共享面板；命令/CLI/MCP连接同一核心 |
| 输出 | 与Trae语义一致的动作结果、DTO、报告和归属明确的运行记录 |
| 规则 | 适配器只映射宿主事件，不复制规则；多目录显式选项目，多入口同intent去重、明确重跑新intent |
| 异常 | 缺面板/跳转/工具配置给对应替代；数据目录不可写禁止新写，源码只读与信任分别判断；迟到响应不串项目 |
| 验收 | P2-AC01/06/09：安装到导出闭环、多目录切换与三入口单写 |

### 4.2 P2-FR02 系统与运行时

| 项目 | 说明 |
| --- | --- |
| 输入 | 目标OS/版本、核心运行时、依赖锁文件、扩展与核心制品 |
| 操作 | 在至少一个新增系统安装并运行本地闭环，验证锁、IPC、凭据、路径、刷新与恢复 |
| 输出 | 每个实际组合的兼容记录、制品摘要、原始验证证据和不支持原因 |
| 规则 | 上层合同一致，平台差异局限适配器；新系统不自动扩展被测语言自动执行范围 |
| 异常 | 运行时缺失/不兼容明确失败；未测标untested。凭据后端不可用只阻塞需要该凭据的能力，不回退明文存储 |
| 验收 | P2-AC02：真实新增系统及失败注入，不能用模拟系统替代实测 |

### 4.3 P2-FR03 定位与行内标注

| 项目 | 说明 |
| --- | --- |
| 输入 | 问题/证据/链路已有位置、项目/绑定/源码快照修订、相对路径和可选行号/符号 |
| 操作 | 打开执行快照；显式校验当前目标文件后跳转；在可视文件展示关联问题、Mock与缺口 |

| 验收 | P2-AC03/04：同元数据异内容、再编辑、多文件校验、迟到响应与只读展示 |

### 4.5 P2-FR05 能力诊断

| 项目 | 说明 |
| --- | --- |
| 输入 | 宿主能力探测事实、实例与版本、工作空间可写性、项目信任和已有环境连接记录 |
| 操作 | 启动或显式重检；查看缺项、调用错误与下一步；权限/信任变化上报核心 |
| 输出 | CapabilityState与独立ConnectionState，统一健康DTO及替代入口 |
| 规则 | 核心应用唯一持久化；探测存在性与实际调用失败分别记录；可替代能力缺失为降级，不代替运行时权限校验 |
| 异常 | 截止时返回已完成探测和具体卡点；记录不可写禁止新运行/新导出登记；模型坏只影响AI |
| 验收 | P2-AC02/06/08：逐项缺能力、多宿主上报及权限中途变化 |

### 4.6 P2-FR06 历史与面板增量

| 项目 | 说明 |
| --- | --- |
| 输入 | 一期Run/Report/DecisionDTO、源码身份、环境连接，以及本期图投影 |
| 操作 | 按源码分组、条件区分查看历史；展开报告修订；设置页自检；从缺口聚焦图节点 |
| 输出 | 历史只读视图、四组环境事实、缺口与记录的导航 |

| 异常 | 无历史、记录损坏、图或节点缺失分别提示；缺图仍可读统计与证据；查看旧运行不覆盖当前活动运行 |
| 验收 | P2-AC07/08：分组、多修订、历史返回、自检与缺节点回退 |

## 5 操作导航与共享合同

| 入口 | 完成的任务 | 复用合同 |
| --- | --- | --- |
| 历史页 | 找到同一源码下不同范围和环境的运行，展开报告修订 | 一期报告查询、当前结论键及永久留存 |
| 设置自检 | 查看依赖环境、运行时/依赖、业务目标/数据、模型连接 | doctor与connectivity，不另算健康规则 |
| 图与源码 | 节点到证据、问题或已核实源码位置 | 精确业务ID/修订，定位只读 |
| 编辑器诊断 | 确认可用入口和替代方式 | 共用核心动作、单写存储与协议错误 |

二期新增记录经既有工作单元保存；定义缺失不意味着允许凭推断重建旧图，用户可根据仍在的来源生成一个新的图定义。既有业务记录与报告始终可独立读取。
