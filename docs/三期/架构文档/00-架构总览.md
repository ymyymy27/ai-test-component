# 三期架构总览：只上传

版本：2.4  
更新日期：2026年9月21日  
状态：修订基线，待实现与实测；文档不代表产品已通过验收。

范围仅P3-FR01账号关联和P3-FR02结果上传，P3-AC01—08。平台提供账号/参与项目/接收与回执；插件实现会话使用、冻结投影、候选/提交、查询/补缺与本地状态。

| 层 | 增量 |
| --- | --- |
| 应用 | collaboration/account_session、result_delivery |
| 领域/数据 | identity/accounts、delivery/submissions；与测试判定分离 |
| 适配器 | AccountPort与ResultSubmitterPort出站实现 |
| 凭据 | 按账号增加令牌引用命名空间 |
| 视图 | 账号/项目设置和本账号提交队列 |
| 存储 | 沿用工作单元，新增候选游标、不可变提交/回执、脱敏产物引用 |

不实现接收用例、共享查询、跨账号审核、ASGI宿主、HTTP服务路由或远程MCP。历史参考中的这些模块不进入插件依赖图或验收。

本地核心可选加载上传模块，不经过平台宿主。平台依赖导入/连接失败仅标上传不可用；发送请求在事务外、独立于执行通道，候选由本地提交游标恢复，防止提交成功后尚未入队时崩溃漏结果。

先完成[账号合同](01-账号与项目关联.md)与[上传合同](02-结果上传.md)，平台接口四项前置明确后实现和对拍。平台不可用时一期/二期原功能全部保持；该要求不表示存储本身不可写时仍可运行。

## 对接与隔离验证

| 责任 | 插件完成内容 | 平台前置 |
| --- | --- | --- |
| 身份与参与 | 会话使用、精确账号引用、绑定/策略确认 | 会话取得/刷新、账号/项目标识及参与检查 |
| 已保存结果传输 | 投影、冻结清单、候选/游标、发送/查询/补交 | 提交方式、限制与错误语义、原号查询 |
| 接收确认 | 逐对象摘要/修订/归属核对及本地状态 | 完整回执和缺对象表达 |
| 平台不可用 | 只降上传、保留材料、本地继续 | 不要求平台在线才能启动本地核心 |

验证平台SDK缺失/导入失败、会话过期、接口未配置、断网、回执冲突和队列压力时的本地闭环。会话与上传模块可选装配，失败不能连带阻断一期模块导入。三期八项AC只检验插件账号关联与上传行为，平台内部存储/审核/宿主不纳入本地工程。
