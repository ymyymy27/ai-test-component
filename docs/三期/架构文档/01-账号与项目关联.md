# 三期架构01：账号与项目关联

版本：3.2  
更新日期：2026年9月23日  
文档类型：工程设计文档

AccountPort由出站平台适配器实现，核心只使用验证后会话，不从正文/显示名/本地责任人推断身份。

## 1 记录与账号键

预览校验与发送授权分开：核心先核对当前account_key、项目/Submission归属及冻结manifest_hash，再返回安全对象流；预览本身不产生发送许可。账号切换使原会话的预览流和缓存失效；每次分块读取仍核对会话与归属。列表无正文限制不适用于本账号的独立安全预览，详细交互见[上传面板](../设计文档/01-账号与上传面板.md#2-列表与冻结预览)。

AccountRef=(issuer,account_id,display_name)，前两项按平台合同保留精确值；不能整体lower。issuer规范化必须双方合同约定，不擅自改变account_id大小写。account_key=SHA-256(版本化规范JSON编码[issuer,account_id])，目录使用固定安全十六进制分量，真实标识仍在记录中，校验任何解析路径不逃出outbox。

SessionContext含账号、会话ID、修订、有效性与SecretRef；ProjectMembership只缓存显示，不作为发送时参与证明；PlatformProjectBinding含本地项目、平台项目、可选Git关联、接收目标、上传策略、账号和修订，不能与LocalProjectBinding混用。

plain只需选参与平台项目；Git关联不存在则按平台合同说明缺项，不能因本地无Git阻断上传。采集来源与实际上传账号分别保存，登录不回写旧本地来源。

### 模块职责

本册负责"谁来用、属于哪个项目"。账号与项目参与关系**由平台维护**，插件只读取并引用。

### 子域结构

```text
application/collaboration/account_session.py   # 登录会话、项目与仓库同步、绑定修订
infrastructure/adapters/account.py             # AccountPort 实现
infrastructure/credentials.py                  # 三期增加令牌命名空间（保存/清除）
domain/identity/accounts.py                    # 账号引用与项目参与模型（三期定义）
```

`AccountPort` 在一期 `ports.py` 中只预留**名称与用途**；**方法签名与返回类型在本期（三期）定稿**并登记进 `application/ports.py`，实现于 `adapters/account.py` 并在 `bootstrap.py` 注册（口径见[总体架构](../../总体架构.md)第4节）。

### 记录

| 记录 | 核心字段与约束 |
| --- | --- |
| `SessionContext` | 账号引用、会话编号、到期时间、凭据引用、会话修订；由验证后的会话构造 |
| `ProjectMembership` | 账号引用、平台项目编号、项目名称、参与状态、关联仓库清单、核对时间；缓存只供展示 |

## 2 会话与在途请求

同账号刷新请求合并，成功须身份不变；改变身份结束旧会话。退出/切换递增session_revision，停止尚未发出的提交，清令牌与界面缓存，保留候选/冻结材料。已发网络请求可能成功，迟到响应核对原账号/绑定/请求后只更新原提交，不能移交新账号。

发送前及最终确认按平台合同检查参与关系和目标绑定；平台不可用时保持本地待核实候选，不据旧缓存宣称可上传。重新登录原账号只解除认证障碍，核实同一绑定、暂停原因已解决且发送许可有效后可恢复PAUSED原提交；ABANDONED不自动恢复，其迟到回执和再次发送按上传分册处理；变目标或材料/投影策略须新提交；仅发送模式或暂停变化按三期功能第7节重授许可。

## 3 凭据和离线材料

令牌正文在OS凭据后端，工作空间只引用；切账号只清令牌，不删除待发送材料。轮换给在途请求保留必要引用至收尾后按会话策略清除，不能永久保留失效令牌正文到日志。

outbox是脱敏明文产物及引用，按账号隔离归属，依赖OS用户权限；同OS用户其他进程可读，不承诺额外加密保密。无账号的DeliveryCandidate仅有本地来源，不自动落入随便一个账号分区；用户显式关联后再冻结账号提交。

验收P3-AC01/02/03：大小写敏感账号、含路径分隔符issuer/id、并发刷新、切账号迟到响应、非Git绑定和离线候选。

上传绑定同时明确SendPolicy，默认manual；账号/接收目标/材料范围变化须新策略确认，不能从登录成功推断允许自动发送。已冻结提交继续原归属，改变新提交目标不重写旧提交。模型供应方策略不属于账号绑定。

## 4 使用点核对与令牌生命周期

| 时点 | 核对内容 | 失败结果 |
| --- | --- | --- |
| 取得/刷新会话 | 由平台验证的issuer/account_id、会话修订、凭据引用和有效性 | 身份不一致结束原会话，不改旧材料归属 |
| 展示项目列表 | 平台项目标识、名称、参与状态、可选仓库及核对来源 | 旧缓存明确标只供展示，不能据此发送 |
| 冻结提交 | 会话、项目参与、目标绑定与SendPolicy修订 | 候选保留待处理，不伪造成功提交 |
| 发请求前 | 当前会话及策略仍允许该冻结账号/目标/类别 | 停止尚未发出的请求，已发请求保留核对路径 |
| 核对回执 | 原请求的账号、项目、提交、绑定/内容与对象摘要 | 归属不符不写到新账号，按冲突记录 |
| 退出/切换 | 清凭据后端令牌及临时界面上下文，递增会话修订 | 不删除候选、投影、回执与永久事实 |

令牌引用命名空间与账号安全摘要关联，不从显示名或原始含路径分隔符的账号拼接目录。刷新请求按原会话合并；并发结果核对expected_revision，过期结果不能覆盖新会话。在途操作只保留核对其结果所需的引用/上下文，退出不保留可供新请求使用的旧令牌。

重新登录不会自动认领未关联候选，亦不会恢复ABANDONED；用户确认账号与目标后处理。账号服务失败只降上传能力。AccountPort提供商定的登录/刷新/参与查询能力，方法签名随真实平台合同落定，不引入接收会话注入或远程宿主实现。

### 参与关系核对

| 时点 | 核对内容 | 失败处理 |
| --- | --- | --- |
| 上传准备 | 会话 + 项目参与 + 绑定修订 | 保留本地候选；未核实前不创建可发送许可 |
| 上传完成 | 同上 + 内容修订 | 拒绝提交，保留缺口 |
| 平台准备/原号查询能力 | 平台据实际会话识别账号并核对项目/来源；插件只核对返回归属 | 查询可返回缺口或同一完整回执，不返回无权项目内容；方法名由平台合同确定 |
| 平台完整接收确认能力 | 实际会话/目标、清单摘要、逐对象上传摘要和修订一致 | 插件核对不通过则保留缺口或冲突；平台内部实现不在插件范围 |

- 平台身份来源按其认证合同确定；插件不从正文自填账号、显示名或本地缓存推断授权。不提供宿主会话注入实现；无有效会话时保持候选和暂停原因，不降级匿名发送。平台内部如何接收和核对由平台负责。

检查不可用时返回具体错误，**不把旧缓存当成当前参与证明**。

### 凭据分区

| 项 | 约定 |
| --- | --- |
| 令牌类凭据 | 登录会话令牌；退出、会话失效或切换账号时清除 |
| 存放 | 由凭据设施保存正文，工作空间与落盘记录中只保存逻辑引用；令牌不进入日志、导出与面板 |
| 轮换 | 平台要求轮换时替换令牌引用并保留旧引用用于在途请求的收尾；轮换记录写入诊断 |
| 换机器 | 重新登录即可恢复；未登录时共享功能不可用，**本地记录与待发送材料不受影响** |

`outbox` 中的待发送材料**不做应用层加密**：按账号键分目录保存，依赖"工作空间属于单个操作系统用户 + 用户数据目录权限"保护。理由：应用层加密需要一个独立于令牌长期保留的密钥，而该密钥的跨机器恢复在当前凭据后端（Windows 凭据管理器或编辑器 SecretStorage）下没有实现路径；引入它会把"待发送材料"变成一个取不回来的黑盒，代价大于收益。因此三期只要求"**令牌与材料分区、引用可解析、重新登录可继续补交**"三条行为。

令牌的具体后端由凭据设施决定（见[一期存储与恢复](../../一期/架构文档/04-存储与恢复.md#5-凭据诊断与重试)第5节）。

**同机可读性（如实声明）**：`outbox` 不做应用层加密，因此**同一操作系统用户下的其他进程理论上可读取**；插件不承诺防止同一OS用户进程读取文件，用户需自行控制机器账户与目录权限。账号/队列列表只显示摘要；当前账号可在独立受控预览中查看其Submission的冻结安全投影，禁止展示原始密钥/原始敏感材料，也不允许从当前账号会话预览其他账号材料。跨账号共享场景下，材料按 `account_key` 分区隔离的是"账号归属与补交对象"，不是"防同机读取"。

### 与三期其他分册的关系

| 交互 | 方向 | 说明 |
| --- | --- | --- |
| 会话校验 | 本册 → 平台外部接口 | 会话由连接校验后注入，不由命令正文设置 |
| 密钥分区 | 本册 → 一期凭据设施 | 令牌按账号分区保存与清除；`outbox` 材料不加密、不随令牌清除 |

| 验证主题 | 关键检查 | 场景 |
| --- | --- | --- |
