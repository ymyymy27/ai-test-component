# 三期架构01：账号与项目关联

版本：2.5  
更新日期：2026年9月21日  
状态：修订基线，待实现与实测；文档不代表产品已通过验收。

AccountPort由出站平台适配器实现，核心只使用验证后会话，不从正文/显示名/本地责任人推断身份。

## 1 记录与账号键

AccountRef=(issuer,account_id,display_name)，前两项按平台合同保留精确值；不能整体lower。issuer规范化必须双方合同约定，不擅自改变account_id大小写。account_key=SHA-256(版本化规范JSON编码[issuer,account_id])，目录使用固定安全十六进制分量，真实标识仍在记录中，校验任何解析路径不逃出outbox。

SessionContext含账号、会话ID、修订、有效性与SecretRef；ProjectMembership只缓存显示，不作为发送时参与证明；PlatformProjectBinding含本地项目、平台项目、可选Git关联、接收目标、上传策略、账号和修订，不能与LocalProjectBinding混用。

plain只需选参与平台项目；Git关联不存在则按平台合同说明缺项，不能因本地无Git阻断上传。采集来源与实际上传账号分别保存，登录不回写旧本地来源。

## 2 会话与在途请求

同账号刷新请求合并，成功须身份不变；改变身份结束旧会话。退出/切换递增session_revision，停止尚未发出的提交，清令牌与界面缓存，保留候选/冻结材料。已发网络请求可能成功，迟到响应核对原账号/绑定/请求后只更新原提交，不能移交新账号。

发送前及最终确认按平台合同检查参与关系和目标绑定；平台不可用时保持本地待核实候选，不据旧缓存宣称可上传。重新登录原账号只解除认证障碍，核实同一绑定、暂停原因已解决且发送许可有效后可恢复PAUSED原提交；ABANDONED不自动恢复，其迟到回执和再次发送按上传分册处理；变目标或材料/投影策略须新提交；仅发送模式或暂停变化按三期功能第7节重授许可。

## 3 凭据和离线材料

令牌正文在OS凭据后端，工作空间只引用；切账号只清令牌，不删除待发送材料。轮换给在途请求保留必要引用至收尾后按会话策略清除，不能永久保留失效令牌正文到日志。

outbox是脱敏明文产物及引用，按账号隔离归属，依赖OS用户权限；同OS用户其他进程可读，不承诺额外加密保密。无账号的DeliveryCandidate仅有本地来源，不自动落入随便一个账号分区；用户显式关联后再冻结账号提交。

验收P3-AC01/02/03：大小写敏感账号、含路径分隔符issuer/id、并发刷新、切账号迟到响应、非Git绑定和离线候选。

上传绑定同时明确SendPolicy，默认manual；账号/接收目标/材料范围变化须新策略确认，不能从登录成功推断允许自动发送。已冻结提交继续原归属，改变新提交目标不重写旧提交。模型供应方策略不属于账号绑定。

## 4 使用点核对与令牌生命周期

| 时点 | 核对内容 | 失败结果 |
| --- | --- | --- |
| 取得/刷新会话 | 由平台验证的issuer/account_id、会话修订、凭据引用和有效性 | 身份不一致结束原会话，不改旧材料归属 |
| 展示项目列表 | 平台项目标识、名称、参与状态、可选仓库及核对来源 | 旧缓存明确标只供展示，不能据此发送 |
| 冻结提交 | 会话、项目参与、目标绑定与SendPolicy修订 | 候选保留待处理，不伪造成功提交 |
| 发请求前 | 当前会话及策略仍允许该冻结账号/目标/类别 | 停止尚未发出的请求，已发请求保留核对路径 |
| 核对回执 | 原请求的账号、项目、提交、绑定/内容与对象摘要 | 归属不符不写到新账号，按冲突记录 |
| 退出/切换 | 清凭据后端令牌及临时界面上下文，递增会话修订 | 不删除候选、投影、回执与永久事实 |

令牌引用命名空间与账号安全摘要关联，不从显示名或原始含路径分隔符的账号拼接目录。刷新请求按原会话合并；并发结果核对expected_revision，过期结果不能覆盖新会话。在途操作只保留核对其结果所需的引用/上下文，退出不保留可供新请求使用的旧令牌。

重新登录不会自动认领未关联候选，亦不会恢复ABANDONED；用户确认账号与目标后处理。账号服务失败只降上传能力。AccountPort提供商定的登录/刷新/参与查询能力，方法签名随真实平台合同落定，不引入接收会话注入或远程宿主实现。
