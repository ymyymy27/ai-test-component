# 文档总览

本仓库是「AI 辅助测试插件」一期实现：Python 核心 + Trae 薄扩展 + 共享面板。文档**按期次分**：`docs/项目文档/一期/`、`docs/项目文档/二期/`、`docs/项目文档/三期/`；期次内部按文档类型分 `01-项目 / 02-需求 / 03-设计 / 04-架构 / 05-测试验收 / 06-发布运维`。

**事实优先级（从高到低）**：代码与测试 → `tests/acceptance/*/status.json` → 该期次现行合同 → 计划/简报 → 历史记录。任何文档与代码冲突，以代码为准并在该文档的「偏差记录」里写明。

## 5 文档规则

1. **一个事实只有一个主责位置**：判定与统计只在一期 02-需求/03 第 3 节，有限查询只在一期 04-架构/05 第 4 节，上传 schema 只在三期 04-架构/03；其他文档写「见 X」。
2. **事实优先于叙述**：路径、命令、字段、状态以代码和 `status.json` 为准；每份文档末尾保留「偏差记录」。
3. **不代填验收**：`verified` 必须同时有真实环境验证和非空 `evidence.path`；组件测试、文档一致、历史批次通过都不能升级状态。
4. **不复制数字**：规模、门禁、版本只在 `现状.md` 维护一处。
5. **归档不腐化**：归档保留原结论、失败与路径；新结论写现行文档。
6. **链接与命令必须可解析**：新增或修改后检查目标存在，不写构建产物与本机绝对路径。
