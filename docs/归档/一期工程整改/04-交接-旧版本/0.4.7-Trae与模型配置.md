# 0.4.7 Trae 与模型配置

本版在 0.4.6 完整本地样例链基础上补齐 Trae → 核心的模型配置通路。真实界面验收记录见[本批证据](../../validation/p1-trae-live-20261016/README.md)。

1. 安装同版本 wheel 和 VSIX；`AI Test: 配置工作空间与项目` 选择装有本包的 Python 3.13 和专用用户数据目录。
2. 机器级 `aitest.modelConfigurationFile` 指向操作者维护的绝对 JSON 路径。不要把凭据正文填写在编辑器设置、JSON、计划、提示或高级操作框。
3. 配置只有下列字段；`credential_reference` 对应 Windows Generic Credential 的目标 `aitest/model/<引用>`，正文按 UTF-8 保存，由系统保护。

```json
{
  "schema_version": "aitest.model-provider/1",
  "endpoint": "https://api.deepseek.com",
  "credential_reference": "your-model-credential-reference"
}
```

4. 核心启动时冻结端点与引用。改变配置后先受控排空旧核心再重启；不能强杀有活动/未知执行的核心。
5. 项目模型出站策略仍须确认准确端点、模型与允许材料类别。配置只提供传输能力，不替代业务策略确认或自动发送私有项目材料。
6. 真实供应方失效、凭据缺失、配置不合法只影响模型相关动作；本地计划保存、执行、报告等能力按各自动作依赖判断。

本机接入时官方模型列表已返回当前可用模型；测试实际使用 deepseek-flash，只发送连通性提示。用户锁屏期间无法验证面板交互，不能写成真实 Trae 全功能通过。
