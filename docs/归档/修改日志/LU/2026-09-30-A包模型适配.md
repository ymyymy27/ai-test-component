# 2026-09-30-A包模型适配

## 1. 本次实现概述

补齐 `infrastructure/adapters/model.py` 占位模块，实现 OpenAI 兼容的 HTTPS 模型调用：可替换传输层（默认 urllib），请求只含已投影材料、凭据只在 Authorization 头，归一认证/限流/输入限制/传输/结构错误；成功只回草稿与供应方请求号，不重试、不切换供应方、不产生业务结论。

## 3. 落地的约束清单

- 请求正文只能含已投影材料；凭据只在 Authorization 头，不进日志或错误转储（detail 截断响应体 512 字节）。
- 不重试、不隐式切换供应方；错误按类别归一。
- 成功只表示得到草稿，不代表业务结论。
- 传输层可替换，测试对真实本地服务器执行而非全 mock。
- 不改动 B/C/D 包任何代码。
