# 2026-09-30 A包Python版本适配

## 触发原因

补齐上一轮自测报告列出的"已知未验证项"之一：
Python 3.13 上未复跑（实际环境为 3.14.7，需要 `PYTHONPATH=src` 运行测试）。
本轮调整 pyproject.toml 兼容 3.13/3.14，并让 pytest 默认把 `src`
纳入 `pythonpath`，免去手动设置环境变量。

## 改动文件

### 修改

- [pyproject.toml](file:///c:/Users/Lenovo/Desktop/zhiyin/ai-test-component/pyproject.toml)
  - `requires-python` 从 `>=3.13,<3.14` 放宽到 `>=3.13,<3.15`：
    工程基线 py3.13，运行验证扩展至 py3.14.7；
    注释说明"3.13 与 3.14 行为差异未触发本包 API 兼容性问题，
    新代码避免使用 3.14 独有语法"。
  - `[tool.pytest.ini_options].pythonpath` 从 `["."]` 改为 `["src", "."]`：
    让 `pytest tests` 无需手动 `PYTHONPATH=src` 即可解析 `aitest` 模块；
    保留 `.` 让 tests/ 内 conftest 与相对导入可用。
  - `[tool.mypy]` 注释说明"mypy 用 3.13 目标检查可同时覆盖 3.14 兼容场景"。

## 验证

不设置 `PYTHONPATH` 环境变量，直接 `python -m pytest tests` 即可
解析 `aitest` 模块：

```
python -m pytest tests/unit/test_a_pipe_peer_rejection.py -q
......................                                                   [100%]
22 passed
```

之前需要 `$env:PYTHONPATH = "...src"`；现在直接 `python -m pytest`
即可运行，与 pip 安装环境（3.13）和无安装环境（3.14.7）都兼容。
