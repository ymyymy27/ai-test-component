# 2026-09-30-A包安全投影

## 1. 本次实现概述

补齐 `infrastructure/projections.py` 占位模块，实现冻结策略的安全字节投影：逐项进行源码片段闸门、凭据标记行过滤、非文本/超限排除，全部摘要为真实字节 SHA256，无法安全处理的材料进入排除项并标记 PARTIAL。

## 2. 新增/修改文件清单

- `src/aitest/infrastructure/projections.py`
  - 新增 `SafeMaterialProjector`（ProjectionPort 生产实现）：
    - `source_snippet` 类别受全局开关约束，关闭即整类排除；
    - 命中已知凭据标记（api_key/password/authorization 等）的整行丢弃，全为凭据行则整项排除；
    - 含非法 C0 控制字符（疑似二进制）或超过 256 KiB 单项上限的材料排除；
    - 每项 digest 为投影文本真实 SHA256，整批 projection_digest 为规范序列化后的真实 SHA256，确定性可复算。
  - 导出策略常量 `POLICY_REVISION`、`ITEM_LIMIT_BYTES` 与 `sha256_text`。
- `src/aitest/application/ports.py`
  - `ProjectionPort` 正式化为 `project(*, material, source_snippets_enabled) -> Projection`；新增对 `application.planning.model_ports.Projection` 与 `domain.planning.model_outbound.MaterialKind` 的引用及 `Mapping` 导入。
- `tests/unit/test_a_projections.py`
  - 新增 10 项单元测试：干净材料完整投影与真实摘要、整批摘要确定性、源码片段关/开、凭据行过滤保留其余、全凭据行排除、控制字符排除、超限排除、空材料 PARTIAL、helper。

## 3. 落地的约束清单

- 投影只处理显式选定材料，不自行扩大范围。
- 源码片段开关作用于全部出站类别，不允许通过其他字段夹带。
- 不做“替换后放行”的乐观脱敏；凭据命中行直接丢弃，无法安全投影即排除。
- PARTIAL 必须列出排除项，禁止用“投影成功”掩盖缺口。
- 摘要只来自真实字节，可独立复算；策略版本显式携带。
- Projection 类型复用 B 侧已冻结的 application 层定义，不另起第二套。
- 不改动 B/C/D 包任何代码。

## 4. 重要备注

- 凭据标记集合与一期 capture 过滤合同保持一致，但不承诺识别任意变形秘密。
- 单项 256 KiB 上限为保守缺省；策略演进时须递增 POLICY_REVISION。
- 投影器无状态、无 I/O；尚未接入模型调用编排（接入属后续接线项）。
