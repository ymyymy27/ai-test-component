## 3. 落地的约束清单

- 同一工作单元不能同时开启两个写事务。
- `commit` 后记录按准确 revision 可读。
- `rollback` 后暂存记录不可见。
- 同一 `request_id` 和相同输入只执行一次；相同请求身份配不同输入返回冲突。
- 写命令禁止将 `request_id` 作为 `intent_id`。
- 同一 `intent_id`、相同载荷复用原 revision；载荷变化显式冲突。
- 索引缺失返回 `maintenance_required`，即使记录文件存在也不扫描记录文件。
- 无效游标返回 `invalid_cursor`。
- 固定排序和有界游标分页结果稳定。
- 永久记录只追加，历史 revision 保留，仓储不暴露删除接口。

## 4. 重要备注

- 测试以真实临时目录调用文件后端，不使用内存假存储作为 Windows 后端验收证明。
- 本次是单元测试，不能替代真实 Windows 多进程锁、掉电恢复、权限拒绝和原子替换故障注入验收。
- 测试不包含 B/C/D 业务逻辑，也不判断业务通过或失败。
