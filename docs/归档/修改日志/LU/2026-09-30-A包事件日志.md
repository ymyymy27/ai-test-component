# 2026-09-30-A包事件日志

## 1. 本次实现概述

补齐 `infrastructure/file_store/events.py` 占位模块，实现正式事件日志（信封 `aitest.event/2.0`）：提交边界、快照游标、事件续读、重复事件幂等去重，并具备崩溃后的尾行修复与边界核对能力。

## 2. 新增/修改文件清单

- `src/aitest/infrastructure/file_store/events.py`
  - 新增 `FileEventJournal`：边界暂存（`staging/<commit>.jsonl`）+ 仅含已提交事件的追加日志（`journal.jsonl`）+ 边界标记（`boundaries/<commit>.json`）+ 位置文件（`position.json`）。
  - 边界处理：`begin_boundary` / `record_event` / `commit_boundary` / `rollback_boundary`；事件只在提交后进入 journal，序列全日志连续。
  - 快照游标与事件续读：不透明游标 token（base64 编码最后序列），`read(cursor, limit)` 支持翻页续读；`snapshot_cursor(commit_sequence)` 返回提交边界末尾游标。
  - 重复事件去重：`event_id` 由事件身份元组（instance/commit/type/project/record/revision）确定性派生，边界内重复追加返回既有事件；重复提交边界返回 `already_committed`。
  - 崩溃恢复：尾部损坏行隔离至 `quarantine/` 并截断；历史行损坏返回 `maintenance_required`，不静默截断历史。
  - 恢复核对：`reconcile(committed_sequences)` 以提交清单为事实来源，补提交已确认边界、登记孤立暂存（不自动重放、不删除）。
  - 新增数据类 `BoundaryHandle`、`EventReadResult`、`ReconcileReport` 与游标编解码函数。
- `tests/unit/test_a_event_journal.py`
  - 新增 15 项单元测试：边界生命周期、游标翻页续读、非法游标结构化状态、边界内幂等、重复提交幂等、回滚隔离、快照游标、跨边界序列连续、尾行修复、恢复核对。

## 3. 落地的约束清单

- journal 中每行均为已提交事件，`event_sequence` 全日志连续、单调递增。
- `event_id` 确定性派生，同一事务重放（重试/恢复）不产生重复事件。
- 游标为不透明 token，调用方无法也不应解析其内部结构。
- 崩溃只允许修复尾部；历史损坏一律进入维护状态，不丢历史。
- 恢复不自动重放未知副作用；孤立暂存只登记、保留，交人工恢复。
- 回滚边界的暂存事件隔离保留以备核查，不写入正式日志。
- 仅使用标准库 + pydantic + 本包合同模块，未引入新依赖。
- 不改动 B/C/D 包任何代码；不改动已有稳定骨架。

## 4. 重要备注

- 新事件日志位于 `event-log/`，与既有 `events.json`（`commit_transaction` 的非 正式事件投影）目前并存；后续质量门迭代再将 UOW 事件发布切换到正式日志。
