# 2026-09-30-A包连接适配

## 1. 本次实现概述

补齐 `infrastructure/connections.py` 占位模块，实现端点配置解析/校验与 socket 级真实传输探测，传输错误归一为 DNS/超时/拒绝/不可达四类；只产生事实，不做 HTTP 请求、不带凭据、不重试不睡眠（重试口径唯一在应用层）。

## 2. 新增/修改文件清单

- `src/aitest/infrastructure/connections.py`
  - `EndpointConfig`：冻结端点配置，`from_address` 解析 scheme/host/port，仅允许 http/https，缺省端口按 scheme 归一（443/80）。
  - `TransportFact`：可达性、毫秒级耗时、归一错误类别与原始 detail。
  - `ConnectionProbe.probe(endpoint, timeout)`：真实 TCP 连接探测；`classify_os_error` 归一 gaierror/TimeoutError/ConnectionRefusedError/OSError。
  - `EndpointError`、`TransportErrorKind`。
- `tests/unit/test_a_connections.py`
  - 新增 9 项单元测试：完整地址解析、缺省端口、非法 scheme、缺主机、本地监听可达、关闭端口拒绝/超时、DNS 失败、非正超时拒绝、错误归一。

## 3. 落地的约束清单

- 仅接受 http/https；主机与端口显式校验，拒绝隐式猜测。
- 探测只做 TCP 连接事实，不夹带凭据或业务载荷。
- 不实现重试与睡眠；唯一重试策略保留在 `application/connectivity.py`。
- 错误类别在传输层归一，与认证/限流/结构错误分层。
- 耗时与错误均为真实测量，未知不猜测。
- 不改动 B/C/D 包任何代码。

## 4. 重要备注

- 实测本机 Windows 11 对本机关闭端口返回 connect 超时（errno=None）而非立即拒绝；测试按真实行为接受两类结果。
- DNS 测试依赖 `.invalid` 保留 TLD 不可解析；受限网络环境可能表现为其他错误。
- 探测尚未支持 TLS 握手核对与代理场景。
