# 2026-09-28-A包协议与身份

## 背景/目的
为 A 包本地核心底座固定 `aitest.local/2.0` 协议下的传输请求身份与业务意图身份，避免跨入口重试和业务幂等混用身份。

## 核心改动
- `src/aitest/contracts/identity.py`：新增 `RequestId` 与 `IntentId` 严格字符串值类型，限制为空白、空值、超长及含空白字符的身份值。
- `src/aitest/contracts/commands.py`：将命令的 `request_id`、`intent_id` 接入值类型；写动作拒绝使用相同值承载传输请求和业务意图。
- `src/aitest/contracts/__init__.py`：导出两个身份类型。
- `src/aitest/contracts/schemas/Command.json`：通过生成脚本同步协议 Schema。
- `tests/contracts/test_identity.py`：增加身份格式和 request/intent 分离的合同测试。

## 对接情况
协议版本沿用 `aitest.local/2.0`；B/C/D 尚未修改。A 包继续提供统一合同，调用方通过现有 `Command` 接口传递身份字段。

- 当前工作区未安装 pytest，合同测试尚未执行；已使用 Python 冒烟校验确认有效命令和同身份写请求的拒绝行为。
- 后续实现 A 包存储层时，需将 `intent_id` 与业务幂等结果在同一工作单元中持久化。
