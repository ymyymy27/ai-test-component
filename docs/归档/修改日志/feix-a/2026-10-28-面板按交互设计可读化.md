### 面板（`src/aitest/resources/panel/src/`）

- **当前测试**：控制状态徽标 + 业务结论徽标（按 passed / failed / incomplete 上色）；按当前状态只显示合法动作（运行中→暂停/取消，已暂停→继续/取消，终态不显示控制按钮）；自动步骤计数与进度条；「待你操作」按 待人工 → 待核验 → 阻塞 → 待执行 取第一条并带用例名与步号；统计与来源收进折叠区；空状态提供「读取本次运行」主按钮，并在 `doctor` 回执到达后重试自动读取。

- **测试计划**：按运行视图的 `plan_revision_ref` 读取一次计划记录，显示计划修订、用例层级 L1/L2/L3、必测标记与断言依据状态。记录视图的载荷在 `record` 下（不是顶层），解析按此路径。读取失败时在区块内显示失败原因，不静默降级。
- **工作台**：进入时自动选中"该处理的那一步"；标题带层级、检查名称与必测标记；新增「当前缺口」与「断言依据」；缺口附下一步动作；换运行后清空旧的步骤选择。
- **报告**：结论徽标、缺口原因与补法、三列计数（本轮执行 / 有效复用 / 有效验证）、覆盖结论两行、需要补齐的证据、结果来源（源码 / 环境 / 计划修订）、范围与冻结说明；「去核验」直达待核验的步骤；新增「本地复核」表单，提交 `record_local_review`（`expected_revision=0`，参数集合与核心校验一致）。
- **测试记录**：运行视图到手后自动读取报告修订列表，另提供「读取最近报告」手动入口；读取失败时原样显示回执。
