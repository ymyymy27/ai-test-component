## 2. 使用边界

- 归档文件保留其所属版本的数字、结论和链接；后续修复写新日志/新批次，不回写旧记录。
- 归档中的构建产物、临时日志和本机绝对路径可能未入库；由此产生的断链属于历史事实，不回填。
- 需要恢复原文时，优先按归档目录中的 `documents-before.json`、`restore_commit` 或 Git 历史取回，不凭记忆重写。
- 新工作不要写入归档目录；按[文档总览](../README.md#5-新增文档约定)选择现行目录。
