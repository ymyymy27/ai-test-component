# 一期设计：Trae面板与工作台

版本：2.6  
更新日期：2026年9月21日  
状态：开发基线，待实现及真实界面验证。

覆盖P1-FR01—17，判定只读核心DTO；操作区调用核心用例。无二期图/高级源码分组或三期账号。规则见[一期功能](../功能文档/01-功能文档.md)，首发方式见[能力与模板](../功能文档/02-能力与模板清单.md)。

## 1 导航与首次使用

主导航保留：当前检查、项目与计划、工作台、报告与问题、设置。首次默认快速检查；有历史时显示上次明确选择，不自动升级为完整。

| 阶段 | 必填与操作 | 不阻塞项 |
| --- | --- | --- |
| 选择目录/目的 | 确认单模块草稿或实际模块；选择快速/按需/完整 | Git远端、平台账号不是本地前提 |
| 入口/环境 | 登记实际入口、解释器及本次所需环境 | 纯函数不要求数据库；关闭AI不要求模型凭据 |
| 内容准备 | 显式分析选定项目内容，或人工/模板草稿 | 无Plan也能分析；不自动执行命令 |
| 计划摘要 | 查看范围、检查项、预期、未覆盖项；确认发布 | 快速/按需不强制完整交付表；正式提测仍要求 |
| 准备/授权 | 固定源码和输入，集中逐项确认动作 | 相同有效授权不重复问；未知输入待解析后确认 |

分析展示选定范围与排除项，未保存缓冲区提示保存或明确按磁盘版本。无模板指向自建/导入，不执行猜测命令。必需能力未支持不能标不适用。

full先定义AcceptanceScope：业务目标、模块/业务范围、依赖闭包、排除理由、适用模板。只有实际全项目范围才写全项目完整通过；不允许运行中缩减范围隐藏失败。

## 2 运行前

```text
操作区：[切换检查目的] [查看计划] [查看环境事实] [逐项查看并确认]
检查目的：快速检查
验收对象：工单状态修改 / 订单服务及相关依赖
操作区：[运行快速检查]
最近固定源码：abc1234 + 差异8f3c…
当前目录尚未重新核实；准备运行时重新固定
依赖环境：本机已登记环境
本次：适用L1、变更模块关键L2、适用独立核验
结论范围：本轮覆盖，不作完整验收结论
待授权动作2项
▸ 驱动及高级选项
```

主按钮随目的为“运行快速检查/运行所选检查/运行完整验证”。按需先选检查集；快速由规则确定、完整包含范围内全部适用必测，不提供删减必测勾选。plain显示文件清单摘要，省略仓库字段。主屏不自动扫描源码。

授权清单逐项列实际目标、影响、输入与凭据范围，分别保存确认；没有全部永久信任。未解析变量待执行前确认；变化只使受影响授权失效。

## 3 运行时与生命周期

自动进度、待人工操作与阻塞分开显示；完整输出在工作台按需读取。原因说明紧邻操作区：

| 情形 | 主动作 | 行为 |
| --- | --- | --- |
| 断言失败 | 查看证据/处理问题 | 事实与假设分开 |
| 环境阻塞 | 配置该环境 | 定位具体字段，遵守运行修订边界 |
| 依据未确认 | 核对依据 | 确认不替代执行 |
| 停止未确认/副作用未知 | 核实执行状态 | 不给直接重复副作用快捷动作 |
| 待人工操作 | 继续当前步骤 | 到工作台执行并关联证据 |

暂停中、已暂停、取消中、待核实分别显示；已暂停提供恢复。活动运行常驻提示“关闭编辑器后继续”；宿主支持时退出前再提示，不依赖退出回调。重开回到同一运行，关窗口不等于取消成功。正在执行步骤不可改，后续修订仍经核心守卫。

## 4 运行后

```text
工单状态修改 / 完整验证
本轮未完成
原因：状态持久化尚未核验
[去核验] [查看报告] [导出]
适用12 · 完成11 · 失败0 · 阻塞1
▸ 证据充分性：C，关键链路3/4（查看全部缺口）
▸ 环境事实：依赖环境、数据来源/复位、目标版本
▸ 计划、授权与源码修订
▸ 上次已完成结果（仅历史参考）
```

有实际失败明确失败，不用待处理隐藏。full才有等级，quick/按需未打分；A可对应充分失败证据。未用venv不自动降级；数据污染导致核验失效时显示具体缺口。环境与证据详情分开，主要缺口允许为无。

当前结果与报告快照注明来源修订；旧结果不回退为当前绿灯。重跑新意图，导出冻结报告/复核集合/格式/策略。

## 5 报告、问题与留存

一期报告按项目/状态/运行或报告编号筛选，同运行多修订折叠。隐藏项目仅默认列表偏好，可恢复，不删除、不停止活动任务。二期才增加高级源码分组。

导出选择Markdown摘要或可携带证据包。摘要说明不随附证据；包预览包含/排除/缺失附件，生成相对路径文件与清单。不能安全投影的材料排除并说明，不宣称证据完整。

问题详情“复制修复说明”含来源修订、预期/实际、脱敏证据、事实/假设、位置或未知原因、复测入口。用户自行交给Trae/人工，不假定聊天API；新实际证据才能关闭问题。

设置显示空间组成和备份/迁移入口，无业务删除入口。报告存在不保证外部源码永远可复取，详情显示复现范围。

## 6 模型与可用性

设置独立显示模型接收地址、项目、材料类别、源码片段开关（默认关）；首次出站展示脱敏摘要并确认，变目标或扩大范围重新确认。关闭AI阻止后续发送，已发请求可能返回；人工与报告可用。模型策略不授权平台上传源码。

字段有文字标签、主操作可键盘完成；抽屉关闭后焦点返回触发按钮。窄面板折叠次要详情，不隐藏范围、结论和主动作。无记录、无模型、不可写目录分开提示。P1-AC26/27与P1-AC30—35验证完整路径；最终需真实Trae验证，不用线框代替产品证据。

## 7 页面清单、布局与返回路径

本节把前述流程展开为可实施的页面合同。以下线框只用于说明信息层级，数值是相互一致的示例，不是产品实测结果。业务编辑位于子视图，当前检查信息区只读；查看详情与控制按钮放独立操作区。

```text
当前项目：工单系统（可切换）    活动运行提示
当前检查 | 项目与计划 | 工作台 | 报告与问题 | 设置
-----------------------------------------------------
操作区：随当前流程显示主动作、次动作和阻塞原因
-----------------------------------------------------
信息区：运行前 / 运行时 / 运行后，三者之一
范围名称与本轮状态始终可见，细节可展开
-----------------------------------------------------
状态条：核心连接 · 当前目录形态 · 模型辅助状态
```

| 页面/子视图 | 入口与主要内容 | 返回与保存 |
| --- | --- | --- |
| 当前检查 | 默认入口；准备、进度、结果三段 | 从工作台返回保留所选运行，当前/历史清楚标明 |
| 项目概览 | 项目与计划；目标、模块、任务、变化与阻塞 | 保存上下文修订，不重置已有运行 |
| 任务/交付 | 项目概览→任务；验收、完成/未完成、运行方式、依赖/Mock | 草稿与正式提测分别校验，缺字段就地定位 |
| 规则/模板/计划 | 项目与计划→内容；版本、来源、适用性、用例、范围及依据 | 保存草稿和发布是两个动作，发布后修订不可变 |
| 执行授权 | 准备运行后→逐项清单；实际目标、影响、输入与凭据用途 | 每项单独确认，未知变量显示待解析；返回不自动授权 |
| 工作台 | 当前检查→步骤详情；步骤、当前尝试、执行/证据/分析/意见 | 回到当前检查保留步骤和尝试引用 |
| 证据/链路详情 | 工作台或缺口操作区；原输出、关联对象、节点和缺口 | 一期为记录列表，无图也可完成核验 |
| 问题详情 | 报告与问题→问题；复现、证据、级别/责任人、修复与回归 | 同issue_id留历史；复制修复说明不关闭问题 |
| 报告预览/导出 | 运行后或报告列表；精确报告修订、独立复核与附件 | 查看不改正文，选择摘要/证据包并预览范围 |
| 设置/维护 | 环境、模型出站、目录绑定、空间、备份/迁移 | 展示当前有效配置，修改形成修订，运行冻结值不随之改写 |

一期不显示不可用的二期历史/图或三期账号空页签。报告列表已能查历史报告，不把永久留存访问推迟到二期。

## 8 三段字段与动作矩阵

### 8.1 运行前字段

| 字段 | 显示内容 | 缺失或变化时 |
| --- | --- | --- |
| 检查目的与范围 | 快速/按需/完整、范围名称、包含模块和关键依赖 | 无范围转计划准备，不默认全项目 |
| 最近固定源码 | Git基准+差异或plain清单摘要 | 尚未固定显示未固定；当前目录未重新核实不显示“未变” |
| 环境事实 | 解释器/依赖方式、所需目标/数据条件 | 不隔离显示事实，不预告等级降为C |
| 要跑什么 | 计划修订、适用检查、必测及未覆盖项、初始驱动 | 模板/依据缺失给具体阻塞，不用空集合掩盖 |
| 待授权 | 已解析未确认动作数及待解析动作数 | 明确执行前仍需确认，不能误显“全部已授权” |

| 动作 | 可用条件 | 核心结果 |
| --- | --- | --- |
| 分析选定内容 | 目录可读，用户明确选择范围；模型出站另核策略 | analysis快照/草稿，不执行命令 |
| 查看/编辑计划 | 已有草稿或模板 | 打开计划子视图，不在信息区编辑 |
| 运行快速检查 | 已发布适用计划，实际必需输入可解析 | prepare→逐项授权→start，结论partial |
| 运行所选检查 | 按需集合已确认且已发布 | 未选项保留未执行原因 |
| 运行完整验证 | 已发布AcceptanceScope和全部适用必测，门禁满足 | 只对该范围完整验证 |

按钮不可用时同时给“缺什么”和跳转入口，不只置灰。更改目的/驱动在独立设置或计划控件中完成，信息区只显示结果。

### 8.2 运行时布局与动作

```text
操作区：[暂停] [取消] [查看步骤详情] [查看缺漏详情]
说明：关闭编辑器后当前运行仍由本地核心管理
-----------------------------------------------------
工单状态修改 · 执行中
自动步骤：已完成3/5（按实际执行完成计数）
L1 语法与入口      已完成 / 断言通过
L2 创建与查询      已完成 / 断言通过 / 真实
L2 状态修改        执行中
L3 页面刷新        待人工操作第4步
缺漏：阻塞0 · 未执行2 · 跳过0 · 缺证据0 · 真实性未知1
最近输出：请求已受理，持久化核验尚未完成
```

进度条只表示自动步骤；人工等待不伪装为正在自动执行。执行完成和业务已验证计数分开，五类缺漏可重叠，不能把它们相加当未完成总数。界面只显示脱敏最近输出，完整输出到证据详情按需读取。

| 状态 | 动作区 | 防误操作 |
| --- | --- | --- |
| 执行中 | 暂停、取消、步骤/缺漏详情 | 不允许编辑正在执行步骤 |
| 暂停中 | 查看详情、可行时取消 | 不显示已暂停，不重复发暂停请求 |
| 已暂停 | 恢复、取消、编辑未执行步骤 | 恢复前重新核对修订与授权 |
| 待人工/待授权 | 进入当前步骤/逐项确认 | 不以确认文字代替执行证据 |
| 取消中/待核实 | 查看停止状态、核实执行 | 不提供直接重复副作用快捷动作 |
| 执行结束 | 查看报告、处理问题、重跑、导出 | 新重跑新意图，保留旧记录 |

### 8.3 运行后字段

顺序为“范围与业务结果→主要原因和主动作→实际统计→证据充分性→环境/来源详情”。A/B/C/D不是放行按钮；full才显示等级，其他档显示未打分。

| 字段 | 展示要求 |
| --- | --- |
| 本轮结果 | passed/failed/incomplete/not_applicable对应通过/失败/未完成/不适用；partial清楚说明仅本轮选定检查 |
| 主要原因 | 由核心主缺口/失败原因提供，全无缺口可写无；还有其他缺口时给查看入口 |
| 覆盖 | 本轮执行完成E/S、有效复用R/S、有效验证V/S、有效通过P/失败F及未验证U、必测验证(V∩M)/M、阻塞/跳过、关键链路核验、依据确认，各自分母与单位明确 |
| 证据充分性 | full显示字母及中文含义；可以“业务失败，A证据充分” |
| 环境事实 | 依赖方式、数据来源/复位、目标部署与源码对应；与等级分栏 |
| 来源 | 当前投影来源、报告修订、旧报告/依据过期和证据可用性缺口 |

同一夹具示例：适用12、执行完成11、有效验证11、失败0、阻塞1，分别显示执行完成11/12和有效验证11/12；关键链路3/4且缺必要核验为C、业务未完成。另一例全部有效执行但一个必测断言失败，可以业务失败且A级证据。全不适用显示不适用，不显示100%。

## 9 计划编辑与测试工作台

计划页按业务目标分组用例，技术字段在详情中展开。每条展示层级、前置、输入、预期、断言依据三态、核验方法、允许Mock、必测/关键链路关联及适用性原因。已发布状态与依据是否确认分别显示，不能共用一个勾选框。full范围内适用必测没有删除勾选；运行中编辑仅对未执行步骤开放。

```text
工作台：运行R1 / 计划修订3 / 当前步骤S4 / 尝试2
左侧步骤列表          右侧步骤详情
L1 / L2 / L3          目的、前置、已解析输入、预期、执行方式
每步状态              执行状态 | 断言 | 真实性 | 人工复核
当前尝试和历史        原始证据 | AI分析（假设） | 人工意见
-----------------------------------------------------
操作区：按状态提供执行/继续、暂停、取消、补证、核实、重试
编辑未执行步骤、退回阶段均显示影响范围和修订原因
```

补证表单要求步骤/尝试、采集来源、实际操作、业务对象ID、附件与说明；无法获取的项可写未知原因，但必需证据仍是缺口。退回阶段先展示下游需重跑，不让用户误以为已有继承证据本轮已执行。失败卡片提供原始证据和问题入口，AI分析独立标签且可驳回留痕。

## 10 报告、问题及导出细节

| 视图 | 字段与动作 | 边界 |
| --- | --- | --- |
| 报告列表 | 项目、状态、Run/报告编号筛选；同Run修订折叠 | 一期不提供二期源码高级分组；隐藏项目可恢复且不停止运行 |
| 报告预览 | 范围/结果、分层、覆盖、Mock/未知、失败/阻塞、问题/回归、依据过期、证据索引、来源 | 标快照值和精确修订，不用当前配置覆盖历史 |
| 本地复核 | 复核人、决定、说明、所依据报告修订 | 单独记录，不能改报告或替代证据 |
| 导出预览 | 格式、报告/复核集合、附件包含/排除/缺失、脱敏说明 | 摘要声明不含附件；证据包相对链接可脱离插件阅读 |
| 问题详情 | 复现上下文、预期/实际、证据、事实/假设、级别/责任人、状态、修复/回归 | 修复关闭须新的实际执行；非缺陷/重复为独立处置；复制说明不执行修复 |

证据打不开时展示证据编号、原类型、缺失/损坏原因和受影响范围，不留一个失效链接假装可用。导出生成中只显示状态，校验并登记成功后才给成功结果；保存失败保留可恢复信息。新复核被选入导出时生成新导出记录，原报告正文不变。

## 11 设置字段与Git/plain形态

| 配置组 | 显示/操作 | 生效边界 |
| --- | --- | --- |
| 项目目录 | 本地目录、绑定形态、重新绑定 | 移动/形态变更新绑定修订，保留历史 |

| 位置 | Git目录 | plain目录 |
| --- | --- | --- |

## 13 空态、刷新和措辞

| 触发 | 显示与下一步 |

| 首次无项目 | 选择目录，进入最小向导，不显示虚构统计 |
| 有草稿无发布 | 显示缺项和“去确认计划”，保留已填内容 |

## 14 交互验收路径

键盘能完成首次向导、发布、逐项授权、工作台补证、问题确认、复核与导出；抽屉/弹层关闭焦点回到触发入口。阻塞原因和状态变化应可被辅助技术读取。重开/刷新恢复核心状态，项目切换不串缓存。P1-AC26/27验证只读信息与快照口径，P1-AC30—35覆盖最小配置、范围、分析、修复交接、可用性和证据包。线框及夹具不代替真实Trae验收。

## 15 确认、问题处置与恢复呈现（2.5）

人工确认弹层显示核心冻结的动作、目标、已解析输入、凭据用途与修订；实际点击后提交所属会话的挑战，不提供AI代点、永久信任或无交互自动确认。MCP请求未获授权时，面板显示待用户确认来源和准确动作；确认后重复传输不重复询问。输入变化使旧挑战不可用，返回保留草稿但不授权。

问题详情分别提供“登记修复并复测”“核实为非缺陷”“归并到主问题”“暂缓”。非缺陷须填依据、理由并人工确认；重复须选择同项目主问题，显示关联范围、确认级别及阻塞影响，拒绝循环/自指。结果分别标修复关闭、核实非缺陷、重复跟随主问题、暂缓仍阻塞；不能统一显示“修复通过”。处置撤销和主问题重开重新显示有效阻塞，原失败证据仍可查看。

结果卡片与报告分列执行完成、有效验证及有效通过/失败：12项均执行、2项依据未确认时为“执行完成12/12；有效验证10/12；未验证2”，结果未完成。自动步骤进度与用例分母分开，不用一个“完成率”混用。确认依据后由核心重检实际证据，页面不自行加计数。

网络重传显示原Attempt的传输恢复；“重新执行”创建新Attempt，副作用重新确认。连接恢复按快照配对游标重建，订阅间提交仍显示，不先跳最新游标。维护页明确“已提交状态备份”的边界、活动未纳入材料和永久历史缺口；完整迁移备份须先收尾，缺口存在不显示“可完整迁移”。

## 16 本轮结果、复用与有缺口迁移（2.6）

结果主屏以本轮S为分母，完整验收必测M另列。full的12项中本轮新执行10、有效复用2时，显示“新执行10/12、有效复用2/12、有效验证12/12”；来源展开可查原Run/Attempt，不把复用记成新执行。按需只选3项补充用例且通过时显示“所选3项通过、未打分”，旁列必测验证0/12和未选范围。新增尝试失败或取消后不回退旧复用绿灯。

维护页区分“完整迁移”和“携带已知缺口迁移”。后者先展示冻结清单、缺失/损坏对象、受影响报告及现存材料范围，用户明确确认后复制到新目录；无新增损失且来源可枚举才可切换。未知活动执行器、清单不可遍历或新损失仍阻止切换。成功标“已迁移，保留原有缺口”，不标全部恢复；原目录保留为非活动来源，不提供自动删除。具体守卫见存储分册第11节。
