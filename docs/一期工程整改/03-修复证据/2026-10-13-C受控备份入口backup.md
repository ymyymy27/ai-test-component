## 3. 本批的重要发现（未闭合，如实登记）

**接口级 `BackupPort` 早已冻结且与存储组件不是一回事**：`application/ports.py:212` 已声明
`BackupPort`，形状是 `inspect`／`create(request_id, workspace_id, destination)`／
`verify(..., backup_id)`／`restore(..., backup_id)` 返回协议 `Response`——即**按 `backup_id`
登记并可恢复**的产品级端口。本批新增的是**存储级**端口（`BackupStorePort`）与之并存，
两者不能合并。因此：

- `backup` 动作目前只覆盖"创建 + 校验 + 审计"这一段；**`inspect`／`restore` 与 `backup_id`
  登记未实现**（`restore` 的存储能力已在 `FileBackupStore.restore` 就绪，缺的是登记与产品入口）；
- 这解释了报告里"工作空间级受控写身份与产品入口尚未完成"的另一半；下一步要做的是
  `backup_id` 登记（需要一个记录类别，未在一期存储合同的记录种类里冻结）+ `inspect`/`restore` 入口。

其余未做：`migrate`（`inspect/plan/apply/resume/rollback` 与维护模式）、`return_stage`、
`test_connection`、`request_regression`；真实掉电/真实主机恢复未验收；全量 5133 节点未跑完。
