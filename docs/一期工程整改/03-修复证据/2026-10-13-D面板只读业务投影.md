## 1. 交付内容

| 项 | 说明 | 触点 |
| --- | --- | --- |
| 项目上下文只来自宿主 | 面板新增宿主消息 `{"kind":"projectContext","project_id","run_id"?,"scope_name"?}`：**身份只由宿主声明**，未声明即显示"当前项目：未选择"，面板不推断、不补造 | `src/aitest/resources/panel/src/index.ts` |
| 项目作用域守卫 | 宿主未声明项目时，项目作用域查询不派发，并给出显式拒绝 `PROJECT_NOT_SELECTED`；有项目时派发消息携带 `projectId` | 同上（`dispatchScoped`） |
| 问题与报告只读业务视图 | 「问题与报告」详情新增"读取问题清单"（`query` + `view=OPEN`）与"读取报告修订"（`query` + `run_id`）按钮；回执里的记录行按 `record_id@revision（聚合类别）`**原样列出**，空结果与失败都如实显示，界面不重算结论 | 同上（`reviewDetail`/`rowsBlock`） |
| 查询归位 | 回执只有动作名，面板按**本次查询的作用域**（issues/reports）把结果归位，不靠时间或顺序猜测 | 同上（`pendingQuery`） |
| 只读白名单回归 | 新增 Python 守卫：面板派发的动作必须全部属于 `contracts.commands.READ_ACTIONS`（或面板自有 UI 名字），且**写动作名不得出现在面板源码** | `tests/unit/test_panel_read_only_allowlist.py` |
| 面板行为回归 | Playwright 新增用例：项目上下文门禁、派发消息内容（action/projectId/parameters）、真实形状 `query` 回执逐行渲染、未读取/未选择如实显示 | `src/aitest/resources/panel/tests/panel.spec.ts` |
