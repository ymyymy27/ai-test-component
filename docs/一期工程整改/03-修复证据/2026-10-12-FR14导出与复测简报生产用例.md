## 1. 交付内容

| 项 | 说明 | 触点 |
| --- | --- | --- |
| `ReportArtifactPort` 实现 | `FileReportArtifactPort`：只写事务临时位置 → 核对摘要 → 原子发布；规范相对路径底线（拒绝绝对路径/盘符/穿越/符号链接/非法段），同名同内容幂等复用、同名异内容按篡改拒绝；`verify_artifact` 按实际字节复核 | `src/aitest/infrastructure/exports.py` |
| 导出用例 | `SavedExportService.export_report`：内容由已保存报告修订 + 已保存复核生成，调用方只能给 `report_id`/`kind`/`review_ids`/`attachment_refs`/`run_id`/脱敏策略版本；**导出身份由冻结输入派生**（`export_key_id`），调用方给不出 `export_id`，也给不出 `artifact_digest`/`artifact_ref` | `src/aitest/application/review/saved_exports.py` |
| 制品先入对象库 | 成功导出的永久制品先经 `FileObjectStore.publish_bytes` 保存并纳入已提交引用（`artifact_digest` 是存储侧核对的永久对象引用键），用户可见文件只是交付副本 | 同上 + 既有 `infrastructure/file_store/references.py` |
| Markdown 摘要 | 报告头（项目/运行/范围/来源身份/环境/规则/验收/模板/策略版本）、判定、覆盖计数、缺口、决定性失败、冻结问题修订、本地复核、证据索引（只给引用）与**"附件不随文件交付"声明** | 同上 |
| 可携带证据包 | ZIP：`report.md` + `manifest.json` + `evidence/<id>.bin`；manifest 记包格式版本、报告/复核精确修订、范围、投影策略、逐文件路径/大小/SHA-256、排除与缺失原因、生成时间；摘要按实际导出字节计算并与原始对象摘要区分 | 同上 |
| 脱敏底线 | 正文与附件都经生产投影器（`SafeMaterialProjector`）；无可安全投影的正文/无投影器一律拒绝；对象库落盘前的凭据过滤若改变字节，登记 `artifact.credential_filtered` 排除项 | 同上 |
| 失败不报成功 | 制品端口返回的摘要与实际字节不一致、或复核发布失败 ⇒ `INTEGRITY_CHECK_FAILED` 且**不登记**导出记录 | 同上 |
| 幂等复用 | 相同冻结输入（报告修订 + 复核集合 + 格式 + 脱敏策略 + 附件集合）复用同一产物与同一导出记录；新增复核产生新导出记录，旧记录不改 | 同上 |
| 复测简报 | 只读 `copy_repair_brief`：从指定 Issue/（可选）Attempt 投影文本 + 可解释复测指引，只给证据引用不含正文，位置未知显式保留"未知"，不写任何记录 | `src/aitest/application/review/repair_brief.py` |
| 动作接入默认装配 | `export_report` 与只读 `copy_repair_brief` 真实可派发并由 doctor 广告；默认可派发动作 48 → **50** | `interfaces/local/d_registration.py`、`bootstrap.py` |
