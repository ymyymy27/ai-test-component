## 1. 裁定内容

| 项 | 裁定 |
| --- | --- |
| 动作名 | `select_case_reuse`（与只读 `inspect_case_reuse` 成对；写侧选择） |
| 参数 | 严格为 `case_id` + `source_run_id`/`source_snapshot` + `target_run_id`/`target_snapshot`（与 CORE-001 1.69 同一组引用；`SnapshotContentRef` 三字段），`target` 固定 `case_id` |
| 记录 | `reuse_decision@1`：每个 (项目, 目标运行) 一条、追加修订、正文含 `references`（`ReuseReference` 列表，架构 01 §229 形状） |
| 幂等 | `intent_id` + 输入摘要；同意图同输入回读原结果，同意图异输入 `INTENT_CONFLICT` |
| 权限 | 人工动作：非受控交互会话（含 relay）拒绝且不落盘 |
| 资格 | **不授予资格**：来源身份由同一核对器派生，R/V 仍由消费侧 `derive_reuse_outcome` 按当前事实派生 |
