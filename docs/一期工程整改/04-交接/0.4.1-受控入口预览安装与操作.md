# 0.4.1 受控入口预览：安装与操作

本包先提供可操作的核心入口：配置、连接、新建项目、请求核心确认其他现有业务动作、查看核心回执和原有结果。**它仍不是一期完整可用版**：完整计划/执行向导、默认可信环境载体登记与独立业务核验、真实Trae安装和端到端执行/恢复仍欠。接口已存在不代表这些依赖已经配置。

## 安装

使用Windows与Python3.13；原生确认窗口还需要Python安装中的tkinter/Tcl组件。安装匹配版本的[Python包](../../../dist/ai_test_component-0.4.1-py3-none-any.whl)与[候选VSIX](../../../integrations/trae/dist/aitest-trae.vsix)。在仓库根执行：

```powershell
py -3.13 -m pip install --upgrade .\dist\ai_test_component-0.4.1-py3-none-any.whl
py -3.13 -c "import aitest, tkinter; print(aitest.__version__)"
py -3.13 -c "from aitest.interfaces.local.native_confirmation import _create_windows_root; r=_create_windows_root(); r.withdraw(); print(r.tk.call('info','patchlevel')); r.destroy()"
New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\AITest\workspace-preview"
```

记下安装此包的python.exe路径。在编辑器扩展菜单选择从VSIX安装，选择上述候选文件；真实Trae版本兼容目前待实测。不要把不兼容宿主的安装失败登记为产品通过。

## 新建项目

1. 打开并信任实际源码工作区，在命令面板执行 `AI Test: 配置工作空间与项目`。
2. 填写已安装新包的解释器，选择刚建立的专用用户数据目录，保留新项目编号或填写准确既有编号。
3. 执行 `AI Test: 打开一期面板（预览）`，点击“连接核心”与“刷新核心状态”。
4. 受控操作区点“填写新建项目”，修改真实名称与测试目标。模板取核心实际workspace_id，提交序号由核心事务分配。
5. 点“请求核心确认并提交”；在核心独立窗口核对输入，点击“确认本次操作”。取消、关闭、按回车或120秒未响应均取消。
6. 按回执的具体saved/业务状态判断结果。已有同编号项目会拒绝以首次修订覆盖；传输成功不代表业务测试通过。

## 现有业务动作

高级操作区接受现有完整动作参数，项目固定为宿主选择。计划发布、依据确认、授权步骤等须给准确target及材料修订；窗口展示核心算出的挑战与对应保存正文，调用方不能带审批号或“已确认”字段。环境、执行、报告等仍按现行应用门禁处理，不承诺任意JSON都可执行。

字段形状为 `{"action":"现有动作","intent_id":"稳定业务意图","expected_revision":0,"target":"准确目标","parameters":{}}`；需要绑定修订时另加 `binding_revision`。占位值不能当真实来源提交。Git/plain绑定与清单摘要须取真实来源，不能靠改形态绕过来源核对。

也可用同版本CLI：`aitest dispatch --native-confirmation --workspace <用户数据目录>`，stdin为完整Command（还须提供request_id、project_id等）。普通dispatch与stdio MCP不会自动获得人工权限。

## 结果未知与升级

取消会保留草稿中的intent_id；明确改变业务输入或明确重跑才新建意图。超时/断连可能发生在提交之后，先读取准确对象/修订核对原意图，不能靠换号重发。配置变化会清除旧草稿/运行编号，避免套用旧项目。

已有核心不会因安装新wheel热重载。确认无活动/未知执行后，经现有受控关闭端请求排空；该端仍会拒绝不安全退出。开发者可调用 `aitest.bootstrap.shutdown_endpoint(Path(准确用户数据目录))`；不要直接终止进程或删除发现文件。重新连接并查看doctor声明后再操作。

输入、版本、原始失败、组件检查和未验证边界见[本批证据](../../validation/p1-native-entry-20261015/README.md)；产品是否完成与验收状态只见[项目现状](../../现状.md)。
