# 0.4.5 纯函数与报告关联提测

沿用 [0.4.4 安装与鉴权配置](0.4.4-鉴权与动态对象核验.md)和[计划执行操作](0.4.3-计划执行核验报告操作.md)。安装时使用同版本的核心 wheel 与 Trae VSIX，当前能力和验收边界见[项目现状](../../现状.md)。

本批安装包为仓库根目录下的 `dist/ai_test_component-0.4.5-py3-none-any.whl`，扩展为 `integrations/trae/dist/aitest-trae.vsix`（扩展清单版本 0.4.5）。在已选定的 Python 3.13 虚拟环境中执行：

```powershell
python -m pip install --upgrade .\dist\ai_test_component-0.4.5-py3-none-any.whl
aitest --help
```

Trae 仍按安装 VSIX 流程选择上述扩展，并指向该虚拟环境解释器。此处提供组件试用与提测入口，不代表真实 Trae 安装已经验收；当前来源阻断见第 4 节。

## 1. 纯函数独立预期

适用于明确测试函数输出的用例。把独立预期保存为准确 Case 的 assertion_basis.text，并走原依据确认、计划发布和执行授权流程。例如：

```json
{"schema_version":"aitest.pure-function-basis/1","expected_facts":{"result":5}}
```

被测入口执行真实函数并将结果作为一个 JSON 对象输出到 stdout，例如 `{"result":5}`。预期应来自需求或测试设计，不能从本次实际输出反填。调用原 verify_pending，填写当前 run_id、step_id、attempt_id 和 base_snapshot_commit_id。核心读取这次执行永久保存的完整 stdout，与准确冻结预期比较；不需要 AITEST_BUSINESS_QUERIES 或数据库配置。

当前支持不超过 1 MiB 的 stdout JSON 对象，按预期键严格比较 JSON 值；额外日志、重复键、过滤/截断、非对象或过期 Attempt 都不能作为有效输出。异常仍记录缺口。这种核验只证明预期输出匹配，有持久副作用的业务继续使用独立 HTTP 回读，配置见 0.4.4 指南。

## 2. 报告关联正式提测

先保存任务、交付草稿、来源快照和准确报告，再选择“正式提测并关联报告”。填写项目修订、本次提测编号及准确引用，例如：

```json
{
  "delivery_ref":{"delivery_id":"delivery-1","record_revision":1},
  "source_ref":{"snapshot_id":"source-1","record_revision":1},
  "verification_report_ref":{"report_id":"report-1","record_revision":1}
}
```

这里的编号必须替换为实际保存回执。首次正式提测的预期修订为 0，重传沿用同一业务意图。报告引用可留空，此时没有报告授予验证范围。人工确认绑定任务、交付、来源和报告的准确材料；新报告不会自动替换已提测的旧引用。

报告必须属于同项目、同源码内容。每个任务验收项须通过 CaseLink 关联用例；该项关联的全部用例都属于报告的新执行 E 与有效验证 V 才进入 verified_in_scope，复用 R 不代替这次新执行。运行中修订读取准确有效链，并保留原关联义务。没有关联的项继续未验证。

交付视图分别显示开发自述、实际验证范围、未验证范围、核验状态与业务结论。核验有效不等于业务通过。视图重读报告及证据材料，失效时显示“材料无效”，不篡改历史提测记录。

## 3. 运行控制

流程表单新增“按计划推进已授权步骤”“暂停运行”“恢复运行”“请求取消运行”。均填写实际运行编号和最新执行快照编号。推进只消费已有授权；恢复和取消不伪造执行结束，未知副作用不自动重跑。快照已变化时先刷新读取再操作。

## 4. 验证边界

完整四步样例已暴露默认执行路径的实现缺口：执行前语法/导入探针不能证明业务进程实际加载来源，核心保留 `actual_execution_load_source_unverified`，报告为 `incomplete`，关联提测仍为未验证。输出全部匹配也不能消除此缺口。当前版本不能作为一期完整通过版本交付；实际进程来源采集、适用构建与显式最小启动仍需实施。

[本批证据](../../validation/p1-implementation-audit-20261015/README.md)分别登记组件流程、浏览器、打包和剩余范围。自动化中的人工事件使用明确夹具；真实 Trae 用户操作、实际业务部署、动态复用资格、物理掉电及一期全部 AC 未完成验收。
