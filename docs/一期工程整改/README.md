## 3. 使用边界

- 历史批次中的“通过”只证明其记录的命令与版本；不能替代当前全量、真实 Trae、其他宿主、掉电恢复或平台对拍。
- 后续修复与验收写入[现状](../现状.md)、四包检查或新的[修改日志](../修改日志/README.md)/[验证批次](../validation/README.md)，不回写历史目录。
- 本目录不另定字段、判定口径或降低一期承诺；与项目文档冲突时以[项目文档阅读索引](../项目文档/阅读索引.md)指定的主责合同为准。
