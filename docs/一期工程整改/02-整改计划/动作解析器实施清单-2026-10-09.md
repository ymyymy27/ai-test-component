# 可信动作解析器实施清单（下一会话可直接开工）

日期：2026-10-09，基线 `f1998e4`，分支 `fix`。本清单把"实现生产 `ExecutionActionResolver`、打通默认执行链"拆成**可直接执行**的步骤、触点与反例；不含实现本身。

## 1. 目标

在 `bootstrap.assemble_workspace_core` 注入一个**生产**解析器，使 `prepare_execution` 不再返回"无可信解析器"，而是把冻结绑定变成 `ResolvedExecutionAction(attempt, request, environment_content_identity, source_content_identity)`。它只**构造对象**：不写业务记录、不启动进程、不落证据。

## 2. 必读触点（按依赖顺序）

| 触点 | 作用 |
| --- | --- |
| `application/ports.py` `ExecutionActionResolver.resolve(run, step, intent_id, prepared, step_content)` | 端口签名与返回类型 |
| `application/execution/authorization.py` `prepare` 与 `_actual` | 现有准入核对：环境/源码内容身份、Run/Step/intent 一致性、冻结步骤截止（`_require_frozen_step_deadline`）、`attempt.timeout_ms == request.timeout_ms` |
| `application/execution/step_content.py` `StepContent.checked_case()` | 步骤正文与用例/计划修订链的自证 |

| `domain/execution/runs.py` `Attempt`/`ExecutionRequest`/`RegisteredEntryRef` | 要构造的字段；截止、身份、副作用类别 |

| `bootstrap.py` `execution_action_resolver=` | 注入点；同时把"默认不可用"的期望改为"缺具体动作依赖" |

## 3. 实现约束（已裁定，AB-001 1.35）

1. `cwd_mapping` 只接受 `workdir:<安全相对路径>`（拒绝绝对/盘符/`..`/越界/逐段链接）；
2. `entry_arguments` **逐字**为最终参数，任何代入即拒绝并要求重新 prepare；
3. 适配器由 `adapter_versions` 的**唯一键**决定；
4. 截止取冻结环境的 `step_timeout_seconds`（准入点已强制），`attempt.timeout_ms == request.timeout_ms`；
5. 四类来源失败（入口缺失/来源不符/环境未登记/物化失败）返回不可重试阻塞并登记 `source_unverified` 缺口；
6. 构造请求时 `source_binding_digest` 应取 start 物化映射摘要（BC-001 §6），**不要**复用 B 在 prepare 冻结的 `resolved_input_digest`。

## 4. 反例清单（实现时必须逐条覆盖）

伪造/缺冻结绑定键；`adapter_versions` 多键或空值；参数被改写/截断/追加；`cwd_mapping` 绝对路径、盘符、`..`、越界、链接祖先；观察入口或解释器与冻结不符；来源核验非 `verified`；物化映射摘要与已保存值不符；截止与冻结声明不符（已由准入点覆盖，仍应加回归）；四类失败各自给出 `retryable=False` + `source_unverified`。
