## 1. `cwd_mapping` 语法 —— 取 A（受限相对前缀）

- **裁定**：`cwd_mapping` 形如 `workdir:<安全相对路径>`；解析结果必须落在固定 workdir 内，拒绝绝对路径、盘符、`..` 穿越与链接（含链接祖先）逃逸。
- **依据**：[架构01 第12节](../../项目文档/一期/架构文档/01-项目与计划.md)："物化始终在 workdirs/<run_id>，包含所选模块依赖闭包、入口、共享配置和必要资源，排除凭据/生成物，**拒绝路径穿越与链接逃逸**"；同节"start 在固定 workdir 中解析实际路径，保存期望→实际路径映射和 source_binding_digest"。
- **影响面**：AB-001 §3.4 需补语法说明；start 解析实现与反例（绝对路径/盘符/`..`/链接祖先/越界）；B 侧生成夹具。

## 2. `entry_arguments` 与用例输入 —— 取 A（不代入）

- **裁定**：`entry_arguments` 即最终参数序列，**不由用例正文或输入代入**；需要不同命令必须重新 prepare（新的 `resolved_input_digest` 与意图）。
- **依据**：[架构01 第12节](../../项目文档/一期/架构文档/01-项目与计划.md)："prepare 冻结解释器/可执行文件身份、project 模块范围、工作目录映射、**已登记入口与参数**……`resolved_input_digest` 包含这些来源约束"；[架构02 第7节](../../项目文档/一期/架构文档/02-执行与证据.md) 的禁止项写明"**模型正文决定新命令**"；[功能文档第9节](../../项目文档/一期/功能文档/01-功能文档.md) 复用须"入口参数……一致"。
- **影响面**：执行请求构造（参数必须逐字来自冻结绑定）、反例（正文/输入试图改写参数、占位符字符原样传递）。

## 3. 适配器选择依据 —— 取 A（`adapter_versions` 键）

- **裁定**：所选适配器由 `ExecutionSourceBinding.adapter_versions` 的**唯一键**决定；键多于一个或缺失即拒绝并要求重新 prepare，不新增字段。
- **依据**：[架构01 第12节](../../项目文档/一期/架构文档/01-项目与计划.md) 把"依赖集合与**适配器版本**"列为冻结来源约束；[架构05 第9节](../../项目文档/一期/架构文档/05-Trae接入.md) 能力协商包含"执行入口类型"；[功能文档第9节](../../项目文档/一期/功能文档/01-功能文档.md)"一期自动适配 Python"。
- **影响面**：prepare/start 校验、默认装配注入；AB-001、BC-001 需注明该解释。

## 4. 失败回执与按动作降级 —— 取 A（不可重试阻塞 + 缺口）

- **裁定**：入口缺失/来源不符/环境未登记/物化失败在 start 前一律视为**不可重试的阻塞**（现实现对应 `SourceBindingUnverified`），并在运行事实中登记 `source_unverified` 缺口；只有不依赖该动作的能力（登记、查询、模板、本地保存）保持可用。
- **依据**：[需求文档 P1-AC03/13/25](../../项目文档/一期/需求文档/01-需求文档.md)："来源无法证明不得声称该源码完整通过"、"启动前核对实际来源，不符则阻塞"；[AGENTS 第4节](../../../AGENTS.md) "能力降级按**具体动作**的真实依赖判断，不把某个适配器故障扩散为全部核心能力故障"。
- **影响面**：错误码与 `next_step` 文案、A-10 动作级门禁、AC19/23 的失败回执证据。
