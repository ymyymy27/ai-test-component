# A 包提交闭包：当前实现与恢复边界

复核：2026-10-12，`develop@845e697`。本文件保留提交/闭包/恢复不变量并刷新实际实现；早期 manifest/1 和“完整清单尚未实现”的说法不再作为当前结论。规范仍以[存储与恢复](../../项目文档/一期/架构文档/04-存储与恢复.md)为准。

## 1. 必须保持的不变量

1. 一份不可变 CommitManifest 冻结记录/幂等结果、引用/对象、索引根、事件边界及业务变更索引；工作空间/格式代次/writer_epoch/父提交准确核对。材料刷新并准备后切换唯一 current。
2. 普通记录、查询、事件、快照游标和原意图回读消费同一已发布根；不能据投影序号/较大提交号/健康标签证明内容完整。旧根和原业务字节永久留存。
3. 外部执行/模型在事务外；业务意图先可靠保存。同意图异输入冲突，丢回执先准确回读，未知结果不自动重放。
4. 迁移/回收先备份、核实真实活动和抢救输出；未知或不可读材料保持阻塞。所有新增字节在落盘前过滤凭据并核对引用/摘要/大小/归属，不能过滤后仍沿用旧摘要。

## 2. 源码实施点

| 触点（src/aitest/infrastructure/file_store/） | 当前实现 |
| --- | --- |
| unit_of_work.py / records.py / sharded_records.py | 短事务、预期修订、记录归属、意图/当前事实同提交 |
| commit_manifest.py / canonical_manifest.py | 清单 v2、准确幂等结果与永久引用、父根核对 |
| publication_backend.py / atomic.py | 七字段 current、Windows 刷新/替换、保留候选与前指针、不确定发布阻塞 |
| ordered_index.py / ordered_events.py / business_changes.py | 有界寻址、旧根/游标、有限 QuerySpec 与业务稀疏索引 |
| integrity.py / references.py / backup.py | 永久闭包、对象归属/字节、备份/恢复路径与链接检查 |
| recovery.py / execution_handles.py / spool.py / maintenance.py | 权威活动/句柄核实、采集租约、抢救与回收资格 |
| commit_migration.py / manifest_migration.py / migrations.py | 备份先行的 0003—0007 迁移与中断前态 |

默认装配会恢复、迁移并 `confirm_current`，不能把未知发布当成功后继续新写。读不出准确记录也不能回假空结果。

## 3. 剩余工作与验证

A-05 保留未知发布人工恢复入口、完整历史对象巡检/产品报告排序、设备耐久/物理掉电；A-06 保留完整 C/D 备份/恢复与符号链接权限实测；A-07 保留未知真实活动的产品处置/安全回收。D 报告/导出未接线，不能据底座测试称其永久闭包已经验收。

切点验证必须覆盖材料准备/刷新、清单写入、current 切换与回执；发布前只能看到完整旧根，发布后失联回原完整结果。故障后新提交不能漏旧已发布记录；游标绑定查询/提交/代次，损坏/异常路径明确拒绝；默认保存→换核心→恢复及未知副作用实测另记。
