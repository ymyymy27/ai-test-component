这些截图来自本机真实 Trae Webview，不是 Chromium mock。对应面板重排后的最终构建：

- `result.png`：结果页。只列本次纳入的 1 个验收项；覆盖条给“通过 1”；项目级检查单独一行；底部只有“已完成 2 / 2 条检查”和查看计划、调整范围、报告、再次运行。

- `report.png`：报告文档。结论、验收项、用例明细、问题、调用链与模拟数据、证据索引；项目级检查为空时不显示空段。
- `plan-doc.png`：任务与计划文档。验收项用“本次 / 待补充”区分是否在当前计划范围；用例、交付说明、检查模板分段。
- `history.png`：项目级历史。每行时间、任务、计划/范围、结论与本次计数；没有把 0 计数的三类全部铺开。

- `settings.png`：设置页。环境自检、项目规则、GitHub 变更、折叠的项目配置、外观、备份。
